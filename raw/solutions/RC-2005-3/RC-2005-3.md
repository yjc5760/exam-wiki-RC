## 1. 原始題目重述 (Problem Restatement)

一 RC 構架樓層高 365 cm，梁之尺寸與配筋等均相同，且柱與梁同寬，柱斷面為 60 cm × 60 cm，梁之有效深度 $d = 70\ \text{cm}$，拉力筋為 6-#8，採用混凝土 $f'_c = 280\ \text{kgf/cm}^2$，鋼筋降伏強度 $f_y = 4200\ \text{kgf/cm}^2$，試檢核該構架**角柱接頭**之剪力強度。（20 分）

> **原卷原文（94 年第三題）核對：** 「一 RC 構架樓層高 365 cm，梁之尺寸與配筋等均相同，且**柱與梁同寬**，
> 柱斷面為 60 cm×60 cm，梁之有效深度 d=70 cm，拉力筋為 6-#8，採用混凝土 $f'_c$=280 kgf/cm²，
> 鋼筋降伏強度 $f_y$=4200 kgf/cm²，試檢核該構架**角柱接頭**之剪力強度。（20 分）」

## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：** 梁柱接頭（BCJ）剪力的水平力平衡——梁鋼筋拉力傳入接頭，柱剪力分擔部分，剩餘由接頭承擔。

> ⚠ **2026-08-22 兩處改判（主線數值變更）：**
> ① **梁鋼筋拉力取 $1.25f_y$ 而非 $f_y$。** $V_{jh} = \gamma\sqrt{f'_c}A_j$ 這條檢核**只存在於耐震專章**
> （土木 401 §15／ACI 318 Ch.18），其配套規定 §18.8.2.1 明訂「接頭力應以梁受拉鋼筋 $1.25f_y$ 計算」。
> 既然用了耐震專章的**強度**公式，需求就必須用耐震專章的**力**，不可混用。
> ② **$V_{col} = M/H$，不是 $2M/H$。** 接頭處梁彎矩由**上下兩根柱**分擔（等勁度時各半），
> 柱反曲點在樓層中高，故 $V_{col} = \dfrac{M/2}{H/2} = \dfrac{M}{H}$。舊版的 $2M/H$ 大了一倍，
> 使 $V_{jh}$ 被低估。（舊版 §4③ 的說明文字本身就自相矛盾：先寫出 $(M_n/2)/(H/2)$，
> 又斷言 $V_{col}\times(H/2) = M_n$。）

**測驗重點：**
1. 接頭水平剪力 $V_{jh}$ 的力平衡推導（由梁鋼筋拉力 $T$ 與柱剪力 $V_{col}$ 計算）
2. 柱剪力 $V_{col}$ 的計算（先求梁 $M_{pr}$，再由**接頭上下柱各分擔一半**得 $V_{col} = M_{pr}/H$）
3. 接頭強度 $\phi V_n = \phi \gamma \sqrt{f'_c} A_j$ 中 $\gamma$ 的選取（角柱接頭 = 外接頭 = $\gamma = 3.2$）
4. 有效接頭面積 $A_j$ 的計算

**典型陷阱：**
- ⚠ **$T$ 要用 $1.25f_y$**：接頭剪力檢核出自耐震專章，配套規定就是超強係數 1.25（§18.8.2.1）
- ⚠ **$V_{col} = M_{pr}/H$ 不是 $2M_{pr}/H$**：接頭處的梁彎矩由上下兩根柱分擔
- ⚠ **$V_{jh} \ne T$**：不少考生直接以 $T$ 作為接頭剪力，忽略柱剪力 $V_{col}$ 的減項
- ⚠ **$\gamma$ 係數選錯**：角柱接頭 = 「其他」類 → $\gamma = 3.2$；不可用 3.9（三面／一雙對面）或 5.3（四面）。**318-19 另有屋頂層接頭之 2.2**
- ⚠ **$A_j = b_j \times h_c$**：$b_j$ 需按公式取較小值，梁寬 = 柱寬時 $b_j = b_c$

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**作戰計畫：**
1. 計算梁鋼筋拉力 $T = 1.25A_s f_y$（耐震）
2. 計算梁可能彎矩強度 $M_{pr}$（Whitney 應力塊，$\phi = 1.0$）
3. 由 $M_{pr}$ 反推柱剪力 $V_{col} = M_{pr}/H$（上下柱各分擔一半）
4. 求接頭水平剪力需求 $V_{jh} = T - V_{col}$
5. 計算接頭有效面積 $A_j$ 與強度係數 $\gamma$
6. 驗核 $\phi V_n \ge V_{jh}$

**關鍵陷阱（4 個）：**
- ⚠ **柱剪力大小**：$V_{col} = M_{pr}/H$（**不是** $2M_{pr}/H$）；方向使它成為接頭剪力的**減項**
- ⚠ **角柱接頭分類**：角柱 = 僅兩個垂直方向各有一根梁（從兩個面進入），在分析平面內只有單側梁 → 外接頭（other joint）→ $\gamma = 3.2$（從 ACI 12 psi^{1/2} 換算）
- ⚠ **$b_j$ 的計算**：$b_j = \min(b_{beam}+h_{col},\ b_{beam}+2x) \le b_{col}$，本題梁與柱同寬 → $b_j = 60\ \text{cm}$
- ⚠ **$H$ 的使用**：題目給「樓層高 365 cm」，此即柱上下兩端的中心線距離，以 $H/2$ 作為柱反彎點至接頭的距離

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

> **主線採耐震規定：梁受拉鋼筋取 $1.25f_y$**（土木 401-112 §15.6.2／ACI 318-19 §18.8.2.1）。
> 文末並列「用 $f_y$」的對照值，兩者結論相同（皆通過）。

### ① 梁受拉鋼筋拉力 $T$

$$T = 1.25\,A_s f_y = 1.25 \times 30.42 \times 4{,}200 = \boxed{159{,}705\ \text{kgf}}$$

（對照：若取 $T = A_sf_y = 127{,}764$ kgf）

---

### ② 梁可能彎矩強度 $M_{pr}$（Whitney 應力塊，$b_w = 60$ cm，$\phi = 1.0$）

$$a = \frac{T}{0.85 f'_c b_w} = \frac{159{,}705}{0.85 \times 280 \times 60} = \frac{159{,}705}{14{,}280} = 11.18\ \text{cm}$$

$$M_{pr} = T\left(d - \frac{a}{2}\right) = 159{,}705 \times \left(70 - 5.59\right) = 159{,}705 \times 64.41 = 10{,}286{,}000\ \text{kgf·cm}$$

$$\boxed{M_{pr} = 102.86\ \text{tf·m}}\qquad(\text{對照：用 } f_y \text{ 時 } M_n = 83.72\ \text{tf·m})$$

---

### ③ 柱剪力 $V_{col}$（⚠ 本題最容易錯的一步）

**接頭彎矩平衡：** 角柱接頭在分析平面內**只有一根梁**，故

$$\Sigma M_{col} = \Sigma M_{beam} = M_{pr} = 102.86\ \text{tf·m}$$

**上下柱分擔：** 上下層柱斷面與樓高相同 ⇒ 勁度相同 ⇒ 各分擔一半

$$M_{col,\text{上}} = M_{col,\text{下}} = \frac{M_{pr}}{2} = 51.43\ \text{tf·m}$$

**柱剪力（反曲點在樓層中高，力臂 $H/2$）：**

$$V_{col} = \frac{M_{col,\text{上}}}{H/2} = \frac{M_{pr}/2}{H/2} = \frac{M_{pr}}{H}
= \frac{10{,}286{,}000}{365} = \boxed{28{,}181\ \text{kgf} = 28.18\ \text{tf}}$$

> ⚠ **舊版寫 $V_{col} = 2M_n/H = 45.9$ tf，分子多算了一倍。**
> 檢查方式：$V_{col} \times H$ 應該等於**一個接頭**的梁彎矩（$28.18 \times 3.65 = 102.9$ ✓），
> 而不是兩倍。物理上：$V_{col}$ 是整個樓層的柱剪力，一根柱上下端合計產生的彎矩 $V_{col}\cdot H$
> 必須等於該柱線上下兩個接頭各分一半後的總和 $= M_{pr}$。
>
> （對照：用 $f_y$ 時 $V_{col} = 83.72\times10^5/365 = 22.94$ tf。）

---

### ④ 接頭水平剪力需求 $V_{jh}$

角柱（外）接頭的自由體：頂部梁筋拉力 $T$ 向接頭傳入，柱剪力 $V_{col}$ 反向：

$$V_{jh} = T - V_{col} = 159{,}705 - 28{,}181 = \boxed{131{,}524\ \text{kgf} = 131.5\ \text{tf}}$$

（內接頭則為 $V_{jh} = T_1 + C_2 - V_{col}$，本題單邊有梁故只有一項 $T$。）

---

### ⑤ 有效接頭面積 $A_j$

土木 401-112 §15.6.3／ACI 318-19 §15.4.2.4：接頭有效寬度取

$$b_j = \min\big(b_{beam} + h_{col},\ b_{beam} + 2x\big) \le b_{col}$$

其中 $x$ 為梁側面至柱側面之較小距離。本題梁寬＝柱寬 ⇒ $x = 0$：

$$b_j = \min(60+60,\ 60+0) = 60\ \text{cm}\ \ (\le b_{col} = 60\ ✓)$$

$$A_j = b_j \times h_{col} = 60 \times 60 = \boxed{3{,}600\ \text{cm}^2}$$

> 舊版寫的 $b_j = \min(b_c,\ b_w + 0.5h_c)$ 是坊間簡化式；本題梁柱同寬時兩式同得 60 cm，
> 但梁比柱窄時兩式會不同，宜引規範原式。

---

### ⑥ 接頭剪力強度 $\phi V_n$

**接頭分類：** 角柱接頭在分析平面內僅單側有梁，**不**滿足「四面」「三面」或「一雙對面」受圍束
⇒ 屬「**其他**」類。土木 401（及 101 年考卷原文）的三個 $\gamma$ 值（kgf/cm² 制）為

$$\gamma = 5.3\ (\text{四面圍束}),\quad 3.9\ (\text{三面或一雙對面}),\quad \boxed{3.2}\ (\text{其他})$$

（SI 制對應 $1.7 / 1.2 / 1.0\sqrt{f'_c}$ MPa；舊 psi 制 $20/15/12\sqrt{f'_c}$ psi。
舊版本頁把中間那項寫成 4.0，是 psi 制換算值；**土木 401 印的是 3.9**。）

$$\phi V_n = \phi\,\gamma\sqrt{f'_c}\,A_j = 0.85 \times 3.2 \times \sqrt{280} \times 3{,}600
= 0.85 \times 3.2 \times 16.733 \times 3{,}600$$

$$= \boxed{163{,}848\ \text{kgf} = 163.8\ \text{tf}}\qquad(\phi = 0.85\ \text{為接頭剪力專用，§21.2.1})$$

---

### ⑦ 強度驗核

$$V_{jh} = 131.5\ \text{tf} \ \le\ \phi V_n = 163.8\ \text{tf} \quad \checkmark$$

$$\frac{V_{jh}}{\phi V_n} = \frac{131.5}{163.8} = 0.80 \quad (\text{利用率 80\%，餘裕 20\%})$$

**結論：角柱接頭剪力強度符合要求。**

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

**① $V_{jh} = T - V_{col}$ 的推導邏輯**

取「接頭 + 上半柱」為自由體，水平力平衡：

| 力 | 方向 | 說明 |
|---|---|---|
| $T = 1.25A_sf_y$ | → 向右（梁頂筋拉力傳入） | 梁受拉鋼筋 |
| $V_{col}$ | ← 向左 | 上柱剪力 |
| $V_{jh}$ | ← 向左 | 接頭水平剪力（待求） |

$\Rightarrow T - V_{col} - V_{jh} = 0$，故 $V_{jh} = T - V_{col}$（$V_{col}$ 是**減項**）。

若保守忽略 $V_{col}$：$V_{jh} \approx T = 159.7$ tf，仍 $< \phi V_n = 163.8$ tf ✓（利用率 97%，僅剩 3% 餘裕）。
**這個「保守下限」很值得在考卷上寫一句**——它顯示本接頭其實相當吃緊。

**② $\gamma$ 係數三值與單位制**

| 接頭圍束情形 | ACI（psi 制） | SI（MPa 制） | 土木 401（kgf/cm² 制） |
|---|:---:|:---:|:---:|
| 四面受梁圍束 | $20\sqrt{f'_c}$ | $1.7\sqrt{f'_c}$ | **5.3** |
| 三面或一雙對面 | $15\sqrt{f'_c}$ | $1.2\sqrt{f'_c}$ | **3.9**（非 4.0） |
| 其他（含角柱） | $12\sqrt{f'_c}$ | $1.0\sqrt{f'_c}$ | **3.2** |

記憶：**角柱 3.2、T 形 3.9、內柱 5.3**。（$\times 3.193$ 由 MPa 換 kgf/cm²。）

**③ 角柱接頭為何是「其他」類？**

規範看的是「梁把接頭的**面**遮住多少」：需梁寬 $\ge \frac34$ 柱寬且梁深不小於最深梁的 $\frac34$，
該面才算「受圍束」。角柱在**兩個正交方向各只有一根梁**，於任一分析平面內都只遮住一面
⇒ 既非四面、也非三面、更非「一雙**對**面」⇒ 落入「其他」，$\gamma = 3.2$。
**這也是角柱接頭在耐震設計中最脆弱的原因**：需求跟內柱差不多，強度卻只有內柱的 60%。

**④ 本題的工程意義：角柱接頭是不是控制項？**

利用率 80%（忽略 $V_{col}$ 時 97%）。梁只要再加一點鋼筋、或混凝土強度略低於設計值，
這個接頭就會不通過。**角柱接頭通常是整棟建築耐震設計最吃緊的節點之一**，
實務上常以「加大柱斷面」「提高柱混凝土強度」「梁筋改用機械式錨定／彎鉤加大彎折半徑」處理，
而不是靠增加接頭箍筋（接頭箍筋只提供圍束，不計入 $\gamma\sqrt{f'_c}A_j$）。

**⑤ 柱淨高 vs 樓層高**

本題以樓層高 $H = 365$ cm（柱上下接頭中心距）計算 $V_{col}$，這與「反曲點在樓層中高」的假設一致，是正確用法。
若誤用柱**淨高**（扣掉梁深），$V_{col}$ 會偏大、$V_{jh}$ 偏小 ⇒ **偏不安全**。原卷未給梁全高，用 365 cm 是唯一可行且正確的作法。

**⑥ 接頭尚須檢核（本題未問，但實務必做）**

- 接頭橫向鋼筋：至少延續柱端圍束箍筋（§18.8.3），或滿足減量規定。
- 梁筋在外接頭的**錨定**：$90°$ 標準彎鉤，$\ell_{dh} = \dfrac{f_yd_b}{17.2\sqrt{f'_c}}$（kgf 制），
  且 $\ge 8d_b$、$\ge 15$ cm。D25：$\ell_{dh} = \dfrac{4200\times2.54}{17.2\times16.733} = 37.1$ cm，
  而柱深只有 60 cm、扣保護層後可用約 55 cm ⇒ 剛好可行，但沒有太多餘裕。
- 柱深 $\ge 20d_b$（梁筋貫穿內接頭時）：本題為外接頭不適用，但同類題常考。

## 6. 依最新規範對照（土木 401-112／ACI 318-19）

原卷（94 年）未指定版本，當時為 **土木 401-86／ACI 318-99** 世代。現行為 **土木 401-112**（ACI 318-19 世代）。

| 項目 | 舊制（318-99 世代） | 401-112／ACI 318-19 | 影響 |
|---|---|---|---|
| 接頭剪力需求之鋼筋應力 | $1.25f_y$（§21 已有此規定） | 同（§18.8.2.1） | 主線改用 1.25$f_y$ |
| $V_{jh} = T - V_{col}$ | 同 | 同 | 不變 |
| $A_j$ 有效寬度 | $b_j = \min(b+h,\ b+2x) \le b_{col}$ | 同（§15.4.2.4） | 不變（60 cm） |
| $\phi$（接頭剪力） | 0.85 | 0.85（§21.2.1(e)） | 不變 |
| **$\gamma$ 值** | 三檔：$20/15/12\sqrt{f'_c}$ psi | **六檔**（Table 18.8.4.3）：<br>依「柱是否延伸至接頭上方」再分兩組 | **本題可能不通過，見下** |
| $\lambda$（輕質混凝土） | — | 明訂 $\gamma$ 須乘 $\lambda$ | 常重混凝土 $\lambda = 1$ |

### ⚠ ACI 318-19 新增的「屋頂層接頭」折減——本題的關鍵風險

318-19 把接頭 $\gamma$ 依「**柱是否連續延伸至接頭上方**」再分成兩組：

| 圍束情形 | 柱**延伸**至接頭上方 | 柱**未延伸**（屋頂層接頭） |
|---|:---:|:---:|
| 四面受梁圍束 | $1.7\sqrt{f'_c}$（kgf 制 5.3） | $1.5\sqrt{f'_c}$（kgf 制 4.7） |
| 三面或一雙對面 | $1.2\sqrt{f'_c}$（3.9） | $1.0\sqrt{f'_c}$（3.2） |
| **其他（含角柱）** | $1.0\sqrt{f'_c}$（**3.2**） | $0.7\sqrt{f'_c}$（**2.2**） |

**本題若為屋頂層角柱接頭：**

$$\phi V_n = 0.85 \times 2.2 \times 16.733 \times 3{,}600 = 112{,}646\ \text{kgf} = \mathbf{112.6\ \text{tf}}$$

$$V_{jh} = 131.5\ \text{tf}\ >\ \phi V_n = 112.6\ \text{tf} \quad ✗ \ \textbf{不通過（超出 17\%）}$$

原卷只說「一 RC 構架樓層高 365 cm」，**沒有交代接頭在哪一層**。
- 若為**中間樓層**（柱上下連續）：$\gamma = 3.2$、$\phi V_n = 163.8$ tf ⇒ **通過**（本解主線）。
- 若為**屋頂層**（柱不再往上延伸）：依 318-19 之 $\gamma = 2.2$ ⇒ **不通過**，須加大柱斷面或提高 $f'_c$。

> 這是本題「依最新規範計算」唯一會改變**結論**的地方，作答時建議明寫假設：
> 「本解假設該角柱接頭位於**中間樓層**（柱延伸至接頭上方）；若為屋頂層接頭，
> 依 ACI 318-19 Table 18.8.4.3 之 $\gamma$ 應降為 $0.7\sqrt{f'_c}$（kgf 制 2.2），$\phi V_n = 112.6$ tf，將不通過。」

**318-19 這樣改的理由：** 屋頂層接頭上方沒有柱提供軸壓與圍束，斜壓桿無法閉合，
實驗顯示其剪力強度明顯低於中間層接頭——這是 318-14 → 318-19 在第 18 章最實質的修訂之一。
