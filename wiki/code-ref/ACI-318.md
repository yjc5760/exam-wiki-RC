對應考點：RC-U1-1 梁彎矩強度

| 條文 | 內容 | 關鍵值 |
|------|------|-------|

| §22.2.2.4.1 | $\beta_1 = 0.85$（f'c ≤ 28 MPa）；每增加 7 MPa 減 0.05，最小 0.65 | |
| §22.2.1.3 | 極限壓應變 $\varepsilon_{cu} = 0.003$ | |
| §21.2.1 | 受拉控制斷面 $\varepsilon_t \geq \varepsilon_{ty}+0.003$；φ = 0.9 | SD420 時 $= 0.005$ |
| §21.2.2 | 壓力控制斷面 $\varepsilon_t \leq \varepsilon_{ty}$；φ = 0.65（矩形箍）/ 0.75（螺旋箍） | $\varepsilon_{ty}=f_y/E_s$ |
| §21.2.2 | 過渡區 $\varepsilon_{ty} < \varepsilon_t < \varepsilon_{ty}+0.003$；φ 線性插值 | |
| §9.3.3.1 | 非預力梁（$P_u < 0.10f'_cA_g$）之最小淨拉應變 $\varepsilon_t \geq 0.004$ | 取代舊制 $\rho_{\max}=0.75\rho_b$ |

> ⚠ **拉力控制界限不是固定的 0.005。** ACI 318-19／土木401-112 寫的是 $\varepsilon_{ty}+0.003$，
> 對 SD420（$\varepsilon_{ty} = 4200/2.04\times10^6 = 0.002059$）習慣直接記成 0.005；
> 但**高強度鋼筋要重算**：SD690（$f_y = 6900$）的 $\varepsilon_{ty} = 0.003382$，界限是 **0.006382**。
> 本庫的 φ 過渡區公式一律用
> $\varphi = 0.65 + 0.25\dfrac{\varepsilon_t-\varepsilon_{ty}}{0.005-\varepsilon_{ty}}$（SD420 專用形式），
> 遇到高強度鋼筋題必須把分母換成 $0.003$。相關題：`RC-2024-1`（$f_y = 6900$，$\varepsilon_u = 0.004$）。

> **軸壓**以 $M_m=M_u-N_u\frac{4h-d}{8}$ 代 $M_u$（$V_ud/M_m$ 不受 1.0 限制），且上限改為
> $0.93\sqrt{f'_c}b_wd\sqrt{1+0.0284\frac{N_u}{A_g}}$——**$M_m\le0$ 時直接取此上限**（最常漏的一格）；

> 相關題：`RC-2014-3`（三種軸力對照，兩版差 −15%／−40%／+17%）、`RC-2020-2`（$d$ 偏移三條件）。
