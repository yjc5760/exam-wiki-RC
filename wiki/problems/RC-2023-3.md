# RC-2023-3 — 懸臂梁臨界剪力 7.425 tf 與扭力忽略門檻偏心量 e=10.4 cm

## 題幹摘要

矩形懸臂梁（$b = 35$ cm，$h = 60$ cm，$d = 53$ cm，跨度 3.5 m），閉合箍筋與縱向鋼筋均為 D13，承受偏心垂直均佈載重 $W_u = 2.5$ tf/m（偏心量 $e$），$f'_c = 280$ kgf/cm²，$f_y = 4200$ kgf/cm²，$\phi = 0.75$。原卷指定土木 401-110。（一）求斷面最大設計剪力 $V_u$；（二）求可忽略扭力的臨界斷面最大偏心量 $e_{\max}$。

## 核心考點

- 懸臂梁臨界斷面：逐條驗 $d$ 偏移三條件（本題三條均成立）→ 距**固定端** $d$ 處，$V_u = W_u(L-d)$
- 扭力忽略條件：$T_u < \phi T_{th}$，$T_{th} = T_{cr}/4$
- $A_{cp}$、$p_{cp}$ 用斷面**外輪廓**（不是箍筋中心線的 $A_{oh}$、$p_h$）
- 偏心 UDL：$T(x) = W_ue(L-x)$、$V(x) = W_u(L-x)$ → $T = V\cdot e$ **對所有截面成立**，故 $e_{\max}$ 是全梁通用限制值
- $T_{th}$ 公式是 SI 制（MPa, mm, N·mm）；kgf 制等效係數為 **0.265**（$T_{cr}$ 為 1.06）

## 解題關鍵步驟

1. $d$ 偏移三條件：(a) 固定端反力向上、端區受壓 ✓ (b) 載重自頂面施加 ✓ (c) 區間無集中載重 ✓ → 臨界斷面距固定端 $d = 53$ cm
2. $V_u = 2.5\times(3.5-0.53) = \mathbf{7.425}$ tf（固定端面為 8.75 tf，$d$ 偏移折減 15.1%）
3. 驗核：$V_c = 0.53\sqrt{280}\times35\times53 = 16{,}451$ kgf $= 16.45$ tf；$\phi V_c = 12{,}338$ kgf $= 12.34$ tf $> V_u$ ✓；$0.5\phi V_c = 6.17 < V_u$ → **需最小箍筋**（這就是題目給 D13 閉合箍筋的理由）
4. $A_{cp} = 35\times60 = 2{,}100$ cm²，$p_{cp} = 2(35+60) = 190$ cm
5. SI 制：$T_{th} = \frac{\sqrt{27.46}}{12}\times\frac{(2.1\times10^5)^2}{1.9\times10^3} = 1.0136\times10^7$ N·mm $= 103{,}354$ kgf·cm
   kgf 制驗算：$0.265\times16.733\times23{,}211 = 102{,}920$ kgf·cm（差 0.4%）
6. $\phi T_{th} = 0.75\times103{,}354 = 77{,}515$ kgf·cm $= \mathbf{0.775}$ tf·m
7. $e_{\max} = 77{,}515/7{,}425 = \mathbf{10.44}$ cm

## 用到的公式

$$V_u = W_u(L - d) \quad (\text{懸臂梁臨界斷面，}d\text{ 偏移三條件成立時})$$

$$T_{th} = \frac{\sqrt{f'_c}}{12}\cdot\frac{A_{cp}^2}{p_{cp}}\ \text{(SI: MPa, mm, N·mm)}\quad\equiv\quad 0.265\sqrt{f'_c}\cdot\frac{A_{cp}^2}{p_{cp}}\ \text{(kgf·cm, kgf/cm}^2\text{, cm)}$$

$$A_{cp} = b \times h,\qquad p_{cp} = 2(b + h)$$

$$T_u = V_u \times e \leq \phi T_{th} \implies e_\text{max} = \frac{\phi T_{th}}{V_u}$$

## 涉及陷阱

- **兩個單位陷阱，踩一個就整題錯：**
  ① 把 kgf/cm² 與 cm 直接代進 SI 式 → $T_{th} = 32{,}363$ kgf·cm，**低估 3.77 倍**（$e_{\max}$ 變 3.3 cm）。
  ② $77{,}515$ kgf·cm $= \mathbf{0.775}$ tf·m，不是 7.75 tf·m（$1$ tf·m $= 10^5$ kgf·cm）。
- **題意歧義「所能承受」：** 讀法 A（本解主線）＝臨界斷面**所受**設計剪力 7.425 tf → $e_{\max} = 10.4$ cm；讀法 B ＝斷面剪力**容量** $5\phi V_c = 61.7$ tf → $e_{\max} = 1.26$ cm。採 A 的理由：第二小題需要臨界斷面的剪力值，且讀法 B 會讓題給的 $W_u = 2.5$ tf/m 完全用不到。**作答時兩個都寫、註明理由最安全**（可比對 [[RC-2020-2]] 小題(三)「所能抵抗」確為容量題，句型幾乎相同）。
- 懸臂梁臨界斷面距**固定端** $d$ 處，非距自由端；且判準是三條件而非構件名稱。
- $A_{cp}$ 是全斷面外輪廓面積，非箍筋圍合面積 $A_{oh}$（後者更小）。
- $\phi = 0.75$：扭力折減係數同剪力。
- $T_u = V_u\times e$，加大偏心即加大扭矩；此比例關係與 $x$ 無關。

## 依最新規範對照

原卷指定的土木 401-110 本身即以 ACI 318-19 為藍本，故**兩版完全一致**：$d$ 偏移條件（§9.4.3.2）、$V_c$（Table 22.5.5.1，$N_u = 0$ 時同為 $0.53\lambda\sqrt{f'_c}b_wd$）、$T_{th}$（Table 22.7.4.1(a)）、$A_{v,\min}$（§9.6.3.4）、$V_{s,\max}$（§22.5.1.2）均無變動 → **答案不變：7.425 tf／10.4 cm**。
唯一要留意：若斷面**未**配置最小剪力筋，318-19 的 $V_c$ 須改用 $2.12\lambda_s\lambda\rho_w^{1/3}\sqrt{f'_c}b_wd$ 並乘尺寸效應係數 $\lambda_s \le 1$；本題有 D13 閉合箍筋（$A_v = 2.54 \gg A_{v,\min} = 0.44$ @ $s=15$）故不觸發。

## 若 $e > 10.4$ cm

須做完整扭力設計：改用 $A_{oh}$、$A_o \approx 0.85A_{oh}$，算扭力箍筋 $A_t/s$ 與扭力縱筋 $A_l$，與剪力箍筋**相加**（$A_v/s + 2A_t/s$），並檢核組合應力上限 $\sqrt{(V_u/b_wd)^2+(T_up_h/1.7A_{oh}^2)^2} \le \phi(V_c/b_wd + 2.12\sqrt{f'_c})$。這正是規範設門檻的價值：門檻以下省下大量計算。
