# RC-2009-3 — 深梁 STM：a=50 cm、θ=45°，Pmax=127.5 tf 由斜壓桿控制

**來源：** 結構工程技師高考 · 鋼筋混凝土設計與預力 · 第3題
**考年：** 2009（民國98年）
**主分類：** [[RC-U2-1]] RC 剪力強度分析與設計
**副分類：** 無
**設計法：** USD強度設計法（STM 壓拉桿模式）
**標籤：** `壓拉桿模式` `STM` `深梁` `兩點載重` `拉力桿` `壓力桿` `節點強度` `CCT節點` `CCC節點` `βs` `βn` `瓶形壓桿` `破壞模式` `尺寸鏈判讀` `45度壓桿`
**驗證狀態：** ⏳ unverified（2026-08-22 XCHECK 已比對原卷尺寸鏈並全面重算幾何與答案，仍待人工複核）

## 題幹摘要

兩點對稱載重簡支深梁，$b=20$ cm，$h=70$ cm，全長 170 cm；6-D19（$A_s=17.22$ cm²），$f'_c=250$ kgf/cm²，$f_y=4200$ kgf/cm²，承壓鈑 $l_b=20$ cm，純彎區水平壓桿寬 20 cm（題給），腹筋符合 ACI，$\phi=1.0$（不考慮強度折減）。

**原卷底部尺寸鏈為 20｜30｜20｜30｜20｜30｜20 = 170 cm**，四段 20 cm 是四塊鈑（左支承、左載重、右載重、右支承），中央 30 cm 標註「純彎區」。故支承鈑中心 10／160、載重鈑中心 60／110 → **支承跨度 $L=150$ cm、剪力跨 $a=50$ cm、$\theta=45°$**。

## 核心考點

- 深梁判定：$a/d = 50/60 = 0.83 < 2$；淨跨/$h = 130/70 = 1.86 < 4$ → 適用 STM
- 力臂 $z = h - h_c/2 - h_t/2 = 70-10-10 = 50$ cm；$\tan\theta = 50/50 = 1 \Rightarrow \theta = 45°$（$>25°$ ✓）
- 桿件力：$T = C_{\text{top}} = 0.5P$；$F_{\text{diag}} = 0.7071P$
- 壓桿有效強度 $f_{ce} = 0.85\beta_sf'_c$：斜向瓶形（有腹筋）$\beta_s = 0.75$；純彎區棱柱／邊界壓桿 $\beta_s = 1.0$
- 節點 $f_{ce} = 0.85\beta_nf'_c$：支承 CCT $\beta_n = 0.80$、載重點 CCC $\beta_n = 1.0$，且須**分三面驗核**
- 最小值決定 $P_{\max}$，並直接指出破壞模式

## 解題關鍵步驟

1. 由尺寸鏈定位四塊鈑 → $L = 150$ cm、$a = 50$ cm
2. $z = 50$ cm、$\theta = 45°$、$\sin\theta = \cos\theta = 0.7071$
3. 桿件力：$T = (P/2)(a/z) = 0.5P$；$F_{\text{diag}} = (P/2)/\sin45° = 0.7071P$
4. 拉力桿：$A_sf_y = 17.22\times4200 = 72{,}324$ kgf → $P \le 144.6$ tf
5. 純彎區水平壓桿（$\beta_s=1.0$）：$212.5\times400 = 85{,}000$ kgf → $P \le 170.0$ tf
6. 斜壓桿（瓶形 $\beta_s=0.75$）：$w_s = 20(0.7071)+20(0.7071) = 28.28$ cm，$A_{cs} = 565.7$ cm²，$f_{ce} = 159.375$，$F_{ns} = 90{,}156$ kgf → **$P \le 127.5$ tf ← 控制**
7. CCT 節點（$f_{ce}=170$）承壓面／背面／斜壓桿面 → 三面**同為 $P \le 136.0$ tf**（45° 幾何的必然結果，可當驗算）
8. CCC 節點（$f_{ce}=212.5$）三面 → 同為 $P \le 170.0$ tf
9. 拉力桿寬檢核：$w_t = 63{,}750/(170\times20) = 18.75 \le h_t = 20$ cm ✓

$$\boxed{P_{\max} = 127.5\ \text{tf}\ \text{（斜向瓶形壓桿壓碎／劈裂控制，脆性破壞）}}$$

破壞順序：斜壓桿 127.5 → CCT 節點 136.0（僅高 6.7%）→ 拉力桿降伏 144.6 → CCC 節點與水平壓桿 170.0。
**改善建議：** 承壓鈑由 20 加大到 30 cm，$w_s$ 增至 35.4 cm，斜壓桿升至 159.4 tf、CCT 節點升至 170 tf，控制項即轉為拉力桿降伏（144.6 tf，延性）。

## 用到的公式

- 幾何：$z = h - h_c/2 - h_t/2$，$\tan\theta = z/a$
- 桿件力：$T = (P/2)(a/z)$，$F_{\text{diag}} = (P/2)/\sin\theta$
- 壓桿有效強度：$f_{ce} = 0.85\beta_sf'_c$，$F_{ns} = f_{ce}A_{cs}$
- 節點強度：$\sigma_{\text{face}} \le f_{ce} = 0.85\beta_nf'_c$
- 壓桿寬：$w_s = l_b\sin\theta + h_{\text{node}}\cos\theta$
- 拉力桿強度：$F_{nt} = A_sf_y$；拉力桿寬需求 $w_t = T/(f_{ce}b) \le h_t$

## 涉及陷阱

- **尺寸鏈判讀（最大風險）：** 七段鏈中四段 20 cm 是鈑寬、三段 30 cm 是淨距。若誤讀成「支承至載重 = 30、純彎區 = 20」，$\theta$ 會變成 59°、$T = 0.3P$、$F_{\text{diag}} = 0.583P$，$P_{\max}$ 變 136.0 tf 且控制項跳到 CCT 節點。判準：**「純彎區」標註在中央 30 cm 上，而純彎區必在兩載重鈑之間**；且題目另給「承壓鈑…良好接觸」暗示 $l_b = 20$ cm 是要用到的量。
- $\beta_s$ 按桿件類型選：斜向瓶形 0.75（有腹筋），純彎區棱柱／邊界壓桿 1.0，不可一律 0.75。
- CCT vs CCC：支承端含一條拉桿 → CCT（0.80）；載重點全壓 → CCC（1.0）。
- 節點須**分面**驗核（承壓面、背面／拉桿面、斜壓桿面），只驗承壓面論述不完整。
- 同一斜壓桿有兩個限制（桿身 $\beta_s = 0.75$ 與節點面 $\beta_n = 0.80$），取小 → 桿身控制。
- 壓桿寬要算投影，不是直接用承壓鈑尺寸。

## 依最新規範對照

ACI 318-19 第 23 章大幅改寫，有效強度式增列**圍束修正係數 $\beta_c$**：$f_{ce} = 0.85\beta_c\beta_sf'_c$（壓桿）／$0.85\beta_c\beta_nf'_c$（節點）。

| 項目 | ACI 318-14（主線） | ACI 318-19 | 本題影響 |
|------|:---:|:---:|:---:|
| 斜壓桿 | 瓶形＋腹筋 = 0.75 | **內部壓桿**＋符合 §23.5 = 0.75 | 不變 |
| 水平壓桿 | 棱柱形 = 1.0 | **邊界壓桿** = 1.0 | 不變 |
| 無腹筋時 | $0.60\lambda$ | **0.4**（加重懲罰） | 本題不適用 |
| 節點 $\beta_n$ | CCC 1.0／CCT 0.8／CTT 0.6 | 相同 | 不變 |
| $\beta_c$ | 無此係數 | 1.0，或 $\sqrt{A_2/A_1}\le2.0$ | 鈑寬＝梁寬，無圍束 → 1.0 |
| $\phi$ | 0.75 | 0.75 | 題目指定 1.0 |
| **$P_{\max}$** | **127.5 tf** | **127.5 tf（不變）** | — |

術語要換：318-19 把「棱柱形／瓶形」改成「**邊界壓桿／內部壓桿**」。若計入 $\phi = 0.75$，$\phi P_{\max} = 95.6$ tf。
