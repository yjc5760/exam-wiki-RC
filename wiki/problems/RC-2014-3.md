# RC-2014-3 — 軸力影響 Vc：規範三條路徑分流（無軸力 18.75／軸壓 32.40／軸拉 10.57 tf）

**來源：** 結構工程技師高考 · 鋼筋混凝土設計與預力 · 第3題

## 題幹摘要

簡支矩形梁 $L=5$ m，$b=30$ cm，$d=60$ cm，$h=70$ cm，$A_s=3$-D32（$=24.42$ cm²）；$f'_c=280$ kgf/cm²，$w_u=5$ tf/m（不計自重）。在三種軸力（無、$N_u=+25$ tf 壓、$N_u=-25$ tf 拉）下，求臨界斷面（距支承面 $d$ 處）之**最大** $V_c$。原卷指定土木 401-100，並附上 $V_c$ 簡化式、詳細式與 $M_m$ 公式。

## 核心考點

**規範對三種軸力狀態各有一條獨立路徑，必須先分流再代值：**

| 軸力狀態 | 規範路徑 | 本題答案 |
|---------|---------|:---:|
| 無軸力 | 詳細式，$V_ud/M_u \le 1.0$、$V_c \le 0.93\sqrt{f'_c}b_wd$ | **18.75 tf** |
| 軸壓 | 以 $M_m$ 代 $M_u$（$V_ud/M_m$ 不受 1.0 限制）；**上限改為** $0.93\sqrt{f'_c}b_wd\sqrt{1+0.0284N_u/A_g}$；$M_m<0$ 時直接取該上限 | **32.40 tf** |
| 軸拉 | **另有專用式** $V_c = 0.53(1+0.0284N_u/A_g)\sqrt{f'_c}b_wd$（$N_u$ 取負） | **10.57 tf** |

- 物理直覺：軸壓抑制斜裂縫（$V_c$ 最高）；軸拉促進開裂（$V_c$ 最低）。趨勢 32.40 > 18.75 > 10.57 ✓
- $M_m$ 的條文只適用「承受軸壓力之構材」，軸拉不可硬套
- $V_c$ 歸零點：軸拉折減因子為 0 時，即 $N_u/A_g = -35.2$ kgf/cm²（本斷面 $N_u = -73.9$ tf）

## 解題關鍵步驟

1. 共用：$\rho_w = 24.42/(30\times60) = 0.01357$、$A_g = 2{,}100$ cm²、$b_wd = 1{,}800$ cm²
2. 臨界斷面（距支承面 $d=60$ cm）：$R = 12{,}500$ kgf，$V_u = 12{,}500-50\times60 = 9{,}500$ kgf，$M_u = 660{,}000$ kgf·cm，$V_ud/M_u = 0.8636 \le 1.0$ ✓
3. Case 1：$V_c = (8.366+175\times0.01357\times0.8636)\times1800 = 18{,}751$ kgf $= 18.75$ tf（$< 28.01$ 上限 ✓）
4. Case 2：$M_m = 660{,}000-25{,}000\times27.5 = -27{,}500 < 0$ → 取軸壓加強上限
   $V_c = 0.93\sqrt{280}\times1800\times\sqrt{1+0.0284\times11.905} = 28{,}011\times1.1568 = 32{,}402$ kgf $= 32.40$ tf
5. Case 3：$V_c = 0.53\times(1-0.0284\times11.905)\times\sqrt{280}\times1800 = 0.53\times0.6619\times16.733\times1800 = 10{,}566$ kgf $= 10.57$ tf

## 用到的公式

- 詳細 $V_c$：$V_c=\left[0.50\sqrt{f'_c}+175\rho_w\dfrac{V_ud}{M_m}\right]b_wd$
- 基本上限：$V_c \le 0.93\sqrt{f'_c}b_wd$
- 等效彎矩：$M_m = M_u - N_u\dfrac{4h-d}{8}$（$N_u$：壓正拉負）
- **軸壓加強上限：** $V_{c,\max} = 0.93\sqrt{f'_c}b_wd\sqrt{1+0.0284\dfrac{N_u}{A_g}}$（$M_m \le 0$ 時直接取此值）
- **軸拉專用式：** $V_c = 0.53\left(1+0.0284\dfrac{N_u}{A_g}\right)\sqrt{f'_c}b_wd$

> 係數 0.0284 的來歷：ACI 英制式為 $\sqrt{1+0.002N_u/A_g}$（$N_u/A_g$ 以 psi 代），$0.002\times14.223 = 0.0284$。

## 涉及陷阱

- **軸壓時上限忘了乘 $\sqrt{1+0.0284N_u/A_g} = 1.157$**：直接寫 28.01 tf，**低估 13.5%**。軸壓不只放大詳細式的分子，連天花板都一起抬高。
- **軸拉硬套 $M_m$**：$M_m$ 條文限「承受軸壓力之構材」。若代入得 16.87 tf，比無軸拉的簡化式 15.96 tf 還高，物理上站不住腳（此讀法已在正本 §4 Case 3 留檔）。
- $N_u$ 符號：壓力為正（$+25$ tf），拉力為負（$-25$ tf），$N_u/A_g$ 以 kgf/cm² 代入。
- $M_m \le 0$ 時不可繼續代詳細式（會得 $V_c = -38$ tf）。
- 忘記 $V_ud/M_u \le 1.0$：無軸力／軸拉時要檢核；**軸壓（用 $M_m$）時此限制解除**。

## 依最新規範對照

ACI 318-19／土木 401-112 全面改寫 $V_c$（Table 22.5.5.1），**$M_m$ 等效彎矩法與軸拉專用式一併廢除**，改用單一線性軸力項：

$$V_c = \max\left\{\left[0.53\lambda\sqrt{f'_c}+\frac{N_u}{6A_g}\right]b_wd,\ \left[2.12\lambda\rho_w^{1/3}\sqrt{f'_c}+\frac{N_u}{6A_g}\right]b_wd\right\},\quad \frac{N_u}{6A_g}\le0.05f'_c,\ V_c\le1.325\lambda\sqrt{f'_c}b_wd$$

| 案例 | 土木 401-100（原卷指定，主線） | 土木 401-112／ACI 318-19 | 差異 |
|------|:---:|:---:|:---:|
| 無軸力 | 18.75 tf | **15.96 tf** | −14.9% |
| 軸壓 +25 tf | 32.40 tf | **19.53 tf** | −39.7% |
| 軸拉 −25 tf | 10.57 tf | **12.39 tf** | +17.2% |

觀念差異：318-19 取消 $\rho_w\cdot V_ud/M_u$ 交互作用（改用 $\rho_w^{1/3}$、不再需要 $M_u$），軸力效應由「非線性 $M_m$ ＋ 開根號上限」改成**線性 $N_u/(6A_g)$**，壓拉共用一式；因此軸壓加成溫和許多（+22% 而非 +73%）、軸拉折減亦然（−22% 而非 −34%）。
