## 題幹摘要

承 [[RC-2017-1]] 加大後柱（$40\times70$ cm，新混凝土翼板各 $15\times40$ cm），介面已粗糙化。求「新舊混凝土介面在**彎矩最大時**需承受多少剪力」，並設計植筋確保介面不致分離。植筋 D19（$f_y = 4{,}200$ kgf/cm²，$A_b = 3.871$ cm²，原卷給定值）。

> 原卷自身筆誤留檔：D19 實際 $A_b = 2.865$ cm²；3.871 cm² 是 D22。本解依原卷數值作答並附實際 D19 的支數。

## 核心考點

- **介面剪力＝新混凝土翼板在該斷面承擔的全部軸向力**（力流連續性）：由零彎矩斷面累積到最大彎矩斷面的增量，全部須經介面傳遞
- 必須與第一題**同一組假設**：Q1 用雙折線分區積分，翼板應力不是常數
  - $c_b = 37.66$ cm，轉折點 $x_{\text{peak}} = c_b/3 = 12.55$ cm **落在翼板（0～15 cm）之內**
  - 翼板應力：$x=0$ → 168、$x=12.55$ → 210（峰值）、$x=15$ → 189.5 kgf/cm²
  - $C_{c,\text{wing}} = 94{,}896 + 19{,}558 = 114{,}454$ kgf $= 114.5$ tf
- **壓力鋼筋 4-D25 在 $d' = 6.5 < t_w = 15$ cm，整支埋在新混凝土內**，其 $C'_s = 81.3$ tf 同樣須跨越介面
- $V_u = 114.5 + 81.3 = 195.7$ tf（每個介面）
- 摩擦剪力法 $\phi V_n = \phi\mu A_{vf}f_y$：$\phi = 0.75$、$\mu = 1.0$（粗糙化）→ $A_{vf} = 62.14$ cm² → **17 支 D19**
- $V_n$ 介面應力上限（粗糙面）$\min(0.2f'_c,\ 3.3+0.08f'_c\,\text{MPa},\ 11\,\text{MPa}) = 42.0$ kgf/cm² → $L_{\min} = 155.4$ cm ← **實際控制設計的條件**

## 解題關鍵步驟

1. 取 Q1 平衡點：$\varepsilon_y = 0.002059$，$c_b = 0.003/(0.003+0.002059)\times63.5 = 37.66$ cm，$x_{\text{peak}} = 12.55$ cm
2. 翼板混凝土分段積分：
   $C_1 = \frac{168+210}{2}\times12.552\times40 = 94{,}896$ kgf；$C_2 = \frac{210+189.5}{2}\times2.448\times40 = 19{,}558$ kgf
   → $C_{c,\text{wing}} = 114{,}454$ kgf（均勻 $0.8f'_c$ 假設只有 100,800，低估 12.0%）
3. 翼板內壓力鋼筋：$C'_s = (4200-189.75)\times20.27 = 81{,}288$ kgf
4. $V_u = 114{,}454+81{,}288 = 195{,}742$ kgf $= 195.7$ tf；拉力側 $T_s = 85.1$ tf（不控制，但**彎矩反向後同為 195.7**，兩側均按大值設計）
5. $A_{vf} = 195{,}742/(0.75\times1.0\times4200) = 62.14$ cm²；$n = 62.14/3.871 = 16.05$ → **17 支 D19**（實配 65.81 cm² ✓）
6. $V_n = 195{,}742/0.75 = 260{,}989$ kgf；$A_c \ge 260{,}989/42.0 = 6{,}214$ cm² → $L_{\min} = 6{,}214/40 = 155.4$ cm → D19 @ 9 cm
7. 錨定：直線伸展長度需 $\approx105$ cm，兩端都不足 → 舊柱側化學植筋（$h_{ef} = 10\sim15d_b = 19\sim29$ cm，可用 33.5 cm ✓）；新混凝土側 90° 彎鉤（$12d_b = 22.9$ cm）或頭錨鋼筋

## 用到的公式

- 介面設計剪力：$V_u = C_{c,\text{wing}} + C'_s = b\!\int_0^{t_w}\!f_c(x)dx + (f_y - f_c@d')A'_s$
- 摩擦剪力法：$\phi V_n = \phi\,\mu\,A_{vf}\,f_y \ge V_u$
- $\mu$ 分級：一體澆置 $1.4\lambda$、故意粗糙化 $1.0\lambda$、未粗糙化 $0.6\lambda$、對型鋼 $0.7\lambda$
- $V_n$ 上限（粗糙面）：$\min(0.2f'_c,\ 3.3+0.08f'_c\,[\text{MPa}],\ 11\,[\text{MPa}])A_c$
- 最小分布長度：$L_{\min} = V_n/(0.2f'_c\,b)$

## 涉及陷阱

- **假設翼板應力均勻 $0.8f'_c$**：與 Q1 的雙折線自相矛盾。雙折線峰值 $1.0f'_c$ 就在翼板內部（$x = 12.55 < 15$），翼板應力先升後降，均勻假設低估 12%。
- **漏算落在翼板內的壓力鋼筋力**：$d' = 6.5 < 15$，$C'_s = 81.3$ tf 也必須過介面（漏算低估 42%）。
- $\mu$ 值取錯：粗糙化面 $\mu = 1.0$，**不可用一體澆置的 1.4**（誤用會少配 29% 植筋）。
- $\phi$ 用 0.65 或 0.9：摩擦剪力屬剪力類，$\phi = 0.75$。
- **$V_n$ 上限引用錯行：** 「5.5 MPa」那一行是**未粗糙化／對型鋼**才用；粗糙面用 $\min(0.2f'_c,\ 3.3+0.08f'_c,\ 11\,\text{MPa})$。
- **只設計壓力側介面**：耐震評估後加大的柱，地震彎矩會反向，兩側介面都要按 195.7 tf 設計。
- **錨定當成鋼筋伸展長度**：D19 需 $\approx105$ cm，舊柱只有 33.5 cm → 必須走化學植筋（ACI 318 第 17 章）或機械錨定，並檢核群錨效應。
- 植筋方向須**垂直穿越介面**，平行則不提供摩擦剪力貢獻。

## 三種介面剪力定義對照

| 定義 | $V_u$ | $A_{vf}$ | D19 支數 | $L_{\min}$ |
|------|:---:|:---:|:---:|:---:|
| 均勻 $0.8f'_c\times A_{\text{wing}}$ | 100.8 tf | 32.0 cm² | 9 | 80 cm |
| 雙折線積分，只計混凝土 | 114.5 tf | 36.3 cm² | 10 | 91 cm |
| **雙折線積分 ＋ 壓力鋼筋（本解）** | **195.7 tf** | **62.1 cm²** | **17** | **155 cm** |

（若改用實際 D19 面積 2.865 cm²，主線需 22 支。）

## 依最新規範對照

摩擦剪力法是 ACI 318 少數幾乎未改動的章節：$V_n = \mu A_{vf}f_y$（§22.9.4.2）、$\mu$ 分級（Table 22.9.4.2）、$V_n$ 上限（Table 22.9.4.4）、$\phi = 0.75$ 在土木 401-100 與 401-112／ACI 318-19 **完全相同**，故 **答案不變（195.7 tf／17 支／$L_{\min}$ 155 cm）**。
318-19 明訂摩擦剪力的 $f_y \le 420$ MPa（§20.2.2.4，本題恰在上限）；§22.9.4.3 允許把**垂直於介面的**永久淨壓力計入夾緊力——本題軸力平行介面，不可計入。

## 工程結論（最有價值的一段）

介面剪力的可用傳遞長度大約是柱淨高的一半（反曲點到柱端）。柱淨高 300 cm 時可用 $\approx150$ cm，而需求 $L_{\min} = 155.4$ cm——**幾乎壓線**。也就是本題真正被卡住的是**混凝土介面應力上限 $0.2f'_cA_c$**，不是植筋量：多打植筋完全無效，只能加大介面面積（改四面包覆使介面總寬度增加）或提高新混凝土 $f'_c$。
