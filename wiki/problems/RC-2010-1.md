# RC-2010-1 — 圓形螺旋柱：圍束增益剛好打平蓋層損失，Pu ≈ Py 零餘裕、ρs 不符規範

## 題幹摘要

圓形螺旋柱 D=75 cm，Dc=68 cm（螺旋筋外緣），12-#10（Ast=98.04 cm²），#4 螺旋筋（Asp=1.27 cm²）；f'c=350 kgf/cm²，fy=4200 kgf/cm²。求降伏軸力 Py（蓋層破壞，全斷面）與圍束後極限軸力 Pu，並驗核 ρs。

⚠ **螺距 s 題目未給**（原卷圖上無間距標註），本解假設 s=10 cm。結果：Py=1697 tf，ρs=0.00747 < ρsmin=0.00812（短少 8%，不符規範），f'cc=414.3 kgf/cm²，**Pu=1697 tf ≈ Py（差 0.02%，零餘裕）**；需 s ≤ 9.2 cm。

## 核心考點

- **Pu 的核心混凝土同樣要乘 0.85**：Pu = 0.85f'c(Ach−Ast) + 4.1fL·Ach + fyAst。漏掉 0.85 的寫法（Pu = f'cc(Ach−Ast)+fyAst）過不了 ρs=0 的檢驗——不配螺旋筋卻仍有 0.97Py，物理上不可能
- 0.85 的來源是「圓柱試體強度→構材內實際強度」的折減，**不是** Whitney 應力塊；記住這點才不會只在 Py 乘、在 Pu 漏
- ρs 的分母量到螺旋筋**外緣**（與 Ach 同基準）：ρs = 4Asp/(Dc·s) = 0.00747；用 Dc−db 會大 1.9% 且混用兩套基準
- 本題的實質內容：蓋層**損失** 0.85f'c(Ag−Ach) = 233.9 tf vs 圍束**補償** 4.1fL·Ach = 233.6 tf → 幾乎剛好打平
- ρsmin 係數 0.45 相對理論門檻 0.4146 有 8.6% 裕度，所以會出現「理論剛好夠、規範不夠」的縫隙——本題正落在裡面
- 螺旋柱 φ=0.75、上限係數 0.85，但那是「符合規定的螺旋柱」才享有；ρs 不足時嚴格說要退回橫箍柱的 0.80/0.65

## 解題關鍵步驟

1. Ag=π×37.5²=4417.9 cm²；Ach=π×34²=3631.7 cm²（量到螺旋筋外緣）；蓋層 Ag−Ach=786.2 cm²
2. Py=0.85×350×(4417.9−98.04)+4200×98.04=1,285,158+411,768=**1,696,926 kgf = 1697 tf**
3. ρs=4×1.27/(68×10)=5.08/680=**0.00747**；ρsmin=0.45×0.2165×0.08333=**0.00812** → 短少 8%，❌
4. 需縮小間距：s ≤ 4Asp/(ρsmin·Dc)=5.08/(0.00812×68)=**9.20 cm**（假設的 10 cm 偏大）
5. fL=0.00747×4200/2=**15.69** kgf/cm²；f'cc=350+4.1×15.69=**414.3** kgf/cm²
6. Pu=0.85f'c(Ach−Ast) + 4.1fL·Ach + fyAst = 1,051,258+233,589+411,768=**1,696,615 kgf = 1697 tf**
7. Pu/Py = 0.9998 → **實質打平、零餘裕**；與 ρs 不足的判定一致（不再是一個 ✅ 一個 ❌）
8. 取 s=9 cm 驗證：ρs=0.00830 > ρsmin ✓；fL=17.43；Pu=1,723 tf > Py ✓（餘裕 1.5%）

## 用到的公式

- 降伏軸力：$P_y = 0.85f'_c(A_g - A_{st}) + f_y A_{st}$
- 螺旋筋比：$\rho_s = \dfrac{4A_{sp}}{D_c\cdot s}$（$D_c$ 量到螺旋筋外緣，與 $A_{ch}$ 同基準）
- 最小螺旋筋比：$\rho_{s,\min} = 0.45\!\left(\dfrac{A_g}{A_{ch}}-1\right)\!\dfrac{f'_c}{f_{yt}}$
- 側向圍束壓力：$f_L = \rho_s f_{yt}/2$
- 圍束混凝土強度：$f'_{cc} = f'_c + 4.1f_L$
- 側向圍束壓力（半圓平衡）：$f_L = \dfrac{2A_{sp}f_{yt}}{D_c\cdot s} = \dfrac{\rho_s f_{yt}}{2}$
- 極限軸力：$P_u = 0.85f'_c(A_{ch} - A_{st}) + 4.1f_L A_{ch} + f_y A_{st}$
- 理論門檻（$P_u = P_y$）：$\rho_{s,\text{th}} = 0.4146(A_g/A_{ch}-1)f'_c/f_{yt}$

## 涉及陷阱

- **Pu 漏乘 0.85**（最嚴重）：檢驗法是把 ρs 設 0，若還有 0.97Py 就是漏了
- 把 Py 的 0.85 誤認成 Whitney 應力塊 → 會覺得 Pu 不必乘
- ρs 分母誤用 Dc−db，與量到外緣的 Ach 混用兩套基準（偏不保守 1.9%）
- Py 用全斷面（含蓋層），Pu 只用核心面積（蓋層已脫落）
- ρsmin 的計算：容易把 Ag/Ach−1 忘記減 1，或分子分母用錯
- 把「ρs 不足 ❌」與「Pu > Py ✅」同時寫出來卻不覺得矛盾——ρsmin 本來就是由 Pu ≥ Py 推導的
- 螺距若題目沒給，要明寫是假設，不能當成題給條件
