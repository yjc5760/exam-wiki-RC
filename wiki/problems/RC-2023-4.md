## 題幹摘要

簡支後拉預力混凝土單向版（$L = 10$ m，$h = 25$ cm，$d_p = 22$ cm），無握裹鋼絞線每根 $A_p = 1.47$ cm²（間距 20 cm），$f_{pu} = 19000$ kgf/cm²，$f_{se} = 11000$ kgf/cm²，$f'_c = 420$ kgf/cm²。求此單向版之計算撓曲強度 $M_n$（不乘 $\phi$）。原卷另有「普通具握裹鋼筋，間距 20 cm」與 $f_y=4200$ kgf/cm²，並強制依土木 401-110 作答。

**答案：$M_n = 22.5$ tf·m/m**（含 §7.6.2.3 強制之 $A_{s,\min}=0.004A_{ct}=1.00$ cm²/條帶）；僅計鋼絞線則為 18.5 tf·m/m。

## 核心考點

- 無握裹腱 vs. 有握裹腱：無握裹腱全長自由滑動，不能用截面應變相容，只能用 ACI 經驗公式
- **跨深比**（非「簡支 vs 懸臂」）決定 $f_{ps}$ 分支：$\ell/h = 1000/25 = 40 > 35$（$\ell/d_p=45.5$ 同結論）→ 分母 $300\rho_p$
- **公式與上限成套**：$\ell/h>35$ 用 $300\rho_p$ 配 $f_{se}+\mathbf{2100}$；$\ell/h\le35$ 用 $100\rho_p$ 配 $f_{se}+4200$。舊版本頁把 300 的公式配 4200 的上限，是混用兩分支
- 高強混凝土 $f'_c = 420 > 280$ kgf/cm² 需折減 $\beta_1 = 0.75$
- **無握裹腱單向版必配最小握裹鋼筋**：$A_{s,\min}=0.004A_{ct}$（§7.6.2.3 強制條文），其 $A_sf_y$ 是 $M_n$ 的一部分

## 解題關鍵步驟

1. 計算 $L/d_p = 1000/22 = 45.5 \geq 35$，選用簡支梁公式（分母 $300\rho_p$）
2. 計算配筋率 $\rho_p = A_p/(b \times d_p) = 1.47/(20 \times 22)$（以每根條帶分析）
3. 代入 $f_{ps} = f_{se} + 700 + f'_c/(300\rho_p)$，並驗算兩個上限
4. 計算 $\beta_1$（$f'_c = 420$ kgf/cm² > 280）：$\beta_1 = 0.85 - 0.05(420-280)/70 = 0.75$
5. $A_{ct} = b\,h/2 = 20\times12.5 = 250$ cm² → $A_{s,\min} = 0.004\times250 = 1.00$ cm²／20 cm 條帶
6. $T = A_pf_{ps} + A_sf_y = 17{,}815 + 4{,}200 = 22{,}015$ kgf；$a = T/(0.85f'_cb) = 3.083$ cm；$c = 4.111$ cm；$\varepsilon_t = 0.0131$（拉力控制）
7. $M_n = 22{,}015\times(22-1.542) = 450{,}390$ kgf·cm／條帶 $\times5 = \mathbf{22.5}$ tf·m/m
8. 對照（僅絞線）：$a = 2.495$、$M_n = 369{,}705\times5 = 18.5$ tf·m/m

## 用到的公式

$$\frac{\ell}{h} \le 35:\quad f_{ps} = f_{se} + 700 + \frac{f'_c}{100\rho_p} \;\le\; \min\!\left(f_{py},\, f_{se}+4200\right)$$

$$\frac{\ell}{h} > 35\ (\textbf{本題}):\quad f_{ps} = f_{se} + 700 + \frac{f'_c}{300\rho_p} \;\le\; \min\!\left(f_{py},\, f_{se}+\mathbf{2100}\right)$$

$$A_{s,\min} = 0.004\,A_{ct},\qquad A_{ct} = b\,h/2 \quad(\text{無握裹腱單向版，§7.6.2.3})$$

$$\beta_1 = 0.85 - 0.05 \cdot \frac{f'_c - 280}{70} \quad (f'_c > 280\text{ kgf/cm}^2)$$

$$a = \frac{A_p f_{ps} + A_s f_y}{0.85 f'_c b}$$

$$M_n = \left(A_p f_{ps} + A_s f_y\right)\!\left(d - \frac{a}{2}\right)\quad(d_p = d = 22\ \text{cm，故可合併力臂})$$

## 涉及陷阱

- **判準是跨深比，不是構材型式**：舊版本頁寫「簡支 vs 懸臂」是錯的，且「分母改 300」文義破碎，已全部改寫。
- **上限必須配對分支**：$\ell/h>35$ 是 $f_{se}+\mathbf{2100}=13{,}100$（本題 $f_{ps}=12{,}119$ 僅餘裕 7.5%）；誤用 $f_{se}+4200=15{,}200$ 會讓這個檢核形同虛設。
- **漏算最小握裹鋼筋**：題目給了 $f_y$ 又講明「兩者間距均為 20 cm」，就是要你算 $A_{s,\min}$；漏掉 $M_n$ 少 22%。
- 高強混凝土 $\beta_1$ 折減：$f'_c = 420$ 時 $\beta_1 = 0.75$，不是 0.85。
- 每根絞線分析單元：$A_p$ 和 $b$ 都以單根/20 cm 條帶計算，維持一致性。

## 依最新規範對照

原卷指定土木 401-110，其本身即以 ACI 318-19 為藍本，**與 401-112 之間本題相關條文完全未動**，
故「依最新規範計算」的答案與依原卷指定規範相同。要修的是舊版本頁**引錯的條文內容**：

| 項目 | 舊版本頁 | 土木 401-110／112＝ACI 318-19 | 影響 |
|---|---|---|---|
| $f_{ps}$ 分支判準 | 「簡支 vs. 懸臂」 | **跨深比 $\ell/h$**（§20.3.2.4.1） | 敘述錯，分支恰好選對 |
| $\ell/h>35$ 之上限 | $f_{se}+4200$ | $f_{se}+\mathbf{2100}$ | **依據錯**；12,119 < 13,100 故答案不變 |
| 單向版最小握裹鋼筋 | 「未給定，略過」 | **§7.6.2.3 強制** $A_{s,\min}=0.004A_{ct}$ | **主線 18.5 → 22.5 tf·m/m** |
| $\beta_1$（$f'_c=420$） | 0.75 | kgf 制同式；SI 制 0.756 | 差 0.8%，不變 |
| 若追問 $\phi M_n$ | — | $\varepsilon_t=0.0131>0.005$ → $\phi=0.9$ → $\phi M_n = 20.3$ tf·m/m | 延伸 |
