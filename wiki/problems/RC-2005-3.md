# RC-2005-3 — 角柱接頭剪力強度驗核 Vjh=131.5t 與 γ=3.2 外接頭

**來源：** 結構工程技師高考 · 鋼筋混凝土設計與預力 · 第3題
**考年：** 2005（民國94年）

## 題幹摘要

RC 構架樓層高 365 cm，柱斷面 60×60 cm，梁有效深度 d=70 cm，梁拉力筋 6-#8（As=30.42 cm²），f'c=280 kgf/cm²，fy=4200 kgf/cm²，梁柱同寬。驗核角柱接頭剪力強度。依耐震專章取梁鋼筋拉力 T=1.25As·fy=159705 kgf，Mpr=102.86 tf·m，柱剪力 Vcol=Mpr/H=28.18 tf，Vjh=T−Vcol=131.5 tf；接頭強度 φVn=0.85×3.2×√280×3600=163.8 tf ≥ 131.5 tf ✓（利用率 80%）。

## 核心考點

- 接頭水平剪力：Vjh=T−Vcol（柱剪力方向為減項，非加項）
- 梁鋼筋拉力取 $1.25f_y$（耐震專章 §18.8.2.1），不是 $f_y$
- 柱剪力由梁 Mpr 反推：接頭梁彎矩由上下柱各分擔一半 ⇒ Vcol=Mpr/H（不是 2Mpr/H）
- 角柱接頭分類：分析平面內單側梁 → 外接頭（other joint）→ γ=3.2（ACI 12 psi^1/2 換算）
- 有效接頭面積 Aj=bj×hc，bj=min(bw+hc, bw+2x) ≤ bc；梁柱同寬（x=0）取 bj=bc=60 cm

## 解題關鍵步驟

1. 梁鋼筋拉力（耐震 §18.8.2.1）：T=1.25×30.42×4200=159705 kgf
2. Whitney 應力塊：a=159705/(0.85×280×60)=159705/14280=11.18 cm
3. 梁可能彎矩強度：Mpr=159705×(70−5.59)=10286000 kgf·cm=102.86 tf·m
4. 柱剪力：接頭梁彎矩由上下柱各分擔一半（Mcol=51.43 tf·m），反曲點在樓層中高 ⇒ Vcol=(Mpr/2)/(H/2)=Mpr/H=10286000/365=28181 kgf=28.18 tf（檢查：Vcol×H=28.18×3.65=102.9 tf·m＝一個接頭的梁彎矩 ✓）
5. 接頭剪力需求：Vjh=T−Vcol=159705−28181=131524 kgf=131.5 tf
6. 接頭面積：bj=min(60+60, 60+0)=60 cm（≤bc=60）；Aj=60×60=3600 cm²
7. 接頭強度：φVn=0.85×3.2×√280×3600=163851 kgf=163.8 tf ≥ Vjh=131.5 tf ✓（利用率 80%，餘裕 20%）

## 用到的公式

- 梁拉力（耐震）：$T = 1.25A_s f_y$
- 柱剪力：$V_{col} = M_{pr}/H$（接頭梁彎矩由上下柱各半分擔，故不是 $2M_{pr}/H$）
- 接頭水平剪力：$V_{jh} = T - V_{col}$
- 有效接頭寬：$b_j = \min(b_w + h_c,\; b_w + 2x) \le b_c$
- 接頭剪力強度：$\phi V_n = \phi \gamma \sqrt{f'_c} A_j$（$\gamma=3.2$，kgf/cm² 制）

## 涉及陷阱

- Vjh≠T：必須減去柱剪力 Vcol；忽略 Vcol 會高估接頭剪力需求
- $V_{col}=2M/H$ 分子多算一倍：接頭處的梁彎矩由上下兩根柱分擔，正確為 $V_{col}=M_{pr}/H$
- $T$ 漏乘 1.25：接頭剪力檢核出自耐震專章，配套規定就是 $1.25f_y$（§18.8.2.1）
- γ 係數選取：角柱（外接頭）=3.2，T 形接頭=3.9（土木 401 印的值，非 4.0），十字形（內接頭）=5.3
- bj 的公式：梁與柱同寬時 bj=bc；若梁寬大於柱寬才受另一上限控制

- **中間樓層**（本解主線）：$\phi V_n = 0.85\times3.2\times\sqrt{280}\times3600 = 163.8$ tf $\ge V_{jh} = 131.5$ tf ✓ **通過**
- **屋頂層**：$\phi V_n = 0.85\times2.2\times\sqrt{280}\times3600 = \mathbf{112.6}$ tf $< 131.5$ tf ✗ **不通過（超出 17%）**
