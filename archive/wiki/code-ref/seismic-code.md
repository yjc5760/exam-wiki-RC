## 耐震設計核心原則

| 原則 | 目標 | 規範依據 |
|------|------|---------|
| **能力設計法** | 確保預期破壞模式（塑鉸於梁端）先於非預期（剪力破壞） | ACI 318 §18 |
| **強柱弱梁** | 柱彎矩容量 ≥ 梁彎矩容量 × 6/5 | ACI 318 §18.7.3 |
| **實際強度放大** | 以 1.25fy（可能強度）計算 Mpr 作為設計基礎 | ACI 318 §18.6.5 |
| **韌性詳細設計** | 密箍圍束、最大配筋率限制、接頭剪力強度 | ACI 318 §18.6–18.8 |

## 特殊矩形框架梁（SMF Beam）

### 縱向配筋限制（ACI 318 §18.6.3）

| 項目 | 規定 |
|------|------|
| 最大配筋率 | $\rho \leq 0.025$（ACI 318-19 §18.6.3.1） |
| 梁端正負彎矩強度比 | $M^+_{n,end} \geq 0.5 M^-_{n,end}$ |
| 梁全長正彎矩容量 | $M^+_n \geq 0.25 \max(M^-_n)$ |
| 最少兩根縱筋貫通梁全長（頂底各） | — |

### 設計剪力 Ve（ACI 318 §18.6.5.2）

$$V_e = \frac{M_{pr,l} + M_{pr,r}}{l_n} \pm \frac{w_u l_n}{2}$$

> $M_{pr}$ 以鋼筋可能降伏強度 $1.25f_y$ 計算（不含 φ 折減）

### 箍筋加密區（ACI 318 §18.6.4）

| 項目 | 規定 |
|------|------|
| 加密區長度（梁端） | $\geq 2h$（梁深的兩倍） |
| 加密區最大間距 | $\min\!\left(d/4,\; \mathbf{6d_b},\; \mathbf{150\ \text{mm}}\right)$（$6d_b$ 取**最小主撓曲筋**；Grade 550 改 $5d_b$）|
| 加密區外最大間距 | $d/2$（全梁，且須用耐震彎鉤肋筋，§18.6.4.6）|
| 第一道箍筋距支承面 | $\leq \mathbf{50}$ mm（**梁**的規定；柱是 $s_o/2$，勿互抄）|

> ⚠ **2026-08-22 勘誤：** 本表原寫 $\min(d/4,\,8d_b,\,24d_{sw},\,300\text{ mm})$，那是 **ACI 318-11** 的舊值。
> **318-14 起**已改為 $\min(d/4,\,6d_b,\,150\text{ mm})$（刪去 $24d_{sw}$ 一項）；土木 401-110／112 均採新制。
> 考 401-100 世代的舊題時可並寫兩制，但現行規範一律用新值。

### 密箍區以外仍受設計剪力包絡線控制

$V_c = 0$ **只適用密箍區內**；密箍區外雖可計入 $V_c$，但**設計剪力仍是同一條 $M_{pr}$ 包絡線**：

$$V_e(x) = \max\big(V_{e,\text{左}} - w_ux,\ V_{e,\text{右}} - w_u(\ell_n-x)\big),\qquad
\min_x V_e = \frac{M_{pr,l}+M_{pr,r}}{\ell_n}\ (\text{跨中})$$

**跨中不會只剩重力剪力 $w_u\ell_n/2$。** 見 [RC-2025-2](../problems/RC-2025-2.md)。

### $A_{v,\min}$（kgf/cm² 制，易與 SI 混用）

$$\frac{A_{v,\min}}{s} = \max\!\left(\frac{3.5\,b_w}{f_{yt}},\ \frac{0.2\sqrt{f'_c}\,b_w}{f_{yt}}\right)
\qquad(\text{SI 制才是 } 0.35\ \text{與}\ 0.062)$$

## 特殊矩形框架柱（SMF Column）

### 強柱弱梁驗算（ACI 318 §18.7.3.1）

$$\sum M_{nc} \geq \frac{6}{5} \sum M_{nb}$$

- $\sum M_{nc}$：節點處各柱彎矩強度之和（考慮軸力影響，取最小 φMn）
- $\sum M_{nb}$：節點處各梁 Mpr（1.25fy 計算）之和

### 圍束箍筋 Ash（ACI 318 §18.7.5.4）

ACI 318-19 Table 18.7.5.4 為**三式取大**（矩形箍）：

$$\frac{A_{sh}}{s\,b_c} \ \ge\ \max\left\{
\underbrace{0.3\frac{f'_c}{f_{yt}}\!\left(\frac{A_g}{A_{ch}}-1\right)}_{(d)},\quad
\underbrace{0.09\frac{f'_c}{f_{yt}}}_{(e)},\quad
\underbrace{0.2\,k_f k_n \frac{P_u}{f_{yt}A_{ch}}\Big/ b_c}_{(f)}
\right\}$$

| 項 | 適用時機 |
|---|---|
| (d)(e) | **恆須查** |
| **(f)** | 僅當 $P_u > 0.3A_gf'_c$ **或** $f'_c > 70$ MPa（$\approx 714$ kgf/cm²）時才須查 |

$$k_f = \frac{f'_c}{175}+0.6 \ \ge 1.0\ (\text{MPa 制}),\qquad k_n = \frac{n_\ell}{n_\ell-2}\ (n_\ell = \text{被橫向支撐之縱筋數})$$

> ⚠ **2026-08-22 補：** 舊版只列兩式（401-100／ACI 318-05 世代）。
> 第三式是 318-14 起新增、318-19 定案的**高軸壓／高強度混凝土**條款——
> 它與 $A_g/A_{ch}$ 無關，而與軸壓力直接相關，在大斷面高軸壓柱常成為控制項。

| 符號 | 說明 |
|------|------|
| $b_c$ | 圍束區箍筋包圍的混凝土核心寬度（至箍筋外緣） |
| $A_{ch}$ | 箍筋外緣圍成的面積 |
| $s$ | 箍筋間距 |

### 柱加密區長度與間距（ACI 318 §18.7.5.1、§18.7.5.3、§18.7.5.5）

$$l_o \ \ge\ \max\big(\text{柱斷面最大邊長},\ \ l_u/6,\ \ 450\ \text{mm}\big)$$

| 區域 | 最大間距 |
|---|---|
| **加密區 $l_o$ 內** | $s \le \min\!\big(\tfrac14 \text{柱最小邊},\ 6d_b,\ s_o\big)$，其中 $s_o = 10 + \dfrac{35-h_x}{3}$ cm，限 $10 \le s_o \le 15$ cm |
| **加密區以外** | $s \le \min\big(6d_b,\ 150\ \text{mm}\big)$（§18.7.5.5）——**$6d_b$ 不是單獨上限，150 mm 一定要一起查** |
| 第一支箍筋 | 距接頭面 $\le s_o/2$（**柱**的規定；梁是 50 mm） |
| 橫向支撐間距 | $h_x \le 350$ mm（§18.7.5.2） |
| 繫筋彎鉤 | 一端 $135°$、另一端可 $90°$，但相鄰層之 $90°$ 端須交錯（§18.7.5.2(f)） |

### 柱設計剪力（ACI 318 §18.7.6.1）

**路徑一（柱本身的 $M_{pr}$）：**

$$V_e = \frac{M_{pr,top}^{col} + M_{pr,bot}^{col}}{l_u}$$

**路徑二（強柱弱梁下由梁 $M_{pr}$ 經接頭反推——考試最常用，且 $V_e$ 不必超過此值）：**

$$\Sigma M_{col} = \Sigma M_{pr,\text{beam}}\ \text{（於各接頭）}
\ \xrightarrow{\ \text{上下柱依勁度分擔}\ }\
V_e = \frac{\Sigma M_{pr,\text{beam}}}{l_u}$$

> ⚠ **路徑二的分子是「一個接頭」的梁 $M_{pr}$ 總和，不是上下兩個接頭相加。**
> 上下柱端各分到 $\Sigma M_{pr,\text{beam}}/2$，兩者相加後除以 $l_u$ 恰好回到 $\Sigma M_{pr,\text{beam}}/l_u$。
> 寫成 $2\Sigma M/l_u$ 會**高估一倍**——見 [RC-2012-3](../problems/RC-2012-3.md)。

### 柱 $V_c = 0$ 條件（§18.7.6.2.1）

$$\text{(a) } V_e \ge \tfrac12 V_{e,\max}\ (\text{於 } l_o \text{ 內})
\qquad\text{且}\qquad
\text{(b) } P_u < \frac{A_g f'_c}{20}$$

## 梁柱接頭（ACI 318 §18.8）

### 水平剪力計算

$$V_{jh} = T_{top} + T_{bot} - V_{col}$$

- 內跨（雙側梁）：$T_{bot}$ 需計入（反向地震時底筋受拉）
- 外接頭：$T_{bot}$ 不計（或需依彎矩方向判斷）
- $T = 1.25 f_y A_s$（可能強度）

### 接頭剪力強度（ACI 318 §18.8.4）

$$\phi V_{jh,n} = \phi \gamma \sqrt{f'_c} A_j, \quad \phi = 0.85$$

**ACI 318-19 Table 18.8.4.3：依「柱是否延伸至接頭上方」分兩組共六檔**

| 接頭圍束情形 | 柱**延伸**至接頭上方<br>MPa ／ kgf/cm² | 柱**未延伸**（屋頂層）<br>MPa ／ kgf/cm² |
|---|:---:|:---:|
| 四面有梁（內接頭／十字形） | 1.7 ／ **5.3** | 1.5 ／ **4.7** |
| 三面或一雙**對**面有梁（T 形） | 1.2 ／ **3.9** | 1.0 ／ **3.2** |
| 其他（外接頭、角接頭） | 1.0 ／ **3.2** | 0.7 ／ **2.2** |

> ⚠ **2026-08-22 兩處更正：** ① 中間檔土木 401 與歷年考卷原文印 **3.9**（不是 4.0；4.0 是舊 psi 制 15 的換算）；
> ② **屋頂層那一組是 318-19 新增**，角柱由 3.2 降到 2.2（−31%），常直接翻轉判定——見 [RC-2005-3](../problems/RC-2005-3.md)。

> **這是同一組值的三種單位制，不是三套規範。** $k\sqrt{f'_c}$ 型係數換單位時係數本身會變（因為根號裡也換了）：
> psi → kgf/cm²：$\times\sqrt{0.0703}=0.265$；psi → MPa：$\times\sqrt{0.006895}=0.0830$。
> 驗算：$20\times0.265=5.30$、$15\times0.265=3.98\approx4.0$、$12\times0.265=3.18\approx3.2$。
>
> **錨點（依規則 2 以驗證解答為準）：** [RC-2005-3](../problems/RC-2005-3.md) 明載
> 「角柱（外接頭）=3.2、T 形接頭=4.0、十字形（內接頭）=5.3」，並附 $\gamma=12\times0.265=3.18\approx3.2$ 的換算推導；
> [RC-2003-3](../problems/RC-2003-3.md) 明載內接頭 $\gamma=5.3$（對應 psi 制 20）。
> 部分教材將內接頭寫為 5.4，係換算取捨差異，非另一套規範。
>
> **作答時務必寫明採用的單位制**，這是本考點最常見的失分點。

### 有效接頭面積 $A_j$

$$A_j = h_c \times b_j$$

$$b_j = \min\big(b_{beam} + h_{col},\ \ b_{beam} + 2x\big)\ \le\ b_{col}
\qquad(\text{§15.4.2.4})$$

- $h_{col}$ ＝ 柱平行於剪力方向之斷面深度（＝ 接頭深度）
- $x$ ＝ 梁側面至柱側面之**較小**距離；梁置中且與柱同寬時 $x = 0 \Rightarrow b_j = b_{col}$

## 耐震設計常見考試陷阱速查

| 陷阱 | 正確做法 |
|------|---------|
| 用 φMn 計算 Ve | 應用 **Mpr（1.25fy，無 φ）** |
| 梁端 Vc 未歸零 | 地震主控時（Ve ≥ 0.5Vu 且 Pu < 0.05Ag f'c）$V_c = 0$ |
| γ 係數單位制混用／漏屋頂層 | kgf/cm² **5.3／3.9／3.2**（柱延伸）與 **4.7／3.2／2.2**（屋頂層）；作答務必寫明單位制與接頭位置 |
| Ash 只算一個公式 | 318-19 為**三式取大**；第三式僅當 $P_u > 0.3A_gf'_c$ 或 $f'_c > 70$ MPa 時才須查 |
| 梁密箍區間距抄舊值 | 318-14 起為 $\min(d/4,\,6d_b,\,150\text{ mm})$，不是 $8d_b$／$24d_{sw}$／300 mm |
| 柱塑鉸區外間距只查 $6d_b$ | 須 $\min(6d_b,\ 150\text{ mm})$ |
| 柱剪力由梁 Mpr 反推時算成兩倍 | $V_e = \Sigma M_{pr,\text{beam}}/l_u$（一個接頭的總和） |
| 強柱弱梁 6/5 忘記 | $\sum M_{nc} \geq 1.2 \sum M_{nb}$（6/5 = 1.2） |
