# 預力鋼腱極限應力 fps 公式選擇陷阱

**陷阱 ID：** PRESTRESS-FPS-FORMULA
**知識分類：** RC-U4-1
**危險係數：** ★★★（高頻、高誤率）
**最後修訂：** 2026-08-22（XCHECK：補上兩分支的配對上限、$\gamma_p$ 取值表、$f_{se}\ge0.5f_{pu}$ 前提、$A_{s,\min}$、$\varepsilon_t$ 取代 $\omega_p$；修正條文編號 §20.3.2.3／§20.3.2.4）

---

## 陷阱描述

預力梁計算撓曲強度時，$f_{ps}$ 的計算方式取決於**鋼腱有無黏結（bonded vs. unbonded）**。
考生最常犯的錯誤是：混用有黏結與無握裹的公式。

---

## 公式對照

### 有黏結鋼腱（Bonded Tendons）　土木 401-110/112 §20.3.2.3.1／ACI 318-19 §20.3.2.3.1

$$f_{ps} = f_{pu}\left(1 - \frac{\gamma_p}{\beta_1}\left(\rho_p \frac{f_{pu}}{f'_c} + \frac{d}{d_p}(\omega - \omega')\right)\right)$$

| 項目 | 內容 |
|---|---|
| $\gamma_p$ | $f_{py}/f_{pu}\ge0.80$ → 0.55；$\ge0.85$ → **0.40**；$\ge0.90$ → 0.28（低鬆弛絞線） |
| **使用前提** | $f_{se} \ge 0.5f_{pu}$（不成立則不得用此近似式，須做應變相容分析） |
| **上限** | **沒有** $f_{py}$ 上限——$f_{ps} > f_{py}$ 是合法的（極限狀態已進應變硬化區） |
| 舊制延性驗核 | $\omega_p = A_{ps}f_{ps}/(bd_pf'_c) \le 0.36\beta_1$（ACI 318-99 舊制，**現行已刪除**） |
| 現行 $\phi$ 判定 | 淨拉應變 $\varepsilon_t$：預力構材壓力控制 0.002、拉力控制 **0.005**（固定值，不隨 $f_y$ 變） |

### 無握裹鋼腱（Unbonded Tendons）　§20.3.2.4.1

**兩個分支是「公式＋上限」成套的，最常見的錯誤就是拿 A 的公式配 B 的上限：**

| 跨深比 $\ell/h$ | $f_{ps}$ 公式（kgf/cm² 制） | 應力增量上限 |
|---|---|---|
| $\le 35$ | $f_{se} + 700 + \dfrac{f'_c}{100\rho_p}$ | $\min\!\left(f_{py},\ f_{se}+\mathbf{4200}\right)$ |
| $> 35$ | $f_{se} + 700 + \dfrac{f'_c}{300\rho_p}$ | $\min\!\left(f_{py},\ f_{se}+\mathbf{2100}\right)$ |

SI 制對應：$+70$、$f_{se}+420$／$f_{se}+210$ MPa。

**判準是跨深比，不是「簡支 vs. 懸臂」**——條文文字是 span-to-depth ratio，深度取構材**全深 $h$**
（坊間亦有直接用 $d_p$ 者，多數題目兩者同結論；不同時以 $\ell/h$ 為準）。
直覺：跨度越長，同樣的絕對伸長量被分配到越長的自由長度，$\Delta f_{ps}$ 越小 → 公式壓低、上限也減半。

### 無握裹腱的配套強制條文：最小握裹鋼筋 §7.6.2.3

$$A_{s,\min} = 0.004\,A_{ct},\qquad A_{ct} = \text{受拉面至全斷面形心之間的面積}\ (= b\,h/2\ \text{矩形版})$$

無握裹腱不與混凝土握裹，開裂後裂縫會集中；此鋼筋負責分散裂縫並提供剩餘強度。
**它是強制最小量，其 $A_sf_y$ 屬斷面標稱撓曲強度的一部分**——算 $M_n$ 時漏掉會低估（RC-2023-4 少 22%）。

## 判斷流程

```
讀題 → 確認「有黏結腱（bonded）」或「無握裹腱（unbonded）」
     ↓
有黏結：先驗 fse ≥ 0.5fpu → 代 γp/β₁ 近似式（fps 不出現在右邊，一次算完）
        → 無 fpy 上限
無握裹：先算跨深比 ℓ/h → 選 100 或 300 分支
        → 代公式 → 用「同分支」的上限驗核（4200 或 2100）
        → 另依 §7.6.2.3 算 As,min = 0.004Act 並計入 Mn
     ↓
最終驗核（現行）：c = a/β₁ → εt = 0.003(dt−c)/c ≥ 0.005 → φ = 0.9
        （舊制 ωp ≤ 0.36β₁ 可並寫，但已非現行依據）
     ↓
最小撓曲強度：φMn ≥ 1.2Mcr（§9.6.2.1）
```

## 常見陷阱場景

| 陷阱 | 說明 |
|------|------|
| 忘記 $\beta_1$ 折減 | $\gamma_p/\beta_1$ 的 $\beta_1$ 常被遺漏 |
| 無握裹腱用有黏結公式 | 無握裹腱的 $f_{ps}$ 遠小於有黏結腱 |
| 忘記 $\omega'$（壓力鋼筋） | 若同時有壓力非預力筋，需在公式中扣除 $\omega'$ |
| **上限配錯分支** | $\ell/h>35$ 卻用 $f_{se}+4200$——上限直接放大一倍，檢核形同虛設（RC-2023-4 舊版即此錯）|
| **判準寫成「簡支／懸臂」** | 條文是跨深比，與構材型式無關 |
| **漏算 $A_{s,\min}$** | 無握裹腱單向版必配 $0.004A_{ct}$，其貢獻屬 $M_n$ |
| **有黏結腱誤加 $f_{py}$ 上限** | 上限只加在無握裹腱；有黏結腱 $f_{ps}>f_{py}$ 合法 |
| **忘了 $f_{se}\ge0.5f_{pu}$ 前提** | 近似式的適用門檻，不成立要改應變相容 |
| $d$ vs. $d_p$ | 公式中的 $d$ 是非預力鋼筋深度，$d_p$ 是預力腱深度 |
| 開裂彎矩 $M_{cr}$ 計算 | $M_{cr}$ 用彈性方法（$f = P/A \pm Pe \cdot y/I \pm M \cdot y/I$），而非 Whitney |
