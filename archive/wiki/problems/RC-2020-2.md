# RC-2020-2 — 倒T型梁：載重在下翼板故不可 d 偏移，s_max=16.6 cm

**來源：** 結構工程技師高考 · 鋼筋混凝土設計與預力 · 第2題

## 題幹摘要

簡支**獨立**倒 T 型梁（腹板在上、翼板在下），均佈設計載重 $w_u = 15$ tf/m，跨度 800 cm，$f'_c = 280$ kgf/cm²，$f_y = 4200$ kgf/cm²，腹板寬 $b_w = 35$ cm，全深 $h = 90$ cm，$d = 84$ cm，D13 閉合箍筋（$A_v = 2.534$ cm²）。**附圖中載重箭頭終止於距梁頂 70 cm 處，即下翼板頂面（拉力側）。** 三小題：（一）是否可採 $d$ 偏移；（二）支承位置最大肋筋間距；（三）斷面最大設計剪力。

## 核心考點

- $d$ 偏移**三條件**（土木401-100 §4.11.1／ACI 318 §9.4.3.2）：(a) 支承反力在端區產生壓力、(b) **載重施加於構材頂部或其附近**、(c) 區間內無集中載重。**缺一即不可偏移**
- 本題條件 (b) 不成立：倒 T 承托梁的載重自下翼板（拉力側）進入 → 懸吊式載重 → **臨界斷面取支承面**
- $V_c = 0.53\sqrt{f'_c}b_wd = 26.07$ tf，$\phi = 0.75$
- 箍筋間距上限雙門檻：$V_s \le 2V_c$ → $\min(d/2,60)$；$V_s > 2V_c$ → $\min(d/4,30)$。本題 $V_s = 53.93 > 2V_c = 52.15$（僅超 3.4%）→ 取 $d/4 = 21$ cm
- 斷面最大可承受設計剪力由 $V_{s,\max} = 4V_c$ 控制
- 懸吊鋼筋（hanger reinforcement）需求 $A_h \ge w_u/(\phi f_y)$

## 解題關鍵步驟

1. （一）逐條驗三條件 → 條件 (b) 不成立（載重在拉力側）→ **不可** $d$ 偏移，臨界斷面取**支承面**
2. $V_c = 0.53\sqrt{280}\times35\times84 = 26{,}074$ kgf $= 26.07$ tf
3. 臨界斷面剪力：$V_u = w_uL/2 = 15\times4 = 60$ tf（**不扣** $w_ud$）
4. $V_s = V_u/\phi - V_c = 80 - 26.07 = 53.93$ tf
5. （二）$2V_c = 52.15 < V_s = 53.93 < 4V_c = 104.30$ → $s_\text{max,code} = \min(d/4,30) = 21$ cm；強度需求 $s = A_vf_{yt}d/V_s = 894{,}005/53{,}926 = 16.58$ cm 控制 → **$s_{\max} = 16.6$ cm（實配 D13 @ 16 cm）**
6. （三）$V_{u,\max} = \phi(V_c+4V_c) = 5\phi V_c = 0.75\times130{,}369 = 97.8$ tf
7. 補充：$A_{v,\min} = \max(0.2\sqrt{f'_c},\,3.5)b_ws/f_{yt} = 0.467$ cm² $\ll A_v = 2.534$ ✓；懸吊需求 4.76 cm²/m $\ll$ 實配 15.8 cm²/m ✓

## 用到的公式

$$V_c = 0.53\sqrt{f'_c}\, b_w d$$

$$V_s = \frac{V_u}{\phi} - V_c$$

$$s = \frac{A_v f_{yt} d}{V_s}$$

$$s_\text{max,code} = \begin{cases} \min(d/2,\,60) & V_s \leq 2V_c \\ \min(d/4,\,30) & V_s > 2V_c \end{cases}$$

$$V_{u,\max} = \phi(V_c + 4V_c) = 5\phi V_c \quad (V_{s,\max} = 4V_c = 2.12\sqrt{f'_c}b_wd)$$

$$A_h \ge \frac{w_u}{\phi f_y}\ \text{（懸吊鋼筋，單位長度）}$$

## 涉及陷阱

- **附圖判讀（致命）：** 載重箭頭畫在下翼板頂面而非梁頂。誤讀成梁頂載重會答成「可以偏移」，間距從 16.6 cm 放寬到 24.1 cm（**偏不安全 45%**），且規範上限誤用 $d/2$ 而非 $d/4$。
- $\phi = 0.75$：108 年規範／土木 401 剪力用 0.75，$\phi=0.85$ 是 ACI 318-99 舊制。誤用 0.85 會使 $V_s = 44.5 < 2V_c$，兩個分支同時錯。
- $A_v = 2\times1.267 = 2.534$ cm²：閉合箍筋一組兩腳，非單腳 1.267。
- 間距門檻判斷順序：須先算 $V_s$ 再與 $2V_c$ 比較；本題只超門檻 3.4%，但規範是硬門檻。
- $A_{v,\min}$ 係數是 **3.5**（$3.5b_ws/f_{yt}$），不是 0.35。
- 倒 T 承托梁另需**懸吊鋼筋**把下翼板載重吊入腹板壓力區，與剪力箍筋須分別檢核。

## 依最新規範對照

原卷指定 108 年規範／土木 401-100。土木 401-112／ACI 318-19 的 $d$ 偏移三條件（§9.4.3.2）、間距門檻（§9.7.6.2.2）、$V_{s,\max}$（§22.5.1.2）、$A_{v,\min}$（§9.6.3.4）**均相同**，且 $V_c$ 由原卷直接給定、$N_u = 0$、$A_v \ge A_{v,\min}$（不觸發 318-19 新增尺寸效應係數 $\lambda_s$），故 **兩版答案完全一致：16.6 cm／97.8 tf**。
