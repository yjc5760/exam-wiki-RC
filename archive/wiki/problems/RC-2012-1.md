## 題幹摘要

**後拉法**懸臂純預力梁，$b=30$ cm，$h=90$ cm，懸臂長 $L=610$ cm，全長固定偏心 $e=30$ cm；3根 12.7 mm 七線絞有黏裹鋼鍵（$A_{ps}=2.9613$ cm²），初始預力 $f_{pi}=0.75f_{pu}=14{,}250$ kgf/cm²，$f'_{ci}=0.7f'_c=245$ kgf/cm²。判斷鋼鍵偏心方向，並檢核初始階段固定端與自由端混凝土應力是否超出規範容許值；說明補救措施。

## 核心考點

- 懸臂梁固定端受最大負彎矩（頂纖維拉）→ 鋼鍵應在重心**上方**（與簡支梁相反）
- 自由端無外力矩，上偏心導致底纖維純拉力，是底纖維控制斷面
- 初始階段必須用 $f'_{ci}$（低），容許拉應力僅 $0.80\sqrt{245}=12.52$ kgf/cm²
- 計算結果：固定端四值均通過；自由端底纖維 $+15.63$ kgf/cm² 超限（$>12.52$）
- **超限的是一整段而非一點**：$f_{bot}(\xi)=15.63-28.53(\xi/610)^2 > 12.52$ ⇒ 自由端起 **201 cm**（約梁長 1/3）全段超限
- $f_{bot}=15.63 < f_r = 2.0\sqrt{f'_{ci}} = 31.3$ ⇒ **斷面尚未開裂**，補救屬「配鋼筋承擔拉力」而非重新設計斷面（原卷給 $f_r$ 就是要你判這件事）
- 補救一：彎折腱型（自由端 $e=0$）消除底纖維拉力；補救二：底部配非預力握裹鋼筋承擔**全部**拉力

## 解題關鍵步驟

1. 偏心方向：懸臂梁固定端頂纖維受拉 → 鋼鍵在重心上方（$e=+30$ cm）
2. 斷面性質：$A=2{,}700$ cm²，$I=1{,}822{,}500$ cm⁴，$S_t=S_b=40{,}500$ cm³
3. 初始預力：$P_i=14{,}250\times2.9613=42{,}199$ kgf；$P_i/A=15.63$，$P_ie/S=31.26$ kgf/cm²
4. 自重力矩（固定端）：$w=6.21$ kgf/cm，$M_{sw}=wL^2/2=1{,}155{,}371$ kgf·cm，$M/S=28.53$ kgf/cm²
5. 固定端：頂 $=-15.63-31.26+28.53=-18.36$ C ✓；底 $=-15.63+31.26-28.53=-12.90$ C ✓
6. 自由端：頂 $=-15.63-31.26=-46.89$ C ✓；底 $=-15.63+31.26=+15.63$ T ❌（超限）
7. 超限區段：$(\xi/610)^2 = (15.63-12.52)/28.53 = 0.1090 \Rightarrow \xi = 201$ cm（自由端起算）
8. 開裂判定：$f_r = 2.0\sqrt{245} = 31.3 > 15.63$ → **未開裂**
9. 補救一：改腱型為彎折腱（自由端 $e=0$），自由端底纖維 $=-15.63$ C（全壓）
10. 補救二：$T = \frac12\times15.63\times22.5\times30 = 5{,}275$ kgf；$f_s = \min(0.6f_y,\,2100) = 2{,}100$ → $A_s = 2.51$ cm²，配 2-D13 由自由端延伸 ≥201 cm + $\ell_d$

## 用到的公式

- 固定端應力：$f_{top}=-P_i/A-P_ie/S_t+M_{sw}/S_t$；$f_{bot}=-P_i/A+P_ie/S_b-M_{sw}/S_b$
- 自由端應力（$M=0$）：$f_{top}=-P_i/A-P_ie/S_t$；$f_{bot}=-P_i/A+P_ie/S_b$
- 懸臂自重矩：$M_{sw}=wL^2/2$
- 容許壓應力：$0.60f'_{ci}=147$ kgf/cm²；容許拉應力：$0.80\sqrt{f'_{ci}}=12.52$ kgf/cm²
- 超限區段：$f_{bot}(\xi) = -\dfrac{P_i}{A}+\dfrac{P_ie}{S}-\dfrac{w\xi^2/2}{S}$（$\xi$ 自自由端量起）
- 補充鋼筋：$A_s = T/f_s$，$f_s = \min(0.6f_y,\ 2{,}100\ \text{kgf/cm}^2)$（§24.5.3.2，承擔**未開裂斷面算出的全部拉力**）

## 涉及陷阱

- 懸臂梁鋼鍵偏心方向與簡支梁相反（在重心上方，非下方）
- 自由端無重力矩遮蔽，底纖維拉力在全梁中最大，是控制斷面（常被忽略）
- 初始階段必須用 $f'_{ci}=245$ kgf/cm²，不可用 $f'_c=350$ kgf/cm²（容許拉應力差 27%）
- $A_{ps}$ 單位換算：98.71 mm²/根 = 0.9871 cm²/根（$\div100$，非 $\div10$）
- **工法別看到「有黏裹」就寫先拉法**：「混凝土達 7 天強度才張拉」＋「忽略鋼鍵與**套管**面積」＝後拉法（舊版本頁誤標先拉法，已更正）
- 補充鋼筋應力用 $0.6f_y$（上限 2,100）而非 $0.5f_y$——本題 $f_y=4200$ 時兩者巧合同值，$f_y$ 不同時會算錯
