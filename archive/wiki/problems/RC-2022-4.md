## 題幹摘要

RC 柱（80×80 cm，淨高 6.4 m，$f'_c = 280$，$f_y = 4200$，主筋 D32），柱底承受 $P = 270$ tf、$M = 232.5$ tf·m。依線性內插（$P = 180$ 與 360 tf 兩組塑鉸參數）求彎矩塑鉸性質，依 109 年公路橋梁耐震規範公式，評估曲率韌性需求 $\mu_\phi$、轉角韌性需求 $\mu_\theta$、位移韌性需求 $\mu$。

## 核心考點

- 線性內插：$P = 270$ tf 位於 180 與 360 tf 之間，各塑鉸參數內插求值
- 塑鉸長度 $L_p$ 公式的混合單位與下限控制
- 三個韌性需求的層次：曲率（斷面）→ 轉角（構件）→ 位移（整體）
- 懸臂長度 $L = l_u/2 = 3.2$ m（反曲點在淨高中點，單曲率柱）
- 主線答案：$L_p = 0.595$ m（**下限式控制**）、$\delta_y = 1.707$ cm、$\delta_u = 4.491$ cm、$\mu_\phi = 4.00$、$\mu_\theta = \mu = 2.63$
- 「以撓曲變形為主」＝ 不計剪力變形與鋼筋滑移之貢獻

## 解題關鍵步驟

1. 確認懸臂長度：$L = l_u/2 = 6.4/2 = 3.2$ m（反曲點在柱淨高中點）
2. 線性內插比例 $= (270-180)/(360-180) = 0.5$，求各塑鉸參數（$\phi_y$、$\phi_u$、$M_y$、$M_u$）
3. 計算 $L_p = 0.08L + 0.0022 d_b f_y \ge 0.0044 d_b f_y$（**$L$、$d_b$ 用 m，$f_y$ 用 kgf/cm²**）：$0.256+0.298 = 0.554$ vs 下限 $0.595$ → **下限控制，$L_p = 0.595$ m**
4. 計算 $\delta_y = \phi_y L^2/3$，$\theta_y = \delta_y/L$
5. 計算 $\delta_u = (M_u/M_y)\delta_y + (\phi_u - \phi_y) L_p (L - 0.5L_p)$
6. 三個韌性比：$\mu_\phi = \phi_u/\phi_y$，$\mu_\theta = \theta_u/\theta_y$，$\mu = \delta_u/\delta_y$

## 用到的公式

$$\text{線性內插：} X = X_1 + (X_2 - X_1)\frac{P - P_1}{P_2 - P_1}$$

$$L_p = 0.08L + 0.0022\,d_b f_y \geq 0.0044\,d_b f_y$$

$$\delta_y = \frac{\phi_y L^2}{3}$$

$$\delta_u = \frac{M_u}{M_y}\delta_y + (\phi_u - \phi_y) L_p \!\left(L - \frac{L_p}{2}\right)$$

$$\mu_\phi = \frac{\phi_u}{\phi_y}, \quad \mu_\theta = \frac{\theta_u}{\theta_y}, \quad \mu = \frac{\delta_u}{\delta_y}$$

## 涉及陷阱

- 懸臂長度 $L = l_u/2$：反曲點在柱淨高中點，$L$ 不是全柱高 $l_u$。
- **$L_p$ 的單位是 $L$、$d_b$ 用 m、$f_y$ 用 kgf/cm²**（舊版本頁誤寫「$d_b$ 用 mm、$f_y$ 用 MPa」）。係數 0.0022／0.0044 已由 Priestley 原式的 0.022／0.044（MPa 制）除以 10.197 換算而得，代入時**不要再自行換算 $f_y$**。
- 下限控制：$L_p \geq 0.0044 d_b f_y$，確保塑鉸長度不低於最小值。
- 三種韌性層次不同：曲率（斷面）$\mu_\phi = 4.0$ $\gg$ 轉角／位移（構件、整體）$= 2.63$；塑鉸只有 $L_p = 0.595$ m，其貢獻被稀釋於 $L = 3.2$ m 之中。
- **「需求」與「容量」的用語落差**：原卷印的是容量公式（下標 $u$），但題幹說「需求」，且給的 $M = 232.5$ 恰為 $M_y$ 與 $M_u$ 正中點卻用不到——兩種讀法都須留檔（見下）。

## 讀法留檔：$M = 232.5$ tf·m 要不要用？

$232.5 = (220+245)/2$，**恰為內插後 $M_y$ 與 $M_u$ 的正中點**。

| | **讀法 A（主線）** | 讀法 B（依 $M=232.5$ 的「需求」） |
|---|---|---|
| 依據 | 照原卷印出的公式（下標 $u$）逐字代入 | 「需求」＝在實際承受之 $M = 232.5$ 評估 |
| $\phi$ | $\phi_u = 0.020$ | $\phi_d = 0.005+\frac{12.5}{25}(0.015) = 0.0125$ |
| $\mu_\phi$ | **4.00** | **2.50** |
| $\delta$ | 4.491 cm | 3.099 cm |
| $\mu_\theta = \mu$ | **2.63** | **1.82** |
| 名稱 | 實為**韌性容量** | 才是嚴格的**韌性需求** |

採 A 為主線：題幹明寫「請根據規範**所列公式如下**……評估」，而公式下標就是 $u$。
$M = 232.5$ 則用來確認柱底**已降伏**（$>M_y=220$）且**未達極限**（$<M_u=245$）。
**考場兩個都寫**，並可補一句「容量／需求 $= 2.63/1.82 = 1.44$，尚有 44% 韌性餘裕」。
