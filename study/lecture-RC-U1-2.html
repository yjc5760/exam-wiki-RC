§0 全景：軸力是幫手，也是兇手

一句話：軸壓對「彎矩容量」是先幫忙、後傷害；對「延性」則是從頭到尾只有傷害。
平衡點就是「幫忙」翻成「傷害」的那個轉折 —— 而 ACI 也剛好把 \(\phi\) 值的分界線畫在同一個地方。 RC-U1-2 這 20 題考題，全部是這一句話的展開。

先把最容易誤導人的直覺丟掉：柱不是「加了軸力的梁」。梁的答案是一個數字 \(M_n\)； 柱的答案是一條曲線 —— 因為斷面能承受多少彎矩，取決於此刻壓在它身上的軸力有多少。 同一根柱，\(P_u = 0\) 時可能只撐得住 60 tf·m，\(P_u = 430\) tf 時卻能撐 136 tf·m。

圖 0-1　梁與柱在「數學上」的差別：梁少一個未知數，所以有唯一解；柱多一個，所以只能掃描 \(c\) 得到一條曲線。 把「P-M 互制圖是一條曲線」理解成「方程式少一條」，就不需要記它長什麼樣子。

那條曲線為什麼會「鼓出來」

P-M 圖最反直覺的地方是：它不是從左上角一路單調滑到右下角，中間會凸出一塊。 原因就是本節那句話 —— 軸力對彎矩的兩種作用在不同區間輪流當家：

拉力控制區（P 小，e 大）
斷面大半在受拉、混凝土幾乎沒在出力。此時加一點軸壓，等於幫忙把拉力區壓回去， 中性軸下移、壓力塊變深、力偶臂拉長 → \(M_n\) 隨 \(P\) 一起上升。
軸力此時是幫手。
壓力控制區（P 大，e 小）
斷面已經幾乎全部受壓，拉力筋還沒降伏甚至還在受壓。再加軸力，只是把混凝土的容量 拿去扛軸力、剩給彎矩的就變少 → \(M_n\) 隨 \(P\) 一起下降。
軸力此時是兇手。

兩個區間的交界，就是平衡點：最外層拉力筋剛好降伏（\(\varepsilon_t = \varepsilon_y\)）的那一刻。 它同時是「\(M_n\) 的最大值」與「\(\phi\) 從 0.90 掉到 0.65 的底部」—— 這不是巧合，見 §3、§4。

圖 0-2　P-M 互制圖全貌。藍實線是斷面真實能力，紅虛線是乘上 \(\phi\) 之後你能用的部分。 注意兩件事：(1) 紅線在上方被「削平」—— 那是 \(0.80\phi P_o\) 的強制上限； (2) 紅線在平衡點附近被壓得特別扁，因為那裡 \(\phi\) 最小（0.65）。設計點 \((P_u, M_u)\) 必須落在紅線內側。
為什麼要有 0.80 這個上限？ 不是為了「安全係數再乘一次」。真正的理由是：世界上沒有真正的純軸壓柱。 施工偏差、梁端不對稱、樓版收縮，都會給柱一個誰也沒算的小偏心。 ACI 用「強制保留一段偏心容量」的方式處理它 —— 0.80 對應大約 \(e \approx 0.10h\)， 0.85（螺旋柱）對應大約 \(e \approx 0.05h\)。
螺旋柱為什麼可以放寬到 0.85？因為螺旋筋是連續圍束，蓋層剝落後核心還能繼續出力（見 §5）， 破壞前有可見的預兆；箍筋柱一旦壓碎就整段掉，所以扣得比較重。這條「有沒有預警」的邏輯， 從 \(\phi\) 值到 \(0.80/0.85\)、到 §5 的圍束規定，全部通吃。
本節因果鏈：柱多一個未知數 → 只能掃描 c → 得到一條曲線 → 軸力在拉力側幫忙、在壓力側傷害 → 曲線鼓出來，峰值在平衡點

§1 唯一引擎：假設一個 c，其餘全部是它的函數

本節主張：整個 RC-U1-2 只有一個計算引擎 —— 假設中性軸深度 \(c\)，用「應變是直線」把每一排鋼筋的應力算出來，然後做兩次平衡（力、力矩）。 20 題考題差別只在「\(c\) 是怎麼被決定的」。

1.1 三個假設，一個都不能少

假設內容它在幫你做什麼
平面保持平面
（Bernoulli）		應變沿斷面深度線性分布只要知道 \(c\)，任何位置的應變都能用相似三角形算出來 —— 這是唯一能把「幾何」翻成「應力」的橋
\(\varepsilon_{cu} = 0.003\)壓力最外緣的極限壓應變把應變直線的一端釘死。有了固定端點＋一個 \(c\)，整條直線唯一確定
鋼筋理想彈塑性\(f_s = E_s\varepsilon_s\)，但上限 \(\pm f_y\)把應變翻成應力。「上限」三個字是柱題最大的失分點（見陷阱表）
為什麼是 0.003 而不是別的？ 它是試驗迴歸的下包絡，不是物理常數。真實混凝土壓碎應變落在 0.003–0.004 之間（隨 \(f'_c\) 略降）， ACI 取偏保守的 0.003。歐規（EC2）取 0.0035，紐西蘭規範取 0.004 —— 同一個現象、不同國家取不同的保守程度。 能記住「它是一個保守取值」，你就不會在圍束混凝土題（§5）看到 \(\varepsilon_{cu}=0.015\) 時傻眼 —— 圍束改變了這個試驗事實。

1.2 三種「c 被決定」的方式 —— 這就是全部的題型

圖 1-1　柱題的三種入口。拿到題目第一件事就是判斷自己在哪一格 —— A 格不用解方程（送分），B 格要準備解二次式（費時但機械化），C 格是概念題（寫步驟即可）。 判斷錯了會白花十分鐘去解一個題目其實已經給你答案的 \(c\)。

1.3 應變直線：一張圖看懂三排鋼筋

圖 1-2　柱斷面的三張圖，永遠一起畫。左：幾何；中：應變（唯一的直線，斜率由 \(c\) 決定）；右：應力與合力。 畫不出中間那張圖的人，一定會漏掉某一排鋼筋。考場上務必先把這三張並排畫在草稿紙上。
引擎的完整寫法（背這個就好，不要背個別題型的公式） $$\varepsilon_i = 0.003\cdot\frac{c - d_i}{c}\quad(\text{壓為正}),\qquad f_{si} = \operatorname{clip}(E_s\varepsilon_i,\,-f_y,\,+f_y)$$ $$P_n = \underbrace{0.85f'_c\,\beta_1 c\,b}_{C_c} \;+\; \sum_i F_i,\qquad F_i=\begin{cases} A_{si}\,(f_{si}-0.85f'_c) & d_i < a \;(\text{在應力塊內}) \\[4pt] A_{si}\,f_{si} & d_i \ge a\end{cases}$$ $$M_n = C_c\left(\frac{h}{2}-\frac{a}{2}\right) + \sum_i F_i\left(\frac{h}{2}-d_i\right)$$

三個提醒：① \(\sum\) 是代數和，拉力筋的 \(f_{si}\) 自帶負號，不要再手動減一次； ② 力矩一律對塑性形心取（對稱配筋時 = 幾何中心 \(h/2\)）； ③ 位於 \(h/2\) 的中排鋼筋力臂為零，它影響 \(P_n\) 但完全不影響 \(M_n\) —— 這是 RC-2008-2、RC-2011-3、RC-2021-2 三題共同的送分點。

極限檢查（忘記公式時自救）： 把 \(c \to \infty\) 代進去 —— 所有 \(\varepsilon_i \to 0.003\)（全部受壓且降伏）、\(a \to h\)， 於是 \(P_n \to 0.85f'_c(A_g-A_{st}) + f_yA_{st} = P_o\)，而各力對稱 \(\Rightarrow M_n \to 0\)。 這正是純軸壓點。反過來令 \(P_n = 0\)，就回到 RC-U1-1 的雙筋梁。 如果你的公式在這兩個極限上對不起來，一定是符號寫錯了。
本節因果鏈：平面保持平面 → 應變是一條直線 → 一個 c 定住整條直線 → 每排鋼筋應變 → 應力（記得 clip 到 fy）→ 力平衡給 Pn、力矩平衡給 Mn → (Pn, Mn) 是 c 的函數

§2 四個控制點：它們其實是同一個公式的四個切片

本節主張：不要把四個控制點當成四條要背的公式。它們是同一個引擎在四個特定 \(c\) 值下的輸出。 搞清楚「這個點對應的 \(c\) 是多少」，公式自己會長出來。
控制點物理條件對應的 cφ
① 純軸壓 \(P_o\)整段均勻壓縮，無彎矩\(c \to \infty\)0.65 / 0.75，另乘 0.80 / 0.85 上限
② 全壓邊界最外層鋼筋 \(\varepsilon_t = 0\)\(c = d_t\)（直接讀出來）0.65 / 0.75
③ 平衡點 \(P_b\)\(\varepsilon_t = \varepsilon_y\) 且 \(\varepsilon_c = 0.003\)\(c_b = \dfrac{6120}{6120+f_y}d_t\)≈ 0.655（過渡區起點，不是 0.65）
④ 純彎\(P_n = 0\)解方程（＝雙筋梁）通常 0.90
\(c_b\) 公式裡的 6120 是怎麼來的？不要背它。
平衡點的定義是「壓力側到 0.003、拉力筋剛好到 \(\varepsilon_y\)」。相似三角形直接給： $$\frac{c_b}{d_t}=\frac{\varepsilon_{cu}}{\varepsilon_{cu}+\varepsilon_y}=\frac{0.003}{0.003+f_y/E_s}$$ 上下同乘 \(E_s = 2.04\times10^6\)：分子 \(=0.003\times2.04\times10^6 = 6120\)，分母 \(=6120+f_y\)。 6120 就是 \(\varepsilon_{cu}E_s\)，單位 kgf/cm²。
所以 SI 制（\(E_s=200{,}000\) MPa）自然變成 \(0.003\times200000=600\) → \(\dfrac{600}{600+f_y}\)。 記住「它是 \(\varepsilon_{cu}E_s\)」，就再也不會用錯單位制。

2.1 ① 純軸壓：兩個 0.85 是不同的東西

$$P_o = 0.85f'_c\,(A_g - A_{st}) + f_y A_{st}$$
陷阱：公式裡的 0.85 和螺旋柱上限的 0.85 完全無關。
  • \(0.85f'_c\)：把「圓柱試體強度」折算成「實際構材強度」。因為實際柱較高較細、受力時間長、養護條件差、有尺寸效應 —— 這是材料折減，箍筋柱螺旋柱都有。
  • \(0.85 P_o\)（螺旋柱）／\(0.80 P_o\)（箍筋柱）：最小偏心保留，是幾何理由，不是材料理由。
考卷上把兩個 0.85 混在一起寫成 \(0.85\times0.85\) 是常見的錯誤來源。

2.2 ② 全壓邊界（\(\varepsilon_t = 0\)）—— 考最多次的「送分點」

題目寫「拉力側鋼筋之應變剛好等於零」時，不要去解方程。應變是直線，\(\varepsilon = 0\) 的地方就是中性軸， 所以直接 \(\boxed{c = d_t}\)。RC-2008-2 與 RC-2024-3 都是這個套路。

手算範例 A｜RC-2008-2（2008）：\(\varepsilon_t = 0\) 的方形柱

方形柱 56×56 cm，8-#8（\(A_b = 5.07\) cm²）分三排 3+2+3，各排距壓力面 \(d_1=8,\ d_2=28,\ d_3=48\) cm。 \(f'_c = 350\)、\(f_y = 4200\)、\(E_s = 2.04\times10^6\) kgf/cm²。求拉力筋應變為零時的 \(M_n\)。

2.3 ④ 純彎：柱題裡藏著一題梁題

令 \(P_n = 0\)，引擎變成 \(C_c + \sum F_i = 0\)。這就是 RC-U1-1 的雙筋梁分析 （\(\to\) 見 RC-U1-1 講義 §4）。 柱通常對稱配筋、\(A'_s = A_s\)，所以純彎點的 \(M_n\) 反而比平衡點小很多 —— 這正是下一節要解釋的事。

§3 為什麼最大彎矩在平衡點（不是純彎點）

本節主張：對稱配筋柱的 \(M_n(c)\) 是一條先升後降的曲線，轉折就在 \(c = c_b\)。 考題常直接問「適當調整軸力後，此柱能承受的最大彎矩」—— 問的就是平衡點。答錯的人多半直接去算純彎。
圖 3-1　\(M_n\) 對 \(c\) 的變化。左半段拉力筋已降伏，拉力被鎖死在 \(A_sf_y\)， 所以增加 \(c\) 只有「壓力變大、力偶臂變長」的好處；右半段拉力筋掉出降伏， 拉力隨 \(c\) 快速衰減，好處被吃光。轉折點的定義就是「拉力剛好還在降伏」＝ 平衡點。
兩行代數就能證明。在 \(c \le c_b\)（拉力筋降伏、壓力筋也降伏）的區間， \(T = A_sf_y\) 與 \(C_s\) 都是常數，只有 \(C_c = 0.85f'_c\beta_1 c\,b\) 隨 \(c\) 線性增加。 對形心取矩： $$M_n(c)=\underbrace{0.85f'_c\beta_1 b}_{k}\,c\left(\frac{h}{2}-\frac{\beta_1 c}{2}\right)+\text{const} \;\Rightarrow\;\frac{dM_n}{dc}=k\left(\frac{h}{2}-\beta_1 c\right)$$ 在一般柱尺寸下 \(\beta_1 c_b < h/2\)，所以整個 \(c \le c_b\) 區間 \(dM_n/dc > 0\)，單調遞增。 一過 \(c_b\)，\(T\) 開始以 \(\propto (d-c)/c\) 掉下來，\(dM_n/dc\) 翻負。峰值只能在交界。 （RC-2015-1 的官方解析算出 \(dM_n/dc = 428{,}400 - 11{,}424c\)，在 \(c_b = 30.84\) 時仍為正 —— 與此一致。）

手算範例 B｜RC-2015-1（2015）：求柱能承受的最大極限彎矩

方形柱 60×60 cm，8-#10（\(A_b = 8.143\) cm²）頂 4 底 4，\(d' = 8\)、\(d = 52\) cm。 \(f'_c = 350\)、\(f_y = 4200\) kgf/cm²。

Step 4　三個力 $$C_c=0.85(350)(24.67)(60)=440{,}355\ \text{kgf}$$ $$C'_s=32.572\,(4200-297.5)=127{,}112\ \text{kgf},\qquad T=32.572\times4200=136{,}802\ \text{kgf}$$ $$P_b=440{,}355+127{,}112-136{,}802=430{,}665\ \text{kgf}\approx 430.7\ \text{tf}$$ Step 5　最大彎矩（對形心 30 cm） $$M_n=440{,}355(30-12.335)+127{,}112(30-8)+136{,}802(52-30)=13{,}585{,}000\ \text{kgf·cm}=\boxed{135.9\ \text{tf·m}}$$ Step 6　φ 值 —— 這裡最容易掉分 平衡點的 \(\varepsilon_t=\varepsilon_y=0.00206\)，已略大於 0.002，所以是過渡區起點，不是純壓力控制： $$\phi=0.65+\frac{0.00206-0.002}{0.003}\times0.25=0.655$$ $$\phi M_{n,\max}=0.655\times135.9=\boxed{89.0\ \text{tf·m}},\qquad \phi P_b=0.655\times430.7=282\ \text{tf}$$
答案的自我檢查（兩個都做）：
① 與純軸壓比：\(\phi P_{n,\max}=0.65\times0.80\times1325=689\) tf。平衡點 \(\phi P_b=282\) tf， 約為 41% —— 對稱配筋柱的平衡點軸力典型落在 \(0.3\sim0.5\,P_o\) 之間 ✔。
② 與純彎比：同一斷面令 \(P_n=0\) 解得 \(c = 8.60\) cm（\(a = 6.88\) cm），\(M_n = 65.8\) tf·m。 平衡點 135.9 tf·m 是它的 2.06 倍 —— 對稱配筋柱的典型倍率就落在 1.8–2.2。 若你算出「平衡點彎矩比純彎還小」，一定算錯了。
本節因果鏈：c < cb 時拉力被 fy 鎖死 → 增加 c 只賺不賠 → Mn 遞增； c > cb 拉力開始衰減 → Mn 遞減 → 峰值必在 c = cb，「最大彎矩」＝「平衡點」

§4 φ 值與韌性：規範真正在管的不是強度，是「會不會事先給你警告」

本節主張：\(\phi\) 不是安全係數，是「破壞預警程度」的價格標籤。 延性破壞會先開裂、先大變形、先掉東西 → 有人來得及跑 → \(\phi\) 給你 0.90； 脆性壓碎沒有預兆 → \(\phi\) 砍到 0.65。這條邏輯貫穿 §0 的 0.80/0.85、§5 的圍束規定、§7 的強柱弱梁。
圖 4-1　\(\phi\)–\(\varepsilon_t\) 分段圖。螺旋柱整段被抬高 0.10，理由只有一個：螺旋筋提供連續圍束， 壓碎過程有預兆（見 §5）。\(\varepsilon_t\) 的計算只看最外層拉力筋 \(d_t\)，不是鋼筋重心 \(d\) —— 三排配筋時這兩個不一樣。

4.1 過渡區插值：兩種寫法都對，但要挑一種

4.2 柱的曲率韌性 \(\mu_\phi\)：兩條不同的中性軸

為什麼算韌性要算兩次中性軸？
\(\mu_\phi = \phi_u/\phi_y\)，分子分母是兩個完全不同的狀態：
  • \(\phi_y\)（降伏曲率）發生在服務載重下、混凝土還在線彈性 → 應力是三角形分布 → 用轉換斷面法解彈性中性軸 \(k_yd\)， \(\phi_y = \dfrac{\varepsilon_y}{d-k_yd}\)
  • \(\phi_u\)（極限曲率）發生在極限狀態、混凝土已進入塑性 → Whitney 應力塊 → 解 \(c_u\)， \(\phi_u = \dfrac{\varepsilon_{cu}}{c_u}\)
兩個中性軸位置數值上可能很接近（RC-2011-3 是 24.96 與 24.92 cm），但物理來源完全不同，絕不能只算一次。 服務載重由 \(N = P_u/\gamma\) 反推（\(\gamma\) 是題目給的載重係數，如 1.3）。

手算範例 C｜RC-2011-3（2011）：過渡區 φ ＋ 曲率韌性

矩形柱 \(b=40,\ h=60\) cm，6-#10 分三排（每排 2 根，\(A_i = 16.286\) cm²）， \(d_1=6\)、\(d_2=30\)（正好在形心）、\(d_3=54\) cm。\(f'_c=350\)、\(f_y=4200\)。 給 \(P_u = 0.9P_b\)，求 \(\phi M_n\)；再求 \(\mu_\phi\)（\(\gamma = 1.3\)）。

Step 1　先求平衡點 $$c_b=\tfrac{6120}{10320}\times54=32.02\ \text{cm}\;\Rightarrow\;a_b=25.62\ \text{cm}\;\Rightarrow\;P_b=306.3\ \text{tf}$$ （中排 \(d_2=30 < a_b\)，在應力塊內，也要扣 \(0.85f'_c\)）
Step 2　\(P_u = 0.9P_b = 275.7\) tf，反解 c
把 \(P_n(c)\) 寫成代數式並令其等於 275.7 tf。中排在 \(c\) 附近，需先判斷 \(c\) 落在 30 的哪一側： $$9520c^2-180{,}893c-2{,}990{,}130=0\;\Rightarrow\;c_u=29.60\ \text{cm}\;(<30\ \checkmark\ \text{中排在拉力側})$$ Step 3　\(\varepsilon_t\) 與 \(\phi\) $$\varepsilon_t=0.003\times\frac{54-29.60}{29.60}=0.002473$$ $$\phi=0.65+0.25\times\frac{0.002473-0.002059}{0.005-0.002059}=0.685$$ $$M_n = 82.84\ \text{tf·m}\;\Rightarrow\;\phi M_n = 0.685\times82.84=\boxed{56.75\ \text{tf·m}}$$ Step 4　韌性（兩條中性軸） $$\text{彈性：}\;11{,}556k^2+417{,}303k-17{,}609{,}490=0\;\Rightarrow\;k_yd=24.96\ \text{cm},\quad \phi_y=\frac{\varepsilon_y}{d-k_yd}=7.09\times10^{-5}$$ $$\text{塑性：}\;9520c^2-117{,}293c-2{,}990{,}130=0\;\Rightarrow\;c_u^*=24.92\ \text{cm},\quad \phi_u=\frac{0.003}{24.92}=1.204\times10^{-4}$$ $$\mu_\phi=\frac{1.204\times10^{-4}}{7.09\times10^{-5}}=\boxed{1.70}$$
答案的自我檢查：\(\mu_\phi = 1.70\) —— 這個數字小得應該讓你警覺。 RC 梁的曲率韌性動輒 5–15，柱只有 1.7。為什麼？因為軸力把中性軸推得很深，\(\phi_u = 0.003/c_u\) 就被壓小了。 這正是本講義 §0 那句話的後半：軸壓對延性只有傷害。 也正是耐震規範要求柱端加圍束箍筋（§5）、要求強柱弱梁把塑鉸趕去梁上（§7）的根本原因。 若你算出柱的 \(\mu_\phi > 4\)，八成是把 \(\phi_y\) 或 \(\phi_u\) 算錯了。
本節因果鏈：軸力 ↑ → c ↑ → εt ↓ → φ ↓（強度打折）且 φu = 0.003/c ↓（韌性下降）→ 柱的天然韌性遠低於梁 → 必須靠圍束（§5）與強柱弱梁（§7）補回來

§5 圍束：用側向壓力把混凝土「關起來」

本節主張：混凝土在三軸受壓下比單軸強得多，也韌得多。橫向鋼筋的真正工作不是抗剪，是「不讓混凝土往旁邊膨脹」。 螺旋筋（\(f'_{cc}\)、\(\rho_s\)）與耐震箍筋（\(A_{sh}\)）是同一個物理的兩種寫法。
圖 5-1　圍束的物理。混凝土受壓時會橫向膨脹（泊松效應）；橫向鋼筋被撐開後張力反作用， 給核心一個側向壓力 \(f_L\)，把單軸壓縮變成三軸壓縮。強度和韌性都因此提升，但韌性提升遠大於強度提升 —— 這才是耐震規範真正想要的東西。
4.1 這個係數是怎麼來的？ 出自 Richart（1928）對混凝土做三軸壓縮試驗的迴歸：\(f'_{cc}=f'_c+4.1f_L\)。 它是實驗結果，不是推導出來的。物理意義：每施加 1 單位的側壓，軸向強度可以多拿 4.1 單位 —— 這個「四倍多的槓桿」正是圍束值得做的原因。
Mander（1988）模型更精細（\(f'_{cc}\) 與 \(f_L/f'_c\) 呈非線性），但考試用 Richart 的線性式即可。

5.1 螺旋柱：\(\rho_s\)、\(f_L\)、\(f'_{cc}\) 的一條鏈

$$\rho_s=\frac{\text{螺旋筋體積}}{\text{核心混凝土體積}}=\frac{4A_{sp}}{D_{c,cc}\cdot s}, \qquad f_L=\frac{\rho_s f_{yt}}{2},\qquad f'_{cc}=f'_c+4.1f_L$$
\(f_L = \rho_s f_{yt}/2\) 的 2 是哪來的？從一個切開的半圓自由體圖： 沿直徑切開，兩側各有一根螺旋筋被切斷，提供 \(2A_{sp}f_{yt}\) 的張力； 它必須平衡側壓 \(f_L\) 作用在投影面積 \(D_{c,cc}\cdot s\) 上： $$2A_{sp}f_{yt}=f_L\,D_{c,cc}\,s \;\Rightarrow\; f_L=\frac{2A_{sp}f_{yt}}{D_{c,cc}s} =\frac{f_{yt}}{2}\cdot\underbrace{\frac{4A_{sp}}{D_{c,cc}s}}_{\rho_s}$$ 「切一半、兩根筋」—— 這就是那個 2。跟壓力容器的環向應力是同一個推導。

手算範例 D｜RC-2010-1（2010）：圓形螺旋柱的 \(P_y\) 與 \(P_u\)

圓柱外徑 \(D=75\) cm，螺旋筋外徑 \(D_c=68\) cm，主筋 12-#10（\(A_b=8.17\)）， 螺旋筋 #4 @ 10 cm（\(A_{sp}=1.27\)，\(d_b=1.27\)）。\(f'_c=350\)、\(f_y=f_{yt}=4200\)。

Step 1　三個面積，三種定義（最容易混） $$A_g=\pi(37.5)^2=4417.9,\quad A_{ch}=\pi(34)^2=3631.7,\quad A_{st}=12\times8.17=98.04\ \text{cm}^2$$ \(A_{ch}\) 用螺旋筋外緣直徑 68；但 \(\rho_s\) 要用中心到中心直徑 \(D_{c,cc}=68-1.27=66.73\) cm。兩者不同。
Step 2　\(P_y\)：蓋層還在，用全斷面 $$P_y=0.85(350)(4417.9-98.04)+4200(98.04)=1{,}697\ \text{tf}$$ Step 3　\(\rho_s\) 與最小值檢核 $$\rho_s=\frac{4(1.27)}{66.73\times10}=0.00761,\qquad \rho_{s,\min}=0.45\left(\frac{4417.9}{3631.7}-1\right)\frac{350}{4200}=0.00812$$ $$0.00761<0.00812\;\Rightarrow\;\boxed{\text{不合規範}}$$ Step 4　\(f_L\)、\(f'_{cc}\)、\(P_u\)：蓋層剝落，只剩核心 $$f_L=\frac{0.00761\times4200}{2}=15.99,\qquad f'_{cc}=350+4.1(15.99)=415.6\ \text{kgf/cm}^2$$ $$P_u=415.6(3631.7-98.04)+4200(98.04)=1{,}880\ \text{tf}$$ Step 5　結論 $$P_u=1880>P_y=1697\ \checkmark\quad\text{但}\ \rho_s<\rho_{s,\min}\ \text{✘（規範仍不通過）}$$
\(\rho_{s,\min}\) 公式的物理意義（懂了就不用背）： 規範要求「蓋層剝落所損失的強度，必須由圍束帶來的強度提升補回來」，即 \(P_u \ge P_y\)。 把 Step 2、4 的式子相減、代入 \(f'_{cc}=f'_c+4.1\rho_sf_{yt}/2\) 整理，就得到 \(\rho_s\ge 0.45\left(\frac{A_g}{A_{ch}}-1\right)\frac{f'_c}{f_{yt}}\)。
\(\left(\frac{A_g}{A_{ch}}-1\right)\) 就是「蓋層佔核心的比例」 —— 蓋層越厚，要補的越多，完全合理。
極限檢查：\(A_g\to A_{ch}\)（沒有蓋層）→ \(\rho_{s,\min}\to 0\) ✔。
本題的弔詭：\(P_u > P_y\) 卻仍不合規 —— 因為 ACI 用 0.45 而非剛好相等的係數，多留了餘裕。 遇到這種「檢核通過但規範不通過」的情形，兩個結論都要寫。

5.2 耐震箍筋 \(A_{sh}\)：同一個物理，方形版

$$A_{sh}\ge\max\left[\;0.3\,\frac{s\,b_c\,f'_c}{f_{yt}}\left(\frac{A_g}{A_{ch}}-1\right),\;\;0.09\,\frac{s\,b_c\,f'_c}{f_{yt}}\;\right]$$
兩式為什麼要取大值？兩者管的東西不一樣：
  • 第一式（含 \(A_g/A_{ch}-1\)）：和螺旋柱的 \(\rho_{s,\min}\) 同源 —— 補償蓋層剝落。 柱斷面越大、保護層佔比越小，這一式越寬鬆。
  • 第二式（0.09 定值）：不管斷面多大，都要有基本的韌性。 大斷面柱如果只用第一式會得到很小的 \(A_{sh}\)，但耐震要的是塑鉸轉動能力，不是只補強度。這一式是地板。
極限檢查：柱斷面 \(\to\infty\)（保護層佔比 \(\to0\)）→ 第一式 \(\to0\)，第二式仍在 → 取第二式，符合設計直覺 ✔。

手算範例 E｜RC-2004-3（2004）：反求箍筋間距

柱 50×50 cm，主筋 8-D25，箍筋與繫筋均 D13（\(a_b=1.29\)，\(f_{yh}=2800\)）， 外箍 1 組 + 每方向繫筋 1 支 → 每方向有效肢數 3，\(A_{sh}=3\times1.29=3.87\) cm²。\(f'_c=280\)。

把 \(A_{sh}\) 當已知，反解 \(s\)：

$$s_1=\frac{A_{sh}f_{yt}}{0.3\,b_c f'_c\!\left(\frac{A_g}{A_{ch}}-1\right)}=7.36\ \text{cm}, \qquad s_2=\frac{A_{sh}f_{yt}}{0.09\,b_c f'_c}=10.24\ \text{cm}$$

\(A_{sh}\) 取兩式大值 \(\;\Longleftrightarrow\;\) \(s\) 取兩式小值：

$$s\le\min(7.36,\,10.24)=7.36\;\Rightarrow\;\boxed{\text{採用 } s = 7.0\ \text{cm}}$$

再與間距上限交叉檢核（三者取最小）：

$$s\le\min\left(\frac{b_c}{4},\;6d_{b,\text{縱筋}},\;s_o\right),\qquad s_o=10+\frac{35-h_x}{3}\ \text{cm}$$
倒數關係搞反是本題最大陷阱。\(A_{sh}\) 與 \(s\) 在公式裡成正比，所以 「\(A_{sh}\) 取大」等於「\(s\) 取小」。有人先算出兩個 \(s\) 然後取大值 → 箍筋放太疏 → 完全失去圍束效果。
另一個陷阱：\(b_c\) 是箍筋中心線圍成的核心尺寸，\(A_{ch}\) 是箍筋外緣圍成的核心面積。兩個不同的邊界，別混用。

§6 細長柱：P-M 圖沒錯，是你送進去的彎矩太小

本節主張：細長效應不會改變斷面的 P-M 曲線，它改變的是「設計點的位置」。 柱一彎，軸力就多產生一個 \(P\cdot\Delta\) 的附加彎矩；規範不叫你重畫 P-M 圖， 而是叫你把 \(M_2\) 放大成 \(M_c=\delta_{ns}M_2\) 再拿去比對。
圖 6-1　P-Δ 效應的三格故事。關鍵在第③格：這是正回饋， 不是「加一個修正項」就結束的線性問題。放大係數的分母 \(1-P_u/0.75P_c\) 正是這個無窮級數收斂後的結果。
\(\delta_{ns}=\dfrac{C_m}{1-P_u/(0.75P_c)}\) 的分母是幾何級數的和，不是憑空定的。
第一輪：軸力在初始撓度 \(\Delta_0\) 上產生附加彎矩 → 多彎 \(\alpha\Delta_0\)； 第二輪再多彎 \(\alpha^2\Delta_0\)……總撓度 $$\Delta=\Delta_0(1+\alpha+\alpha^2+\cdots)=\frac{\Delta_0}{1-\alpha},\qquad \alpha=\frac{P_u}{P_c}$$ 所以放大係數天生長成 \(\dfrac{1}{1-P/P_c}\)。ACI 把分母的 \(P_c\) 打 0.75 折， 是為了涵蓋 \(EI\) 的估算離散度（混凝土開裂程度無法準確預測）。
極限檢查：\(P_u\to0\Rightarrow\delta_{ns}\to C_m\)（沒有二階效應）✔； \(P_u\to0.75P_c\Rightarrow\delta_{ns}\to\infty\)（挫屈）✔。 算出負的 \(\delta_{ns}\) 代表 \(P_u>0.75P_c\)，柱已經挫屈，不是「取絕對值」，是要重新設計斷面。

6.1 三個容易寫錯的細節

項目正確做法為什麼
\(M_1/M_2\) 的正負號單曲度取正、雙曲度取負；\(M_2\) 是絕對值較大的端彎矩單曲度時柱整段同向彎，跨中撓度大 → 二階效應嚴重；雙曲度是 S 形，跨中反曲點附近撓度小 → 二階效應輕微。負號讓門檻值 \(34-12(M_1/M_2)\) 變大（更不容易被判定為細長），完全合理
\(C_m=0.6+0.4(M_1/M_2)\ge0.4\)只用於無側移且桿間無橫向載重；否則 \(C_m=1.0\)\(C_m\) 是「把非均勻彎矩換算成等值均勻彎矩」的係數。均勻彎矩（\(M_1=M_2\)，單曲度）最不利 → \(C_m=1.0\)；雙曲度最有利 → 下限 0.4
迴轉半徑 \(r\) 的方向對矩形斷面：\(r=\sqrt{I/A}=h/\sqrt{12}=0.289h\)，\(h\) 是彎曲平面內的斷面深度繞 X 軸彎曲用 Y 方向尺寸。50×70 柱的兩個方向 \(r\) 不同，細長比也不同 —— RC-2004-4 就在考這個

手算範例 F｜RC-2006-2（2006）：無側移細長柱的放大彎矩

方形柱 50×50 cm，8-#10。\(l_u=600\) cm，\(k=0.9\)，\(f'_c=280\)、\(f_y=4200\)， \(P_u=400\) tf，\(\beta_d=0.3\)，\(M_1=15\)、\(M_2=27\) tf·m，單曲度。

Step 1　要不要考慮細長效應？ $$r=\frac{50}{\sqrt{12}}=14.43\ \text{cm},\qquad \frac{kl_u}{r}=\frac{0.9\times600}{14.43}=37.4$$ $$34-12\left(\frac{M_1}{M_2}\right)=34-12\left(+\frac{15}{27}\right)=27.3\quad(\text{單曲度取正})$$ $$37.4>27.3\;\Rightarrow\;\boxed{\text{必須考慮細長效應}}$$ Step 2　有效彎曲剛度 \(EI\) $$E_c=15000\sqrt{280}=250{,}998,\qquad I_g=\frac{50^4}{12}=520{,}833\ \text{cm}^4$$ $$EI=\frac{0.4E_cI_g}{1+\beta_d}=\frac{0.4(250998)(520833)}{1.3}=4.022\times10^{10}\ \text{kgf·cm}^2$$ Step 3　臨界載重 $$P_c=\frac{\pi^2EI}{(kl_u)^2}=\frac{\pi^2(4.022\times10^{10})}{(540)^2}=1{,}361\ \text{tf}$$ Step 4　\(C_m\) 與 \(\delta_{ns}\) $$C_m=0.6+0.4\left(\frac{15}{27}\right)=0.822$$ $$\delta_{ns}=\frac{0.822}{1-\dfrac{400}{0.75\times1361}}=\frac{0.822}{1-0.392}=1.352\;\;(\ge1.0\ \checkmark)$$ Step 5　設計彎矩 $$M_c=\delta_{ns}M_2=1.352\times27=\boxed{36.5\ \text{tf·m}}$$
答案的三重自我檢查：
① \(P_u/0.75P_c=0.392\) —— 落在 0.2–0.6 是健康的細長柱。若 > 0.8，斷面明顯不足。
② \(\delta_{ns}=1.35\) —— 一般考題答案落在 1.1–1.6。算出 > 3 或 < 1 都要回頭檢查。
③ \(0.4E_cI_g\) 中的 0.4：這是「開裂＋潛變後的殘餘剛度」粗估。 純彈性用 \(E_cI_g\)、全開裂用 \(E_cI_{cr}\approx0.3E_cI_g\)，0.4 落在兩者之間，方向正確。 再除以 \((1+\beta_d)\) 是因為持續載重造成潛變，讓柱長期下更軟。\(\beta_d\) 越大 → \(EI\) 越小 → \(P_c\) 越小 → \(\delta_{ns}\) 越大，全部同向，好記。
細長柱與 P-M 圖的正確接法：細長效應算完後，你手上是 \((P_u,\,M_c)\)。 拿這一組去和原本那張沒有改變的 P-M 互制圖比對。 常見錯誤是「把 \(\delta_{ns}\) 拿去折減 P-M 曲線」——方向完全反了。 放大的是需求（\(M\)），不是折減容量。
本節因果鏈：柱有初始撓度 → Pu·Δ 產生附加彎矩 → 更彎 → 正回饋 → 撓度收斂成 Δ₀/(1−Pu/Pc) → δns = Cm/(1−Pu/0.75Pc) → Mc = δns·M2 送進原本那張 P-M 圖

§7 柱在系統中：強柱弱梁、接頭剪力、加大柱

本節主張：前六節把柱當成一個孤立斷面。但考題的另一半（8 題副分類）問的是「這根柱和旁邊的梁、和接頭、和舊柱怎麼互動」。 共同主軸仍然是 §4 那句話：柱的韌性天生比梁差，所以想辦法別讓柱先壞。

7.1 強柱弱梁：把塑鉸趕到梁上去

$$\sum M_{nc}\ \ge\ \frac{6}{5}\sum M_{nb}$$
為什麼一定要梁先壞？看崩塌機構就懂了：
  • 梁式機構（塑鉸在梁端）：每一層每一支梁都要形成塑鉸，結構才會倒。 塑鉸數量多 → 消能點多 → 變形分散到整棟樓 → 需要的總能量大。
  • 層崩塌機構（塑鉸在柱端）：只要一層的柱上下端形成塑鉸，那一層就整層側倒（軟腳層）。 塑鉸數量少、變形全部集中在一層 → 那一層的柱要承受極大轉角 → 而柱的 \(\mu_\phi\) 只有 1.7（§4） → 立刻崩塌。
6/5 = 1.2 這個數字不是安全係數，是「模型誤差補償」：實際梁的強度會因鋼筋超強（\(f_y\) 實際值高於標稱）、 樓版鋼筋參與受拉而高於計算值。1.2 是給這些沒算到的東西留的餘裕。
強柱弱梁的三個常錯： ① \(M_{nc}\) 要用當時軸力下的柱彎矩強度（從 P-M 圖讀），不是純彎；地震往復所以要取上下兩個方向較不利者。 ② \(M_{nb}\) 取梁兩側正負彎矩的對應組合（左梁負彎矩 + 右梁正彎矩），不是隨便取大值。 ③ 不滿足時的對策是加大柱或增加柱縱筋，不是減少梁鋼筋（梁鋼筋是撓曲需求決定的，不能亂減）。

7.2 梁柱接頭剪力：γ 係數只有三個數字

$$\phi V_{jh,n}=\phi\,\gamma\sqrt{f'_c}\,A_j\qquad \gamma=\begin{cases}\text{內部接頭（四面有梁）} & 1.0\;(\text{SI: }1.7)\\ \text{T 形／外接頭（三面）} & 0.75\;(\text{SI: }1.25)\\ \text{L 形角柱接頭（兩面）} & 0.50\;(\text{SI: }1.0)\end{cases}$$
γ 為什麼隨「幾面有梁」遞減？因為接頭核心靠斜壓桿（diagonal strut）傳力， 而斜壓桿需要周圍的梁提供橫向圍束才不會鼓出去。 四面都有梁 → 核心被圍得最緊 → 可以拿滿 1.0；角柱只有兩面有梁 → 另兩面是自由面 → 只給一半。 這又是「圍束」這個概念的第三次出現（第一次是螺旋筋 §5.1，第二次是耐震箍筋 §5.2）。

接頭需求 \(V_{jh}\) 的算法：梁端上下拉壓力（用 \(1.25f_y\) 的 \(M_{pr}\) 反推）減去柱剪力。 單位注意：\(\gamma\) 的數值在 kgf/cm² 與 MPa 制下不同（表中括號為 MPa 制），代錯會差一個 \(\sqrt{10}\) 倍。 相關題：RC-2012-4（角隅外接頭）、 RC-2018-2（角柱接頭）。

7.3 加大柱（jacketing）：規範沒有的題，考的是你會不會回到第一原理

RC-2017-1 給了一個「原 40×40 加大成 40×70」的柱，並且自己定義一條雙折線混凝土應力應變關係 （上升段 0→0.002 線性到 \(1.0f'_c\)，下降段 0.002→0.003 線性降到 \(0.8f'_c\)）。 此時 Whitney 應力塊完全不能用 —— \(0.85f'_c\) 與 \(\beta_1\) 都是從「標準拋物線應力分布」等效出來的， 題目換了應力應變關係，等效係數當然要重算。

這種題的正確心態：回到 §1 的引擎，只換掉「應力怎麼從應變來」那一步。 應變相容不變、力平衡不變、對形心取矩不變。改的只有 \(C_c\)： 從「\(0.85f'_c \times a \times b\) 一個矩形」改成「把雙折線沿深度積分」。 能拆解成這三句話的人，這題其實比 RC-2015-1 還快（積分只是兩個梯形）。
RC-2017-1 的答案：\(\phi P_{n,\max}=330\) tf、\(P_{n,b}=634\) tf、\(M_{n,b}=89.3\) tf·m。
另外 RC-2017-2 接著問新舊混凝土介面的摩擦剪力 （shear friction，\(V_n=\mu A_{vf}f_y\)）—— 加大柱要能一起作用，介面必須傳得動剪力，否則兩塊各彎各的。
本節因果鏈：柱的 μφ 天生只有 1.7（§4）→ 柱端塑鉸 = 層崩塌 = 沒有備援 → 規範用三道防線把破壞推離柱：①強柱弱梁把塑鉸趕去梁 ②圍束箍筋讓柱端萬一出鉸也轉得動 ③接頭 γ 確保節點不先剪壞

§11 自我檢測：12 個「為什麼」

先自己回答，再展開對照。答不出來的題目，回到括號裡的節次重讀。

1. 為什麼柱的答案是一條曲線而不是一個數字？（§0）

因為未知數比方程式多一個。梁在 \(P=0\) 下，力平衡 \(C=T\) 直接把 \(c\) 定死；柱多了軸力 \(P_n\) 這個未知數， 同一組平衡式有無窮多組解。所以改成「掃描 \(c\)」，每個 \(c\) 都對應一組合法的 \((P_n,M_n)\)，連起來就是曲線。

2. 為什麼 P-M 曲線會鼓出來，而不是單調下降？（§0、§3）

低軸力時，斷面大半在受拉，加軸壓等於幫忙把裂縫壓住、力偶臂拉長 → \(M_n\) 隨 \(P\) 上升。 高軸力時斷面已幾乎全壓，再加軸力只是把混凝土容量拿去扛軸力 → \(M_n\) 下降。轉折在平衡點。

3. \(c_b\) 公式裡的 6120 是什麼？（§2）

\(\varepsilon_{cu}E_s=0.003\times2.04\times10^6=6120\)（kgf/cm²）。整條公式來自相似三角形 \(c_b/d_t=\varepsilon_{cu}/(\varepsilon_{cu}+\varepsilon_y)\)，上下同乘 \(E_s\) 而已。 SI 制自然變成 \(600/(600+f_y)\)。

4. 為什麼壓力鋼筋要扣 \(0.85f'_c\)，拉力鋼筋不用？（§1、§10-2）

Whitney 應力塊把整個深度 \(a\) 的矩形都當成混凝土在出力，包括鋼筋佔據的那一小塊面積。 如果鋼筋力再全額計入，那塊面積會被算兩次。拉力區的混凝土在 \(C_c\) 裡本來就沒被算（假設開裂不承拉），所以不用扣。 判準是「在不在應力塊 \(a\) 內」，不是「在不在壓力側」。

5. 為什麼純軸壓要再乘 0.80 或 0.85？兩者差別的物理理由是什麼？（§0、§2.1）

因為現實中不存在真正的零偏心 —— 施工偏差、梁端不對稱都會給小偏心。0.80 大約對應 \(e=0.10h\)、 0.85 對應 \(e=0.05h\)。螺旋柱可以放寬，是因為螺旋筋連續圍束、蓋層剝落後核心仍能出力，破壞有預兆（§5）。 這是幾何理由，跟 \(0.85f'_c\) 這個材料折減完全無關。

6. 為什麼「最大彎矩」發生在平衡點？（§3）

\(cc_b\) 後拉力筋掉出降伏，\(T\) 隨 \(c\) 快速衰減 → \(M_n\) 遞減。峰值只能在交界。

7. \(\phi\) 值的三個分區，背後的統一邏輯是什麼？（§4）

「破壞有沒有預警」。拉力控制＝鋼筋先降伏＝大變形、大裂縫、有人來得及跑 → 0.90； 壓力控制＝混凝土先壓碎＝沒有預兆、瞬間崩落 → 0.65。螺旋柱因圍束而有預兆，整段抬高到 0.75。 同一條邏輯也解釋了 0.80/0.85 上限（§0）與耐震圍束規定（§5）。

8. 柱的曲率韌性 \(\mu_\phi\) 通常只有 1.7 左右，遠低於梁的 5–15。為什麼？後果是什麼？（§4.2）

因為軸力把中性軸推得很深，\(\phi_u=\varepsilon_{cu}/c_u\) 直接被 \(c_u\) 壓小。 後果是耐震設計必須：① 用圍束箍筋提高 \(\varepsilon_{cu}\)（§5）；② 用強柱弱梁把塑鉸趕到梁上（§7.1）。 柱端一旦出鉸就是層崩塌，沒有備援。

9. \(f_L=\rho_sf_{yt}/2\) 裡的 2 是怎麼來的？（§5.1）

沿直徑切開螺旋柱的自由體：切面兩側各有一根螺旋筋被切斷，共 \(2A_{sp}f_{yt}\) 的張力， 平衡側壓 \(f_L\) 作用在投影面積 \(D_{c,cc}s\) 上。跟壓力容器環向應力的推導完全相同。

10. \(A_{sh}\) 為什麼有兩個公式且取大值？（§5.2）

第一式（含 \(A_g/A_{ch}-1\)）是補償蓋層剝落的強度損失，與螺旋柱的 \(\rho_{s,\min}\) 同源； 第二式（0.09 定值）是不管斷面多大都要有的基本韌性。大斷面柱只用第一式會得到過小的箍筋量， 所以要有這條地板。極限檢查：斷面 \(\to\infty\) 時第一式 \(\to0\)，第二式仍在 ✔。

11. \(\delta_{ns}\) 分母的 \(1-P_u/0.75P_c\) 為什麼長這樣？0.75 又是什麼？（§6）

P-Δ 是正回饋：每一輪附加彎矩造成更多撓度。總撓度是幾何級數 \(\Delta_0/(1-P/P_c)\)， 所以放大係數天生長成 \(1/(1-P/P_c)\)。0.75 是對 \(P_c\) 打折 —— 因為 \(EI\)（混凝土開裂程度）估算離散度大。

12. 題目自訂一條雙折線混凝土應力應變關係時，為什麼不能用 \(0.85f'_c\) 和 \(\beta_1\)？（§7.3）

因為這兩個係數是專門為了「等效替代標準拋物線應力分布」而迴歸出來的 —— 它們讓矩形塊的 合力大小與作用位置都與拋物線一致。換了應力應變曲線，等效條件就不成立，必須重新沿深度積分求 \(C_c\) 與其形心位置。應變相容與力平衡則完全不變。

★ §12 精選 5 題：時間有限就練這幾題

選題邏輯：不是挑「最常考」，而是挑「一題練到最多獨立技能、彼此重疊最少」。 下面五題涵蓋本單元約 60% 的考點權重，但更重要的是它們涵蓋了全部五種思考模式： 條件直讀、反解方程、圍束物理、二階效應、規範外推。

★ 1｜RC-2011-3（2011）— 投報率最高的一題

為什麼選它：一題吃掉四個獨立技能 —— 平衡點計算、由 \(P_u\) 反解 \(c\) 的二次方程、 過渡區 \(\phi\) 內插、曲率韌性（彈性＋塑性兩條中性軸）。本單元沒有第二題的密度這麼高。 而且它逼你面對「中排鋼筋在形心、力臂為零」這個 3 題共用的關鍵細節。

★ 2｜RC-2008-2（2008）— 觀念鏈題，計算量最小

先讀：§1.2（三種入口）、§1.3（三張圖並排）、§2.2（範例 A）

做完要能回答：① 為什麼 \(\varepsilon_t=0\) 可以直接讀出 \(c\)？ ② 中排明明在壓力區，為什麼它的應力不是 \(f_y\)？ ③ 若把條件改成「拉力筋剛好降伏」，\(c\) 會變大還是變小，\(M_n\) 呢？（答案：\(c\) 變小、\(M_n\) 變大 —— 走向平衡點）

★ 3｜RC-2010-1（2010）— 圍束物理的唯一完整訓練

為什麼選它：本單元只有這一題把圍束的整條鏈走完：\(\rho_s\to f_L\to f'_{cc}\to P_u\)， 再加上 \(\rho_{s,\min}\) 檢核與 \(P_y\) vs \(P_u\) 的比較。別題練不到。 而且它有個很好的教學價值：算出 \(P_u>P_y\) 但 \(\rho_s<\rho_{s,\min}\) —— 檢核通過、規範不通過。 考場上遇到這種矛盾要有膽量把兩個結論都寫出來。

先讀：§5.1（含 \(f_L\) 的推導與 \(\rho_{s,\min}\) 的物理意義）

做完要能回答：① \(A_g\)、\(A_{ch}\)、\(D_{c,cc}\) 三個幾何量分別以哪個邊界為準？ ② \(\rho_{s,\min}\) 公式裡的 \(\left(\frac{A_g}{A_{ch}}-1\right)\) 代表什麼？ ③ 為什麼 \(P_y\) 用全斷面而 \(P_u\) 只用核心？

★ 4｜RC-2006-2（2006）— 細長柱的完整流程

為什麼選它：RC-2004-4 與 RC-2016-3 都只做到「判斷要不要放大」； 只有這題把 \(E_c\to I_g\to EI\to P_c\to C_m\to\delta_{ns}\to M_c\) 整條算完。 細長柱題型的計算流程只需要練一次就會，練這題最划算。

§13 全部因果鏈重列（可以用嘴巴講出來就算懂了）

① 柱比梁多一個未知數（軸力）→ 力平衡不足以定住 c → 只能掃描 c → 答案是一條曲線，不是一個數字
② 平面保持平面 → 應變是直線 → εcu = 0.003 釘住一端 → 一個 c 定住整條線 → 每排 εi → fsi = clip(Es·εi, ±fy) → Pn 與 Mn 都是 c 的函數，這是唯一的引擎
③ c < cb 時拉力被 fy 鎖死、加 c 只賺不賠 → Mn 遞增；c > cb 拉力衰減 → Mn 遞減 → Mn 的峰值＝平衡點＝「最大彎矩」題的答案，約為純彎的 2 倍
④ εt 大＝鋼筋先降伏＝大變形有預警 → φ = 0.90；εt 小＝混凝土先壓碎＝無預警 → φ = 0.65 → 同一條「有沒有預警」邏輯也解釋了 0.80/0.85 上限、螺旋柱的 0.75、以及全部耐震規定
⑤ 軸力 ↑ → c ↑ → φu = 0.003/c ↓ → 柱的 μφ 只有 1.7，遠不如梁的 5–15 → 柱端塑鉸＝層崩塌＝沒有備援 → 必須靠圍束與強柱弱梁補救
⑥ 混凝土受壓橫向膨脹 → 橫向鋼筋被撐開產生張力 → 反作用給核心側壓 fL → 三軸受壓 → f'cc = f'c + 4.1fL、εcu 大幅提升 → 強度小漲、韌性大漲 → ρs,min 與 Ash 兩式＝「補回蓋層 ＋ 保底韌性」
⑦ 柱有撓度 → Pu·Δ 產生附加彎矩 → 更彎 → 正回饋 → 幾何級數收斂成 1/(1−P/Pc) → δns = Cm/(1−Pu/0.75Pc) → 放大的是需求 Mc，P-M 圖原封不動
⑧ Whitney 的 0.85f'c 與 β1 是為了等效「標準拋物線」而迴歸的 → 題目換一條應力應變曲線，這兩個係數就失效 → 但應變相容、力平衡、對形心取矩三件事永遠不變
