解題流程圖

基本剪力Vc + Vs 設計流程

1
確認臨界斷面位置
均布載重：距支承面 d 處；集中載重或懸臂梁：支承面
↓
2
計算 Vc（選簡化或詳細公式）
簡化：Vc = 0.53√f'c·bw·d；詳細：含 ρw、Vu·d/Mu 項
↓
3
判斷箍筋需求程度
Vu ≤ φVc/2 → 不需箍筋
φVc/2 < Vu ≤ φVc → 最小箍筋
Vu > φVc → 需計算 Vs
4
計算 Vs 需求
Vs = Vu/φ − Vc；Av/s = Vs/(fy·d)
↓
5
檢查 Vs 上限 & 箍筋間距
Vs ≤ (2/3)√f'c·bw·d（否則加大斷面）
Vs ≤ (1/3)√f'c·bw·d：s ≤ d/2；否則：s ≤ d/4

軸力修正含軸力構件剪力 Vc

1
判斷軸力性質（壓或拉）
Nu > 0：軸壓（增加剪力強度）；Nu < 0：軸拉（降低剪力強度）
↓
2
使用簡化修正公式
軸壓：Vc = 0.53(1 + Nu/140Ag)√f'c·bw·d
軸拉：Vc = 0.53(1 + Nu/35Ag)√f'c·bw·d（Nu 為負）
↓
3
或使用詳細公式（含 Mm）
Vc 詳細式含等效彎矩 Mm = Mu − Nu(4h−d)/8
若 Mm < 0 → Vc 取簡化式上限值（表示強軸壓，Vc 達最大）
4
軸拉時若 Vc < 0 → Vc = 0
強軸拉力使混凝土完全開裂，Vs 須承擔全部剪力

STM 深梁壓拉桿模式設計

1
確認構件為深梁
Ln/h < 4（深梁）或剪力跨度 a/d < 2
↓
2
建立壓拉桿模型（桁架）
確認壓桿角度 θ ≥ 25°；辨認節點類型（CCC / CCT / CTT）
↓
3
計算壓桿與節點強度
壓桿：fce = 0.85·βs·f'c；節點：fn = 0.85·βn·f'c
↓
4
設計拉力桿（縱向鋼筋）
Ast = Ftu / (φ·fy)，φ = 0.75；須充分錨定於節點
↓
5
驗核各壓桿、節點不超限
φFns ≥ Fns_demand；節點處需考量多方向力合成

摩擦剪力介面剪力設計

1
確認介面條件，選擇 μ 值
一體澆置：μ = 1.4；粗糙施工縫：μ = 1.0；光滑施工縫：μ = 0.7
↓
2
計算所需摩擦鋼筋 Avf
Avf = Vu / (φ·μ·fy)，φ = 0.75
↓
3
驗核 Vn 上限
Vn ≤ min(0.2f'c·Ac, 5.5·Ac) tf，Ac = 介面面積（cm²）
↓
4
植筋設計（新舊混凝土結合）
確認鋼筋與結合面角度（垂直或斜交皆可計算），且鋼筋須在兩側充分錨定
Section 04
核心公式速查

🔴 混凝土剪力強度 Vc（kgf/cm² 單位）

簡化公式（大多數情況可用）：
$$V_c = 0.53\sqrt{f'_c}\, b_w\, d$$
詳細公式（含撓曲與軸力效應）：
$$V_c = \left(0.158\sqrt{f'_c} + 17.2\,\rho_w\frac{V_u d}{M_u}\right) b_w d \leq 0.29\sqrt{f'_c}\, b_w d$$
ρw = As/(bw·d)；Vu·d/Mu ≤ 1.0
詳細公式通常比簡化公式大，但需確認剪跨比與鋼筋比

🔵 含軸力時 Vc 修正（kgf/cm² 單位）

簡化修正（軸壓 Nu > 0，軸拉 Nu < 0）：
$$V_c = 0.53\!\left(1 + \frac{N_u}{140\,A_g}\right)\!\sqrt{f'_c}\, b_w d \quad \text{（軸壓）}$$
$$V_c = 0.53\!\left(1 + \frac{N_u}{35\,A_g}\right)\!\sqrt{f'_c}\, b_w d \quad \text{（軸拉，Nu 取負值）}$$
詳細公式等效彎矩（軸壓）：
$$M_m = M_u - N_u\frac{4h-d}{8}$$
Nu 以 kgf 代入，Ag 以 cm² 代入
Mm < 0 → Vc 取簡化式（即 Vc 已達上限）
軸拉使 Vc 降低，若 Vc < 0 則令 Vc = 0

🔴 箍筋剪力強度 Vs 與間距控制

Vs 設計：
$$V_s = \frac{V_u}{\phi} - V_c, \quad \frac{A_v}{s} = \frac{V_s}{f_y\, d}, \quad \phi = 0.75$$
最大箍筋間距：
$$s_{max} = \begin{cases} d/2 \text{ 且 } 60\text{ cm} & V_s \leq \frac{\sqrt{f'_c}}{3}b_w d \\ d/4 \text{ 且 } 30\text{ cm} & V_s > \frac{\sqrt{f'_c}}{3}b_w d \end{cases}$$
Vs 上限（超過須加大斷面）：
$$V_{s,max} = \frac{2}{3}\sqrt{f'_c}\, b_w\, d$$

🟢 摩擦剪力法（Shear Friction）

介面剪力強度：
$$V_n = \mu\, A_{vf}\, f_y, \quad \phi = 0.75$$
μ 值速查（正常重量混凝土）：
介面條件μ
一體澆置1.4
粗糙施工縫（≥6mm凹凸）1.0
光滑施工縫0.7
鋼材埋入混凝土0.7
Vn 上限：min(0.2f'c·Ac, 480+0.08f'c·Ac, 1670·Ac) [N, mm²]
或約 min(0.2f'c, 55.2 kgf/cm²) × Ac

🟣 壓拉桿模式（STM）強度係數

壓桿有效強度：fce = 0.85·βs·f'c
壓桿類型βs
稜柱形壓桿（一致寬度）1.0
瓶形壓桿（有橫向配筋）0.75
瓶形壓桿（無橫向配筋）0.60
拉力筋控制斷面0.40
節點有效強度：fn = 0.85·βn·f'c
節點類型βn
CCC（三壓桿交會）1.0
CCT（一拉力桿）0.80
CTT（二拉力桿）0.60
φ = 0.75；壓桿角度 θ ≥ 25°（相對於拉力桿）

🟠 剪力扭力組合 — 扭矩忽略門檻

可忽略扭矩條件（MPa 單位）：
$$T_u \leq \phi\frac{\sqrt{f'_c}}{12}\frac{A_{cp}^2}{p_{cp}}$$
kgf/cm² 單位等效：
$$T_u \leq \phi\frac{\sqrt{f'_c}}{4}\frac{A_{cp}^2}{p_{cp}}$$
Acp：斷面全面積（含保護層到外表面）
pcp：斷面外周長（含保護層到外表面）
φ = 0.75；若 Tu 超過門檻，扭矩與剪力需同時設計

Section 06
高頻陷阱 Top 8
基本剪力 臨界斷面的位置判斷
均布載重簡支梁：距支承面 d 處（不是 d/2）。懸臂梁、集中載重靠近支承（a < d）、支承面向下作用力：臨界斷面直接在支承面。錯判位置導致全部計算偏差。
基本剪力 φ = 0.75（剪力），不是 0.9
剪力設計的強度折減係數 φ = 0.75，不是彎矩設計的 0.9。Vu ≤ φVn = φ(Vc + Vs)，每個步驟都需注意 φ 值選用。部分考生在比較時誤用 0.9。
基本剪力 Vs,max 超限時需加大斷面，不是加密箍筋
Vs > (2/3)√f'c·bw·d 是上限，表示即使加再多箍筋也無法通過，必須加大梁深（增加 d）或加大梁寬（增加 bw）。許多考生繼續計算箍筋，方向錯誤。
軸力修正 軸壓修正係數 140、軸拉係數 35 不要互換
軸壓修正：係數為 140（分母大，增幅小）；軸拉修正：係數為 35（分母小，降幅大）。互換後答案差距 4 倍。記憶口訣：軸拉對結構傷害更大，所以係數更小（懲罰更重）。
軸力修正 Mm < 0 時 Vc 的處理
詳細公式中若 Mm = Mu − Nu(4h−d)/8 < 0，表示軸壓很大，此時 Vc 詳細式不適用（分母為負），應改用簡化式計算 Vc。許多考生代入負值 Mm 導致荒謬結果。
摩擦剪力 μ 值依介面條件，不是一律 1.4
施工縫（粗糙面）μ = 1.0，不是 1.4。一體澆置才是 1.4。光滑施工縫 μ = 0.7。題目若描述「施工縫」要用 1.0；若是「同一次澆置」才用 1.4。選錯差距 40%。
STM βs 瓶形壓桿有無配筋決定係數
瓶形壓桿（兩端寬中間窄的壓桿）：有橫向配筋 βs = 0.75，無橫向配筋 βs = 0.60。題目若沒說有配橫筋，預設用 0.60。許多考生直接用 0.75 高估強度。
剪扭門檻 Acp 和 pcp 用外圍總尺寸，非 Aoh 和 ph
忽略門檻判斷用 Acp（斷面全外圍面積，到表面）和 pcp（全外圍周長），而非箍筋中心圍成的 Aoh 和 ph。設計扭力強度才改用 Aoh/ph（塑性理論）。混用兩組幾何量是常見錯誤。
