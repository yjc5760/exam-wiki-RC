1. 原始題目重述 (Problem Restatement)

簡支預力梁，先架設（承受梁自重及版 DL），版硬化後形成組合斷面，施加均布活載重 $w_{LL} = 1.0$ tf/m²，求跨中斷面預力梁上緣（頂）及下緣（底）之混凝土應力。

已知條件：

項目 數值
梁跨度 $L$ 20 m = 2000 cm
梁斷面 $b=30$ cm，$h=80$ cm
梁 $f'_{c1}$ 350 kgf/cm²
版斷面 寬 200 cm，厚 15 cm
版 $f'_{c2}$ 280 kgf/cm²
有效預力 $P_e$ 210 tf = 210,000 kgf
c.g.s. 距梁底 15 cm
均布活載重 $w_{LL}$ 1.0 tf/m²（施於版上）
$\gamma_c$ 2400 kgf/m³（原卷未給，依常規假設，已在 §5 說明）

題目附圖：

圖說：簡支預力梁 30×80 cm，c.g.s. 距梁底 15 cm，梁偏心距 e=40-15=25 cm。梁間距 200 cm（梁中心各 100 cm），版寬 200 cm，版厚 15 cm（$f'_{c2}=280$ kgf/cm²）。有效預力 210 tf，$L=20$ m。

原卷原文（95 年第四題）核對： 「有一簡支預力梁，其跨度為 20 m，梁寬為 30 cm，梁全深為 80 cm，梁之 $f'_c$＝350 kgf/cm²。
在此梁中，預力損失後預力鋼鍵之有效預力為 210 tf。此梁在預力損失後開始吊裝，並在其上澆置 15 cm 厚樓版，
澆置樓版時利用梁作為支撐……當樓版硬化並與梁結合為一體後，再於樓版上施加 1.0 tf/m² 之均布活載重。
試求施加均布活載重後，跨度中央斷面預力梁上緣及下緣之混凝土所承受之應力為何？」
——「利用梁作為支撐」正是把版重指定給非組合梁的關鍵字；原卷未指定規範版本，也未給混凝土單位重。

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

兩階段施工順序：

  • Stage 1（非組合梁）： $P_e$ + 梁自重 + 版濕混凝土 DL → 作用於梁斷面
  • Stage 2（組合斷面）： $w_{LL}$ → 作用於組合轉換斷面

控制條件： 本題不要求驗算，只求應力值。

3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

步驟 工作
1 計算梁斷面性質（$A_1$, $I_1$, $S_{t1}$, $S_{b1}$）
2 Stage 1：預力 + 梁 SW + 版 DL → 梁頂/底應力
3 計算組合轉換斷面（$n=\sqrt{280/350}$）
4 Stage 2：$w_{LL}$ → 組合斷面增量應力
5 疊加得最終應力

三大陷阱：

陷阱 說明
⚠ 版 DL 作用在非組合梁 版尚未硬化時，版重由梁獨自承受
⚠ $n = \sqrt{f'_{c2}/f'_{c1}}$（非 1） 版混凝土較弱，需折減轉換
⚠ LL 在組合斷面上 版硬化後形成組合，活載重作用於組合截面

3.5 變數層次分析 (Variable Hierarchy Analysis)

最終目標

疊加 Stage1（預力+DL）和 Stage2（LL）應力，得梁頂梁底最終應力

本題關鍵公式鏈

$$\text{Stage 1: } f = \frac{P_e}{A_1} \pm \frac{P_e \cdot e}{S} \mp \frac{M_{S1}}{S}$$

$$n = \sqrt{\frac{f'_{c2}}{f'_{c1}}}, \quad b'_{slab} = b_{slab} \times n, \quad \bar{y} = \frac{\sum A_i y_i}{\sum A_i}$$

$$\text{Stage 2: } \Delta f = \pm \frac{M_{LL} \cdot y}{I_c}$$

4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

Step 1：非組合梁斷面性質

$$A_1 = 30 \times 80 = 2{,}400 \text{ cm}^2, \quad I_1 = \frac{30 \times 80^3}{12} = \frac{30 \times 512{,}000}{12} = 1{,}280{,}000 \text{ cm}^4$$

$$S_{t1} = S_{b1} = \frac{I_1}{h/2} = \frac{1{,}280{,}000}{40} = 32{,}000 \text{ cm}^3$$

偏心距：$e = \frac{h}{2} - 15 = 40 - 15 = \boxed{25 \text{ cm}}$

Step 2：Stage 1（非組合梁：$P_e$ + 梁 SW + 版 DL）

預力應力（壓縮為正）：

$$f_{top}^{PS} = \frac{P_e}{A_1} - \frac{P_e \cdot e}{S_{t1}} = \frac{210{,}000}{2{,}400} - \frac{210{,}000 \times 25}{32{,}000} = 87.50 - 164.06 = \boxed{-76.56 \text{ kgf/cm}^2 \text{ （拉）}}$$

$$f_{bot}^{PS} = \frac{P_e}{A_1} + \frac{P_e \cdot e}{S_{b1}} = 87.50 + 164.06 = \boxed{+251.56 \text{ kgf/cm}^2 \text{ （壓）}}$$

Stage 1 DL 荷載（作用於非組合梁）：

$$w_{beam} = 2400 \times \frac{30 \times 80}{10{,}000} = 576 \text{ kgf/m} = 5.76 \text{ kgf/cm}$$

$$w_{slab} = 2400 \times 0.15 \times 2.00 = 720 \text{ kgf/m} = 7.20 \text{ kgf/cm}$$

$$w_{S1} = 5.76 + 7.20 = 12.96 \text{ kgf/cm}$$

$$M_{S1} = \frac{12.96 \times 2000^2}{8} = 12.96 \times 500{,}000 = 6{,}480{,}000 \text{ kgf·cm}$$

Stage 1 DL 應力：

$$f_{top}^{S1,DL} = +\frac{M_{S1}}{S_{t1}} = +\frac{6{,}480{,}000}{32{,}000} = +202.50 \text{ kgf/cm}^2 \text{ （壓）}$$

$$f_{bot}^{S1,DL} = -\frac{M_{S1}}{S_{b1}} = -202.50 \text{ kgf/cm}^2 \text{ （拉）}$$

Stage 1 總應力（預力 + DL）：

$$f_{top}^{S1} = -76.56 + 202.50 = \boxed{+125.94 \text{ kgf/cm}^2 \text{ （壓）}}$$

$$f_{bot}^{S1} = +251.56 - 202.50 = \boxed{+49.06 \text{ kgf/cm}^2 \text{ （壓）}}$$

Step 3：組合轉換斷面

$$n = \sqrt{\frac{f'_{c2}}{f'_{c1}}} = \sqrt{\frac{280}{350}} = \sqrt{0.800} = 0.8944$$

轉換版寬：$b'_{slab} = 200 \times 0.8944 = 178.9$ cm

各子斷面（梁底起量）：

子斷面 面積 $A_i$ 形心 $y_i$
梁（30×80） 2,400 cm² 40 cm
轉換版（178.9×15） 2,683.2 cm² 80+7.5 = 87.5 cm

組合形心：
$$\bar{y} = \frac{2{,}400 \times 40 + 2{,}683.2 \times 87.5}{2{,}400 + 2{,}683.2} = \frac{96{,}000 + 234{,}780}{5{,}083.2} = \frac{330{,}780}{5{,}083.2} = \boxed{65.07 \text{ cm}}$$

各關鍵距離：

  • 梁底至形心：65.07 cm（$y_{bot}$）
  • 形心至梁頂：$80 - 65.07 = 14.93$ cm（$y_{beam,top}$）
  • 形心至版頂：$95 - 65.07 = 29.93$ cm

組合慣性矩：

$$I_{beam} = 1{,}280{,}000 + 2{,}400 \times (65.07 - 40)^2 = 1{,}280{,}000 + 2{,}400 \times 628.5 = 2{,}788{,}400 \text{ cm}^4$$

$$I_{slab} = \frac{178.9 \times 15^3}{12} + 2{,}683.2 \times (87.5 - 65.07)^2 = 50{,}310 + 2{,}683.2 \times 503.1 = 50{,}310 + 1{,}349{,}913 = 1{,}400{,}223 \text{ cm}^4$$

$$I_c = 2{,}788{,}400 + 1{,}400{,}223 \approx \boxed{4{,}188{,}700 \text{ cm}^4}$$

未取捨的精算值 $I_c = 4{,}188{,}695$ cm⁴（$\bar y = 65.074$ cm）。下方 $S$ 值以精算值計。

截面模數（梁材料）：
$$S_{comp,top} = \frac{I_c}{y_{beam,top}} = \frac{4{,}188{,}695}{14.93} = 280{,}622 \text{ cm}^3$$

$$S_{comp,bot} = \frac{I_c}{\bar{y}} = \frac{4{,}188{,}695}{65.07} = 64{,}369 \text{ cm}^3$$

$S_{comp,top}/S_{comp,bot} = 4.36$——組合斷面形心被樓版拉到很高（距梁底 65 cm，梁全深才 80 cm），
這是「同一個 $M_{LL}$ 在梁底造成的應力是梁頂的 4.4 倍」的來源，也是本題梁底吃不消的直接原因。

Step 4：Stage 2（組合斷面：$w_{LL}$ 均布活載重）

$$w_{LL} = 1.0 \text{ tf/m}^2 \times 2.0 \text{ m} = 2.0 \text{ tf/m} = 20.0 \text{ kgf/cm}$$

$$M_{LL} = \frac{20.0 \times 2000^2}{8} = 20.0 \times 500{,}000 = 10{,}000{,}000 \text{ kgf·cm}$$

LL 增量應力（作用於梁）：

$$\Delta f_{top}^{LL} = +\frac{M_{LL}}{S_{comp,top}} = +\frac{10{,}000{,}000}{280{,}552} = +\boxed{35.6 \text{ kgf/cm}^2 \text{ （壓）}}$$

$$\Delta f_{bot}^{LL} = -\frac{M_{LL}}{S_{comp,bot}} = -\frac{10{,}000{,}000}{64{,}372} = -\boxed{155.4 \text{ kgf/cm}^2 \text{ （拉）}}$$

Step 5：施加 LL 後梁頂/底總應力

位置 Stage 1 Stage 2 LL 總應力
梁頂 +125.94（壓） +35.6（壓） $\boxed{+161.6 \text{ kgf/cm}^2}$（壓縮）
梁底 +49.06（壓） −155.4（拉） $\boxed{-106.3 \text{ kgf/cm}^2}$（拉伸）

5. 關鍵爭議點與進階探討

⚠ 容許應力驗算（2026-08-22 全面改正：舊版兩個容許值都錯，壓應力的結論因此反轉）

舊版寫法（錯誤）： 壓應力容許 $0.4f'_c = 140$ → 判 ❌；拉應力容許 $3\sqrt{f'_c} = 56.1$ → 判 ❌。
$0.4f'_c$ 與 $3\sqrt{f'_c}$ 兩個係數在土木 401 與 ACI 318 的任何版本都查不到。

正確容許值（土木 401-110／112 §18.4；ACI 318-19 §24.5，kgf/cm² 制）：

位置 計算應力 載重組合 容許值 判斷
梁頂（壓） 125.9（預力＋持續載重 $D$） 預力＋持續載重 $0.45f'_c = 157.5$ ✅ 通過（餘裕 20%）
梁頂（壓） 161.6（含瞬時活載 $L$） 預力＋全部載重 $0.60f'_c = 210.0$ ✅ 通過（餘裕 23%）
梁底（拉） 106.3 使用階段 Class U $2.0\sqrt{f'_c} = 37.4$；Class T 上限 $3.2\sqrt{f'_c} = 59.9$ ❌ 兩者皆超 → Class C

因此本題真正的結論不是「壓應力超限」，而是：

$$f_{bot} = 106.3 \gg f_r = 2.0\sqrt{350} = 37.4\ \text{kgf/cm}^2$$

底纖維拉應力是開裂模數的 2.84 倍，斷面在使用載重下必然已經開裂。
依 ACI 318-19 §24.5.2.1 的分級，此構材屬 Class C（開裂），其後果有三：

  1. 本題用的「未開裂全斷面彈性疊加」在物理上已失效——真實的梁底拉應力不會達到 106.3，
    一旦開裂中性軸就上移、$I$ 大幅下降，應力重分配。106.3 只能解讀為「假設不開裂時的名目值」。
    考場上這個值就是標準答案（題目要的是彈性分析），但必須加註這一句才是完整的工程判斷。

  2. Class C 構材不得用未開裂斷面做撓度計算，須改用 $I_{cr}$（§24.2.3.9）。

  3. Class C 須做裂縫控制（鋼筋間距限制 §24.3.2）與腐蝕防護檢討；本梁若處於腐蝕環境（如濱海橋梁）根本不可採用。

設計上的診斷： $P_e = 210$ tf、$e = 25$ cm 提供的底纖維預壓只有 251.6 kgf/cm²，
而 $M_{S1}+M_{LL}$ 在各自斷面產生的底纖維拉力合計 $202.5 + 155.4 = 357.9$ kgf/cm²。
預力量明顯不足——要讓底纖維維持 Class U（$\le 37.4$），需要把預力提高約 40%，或加深梁、或加大偏心。

版頂應力驗算（附加）

版頂位於組合形心上方 $95 - 65.07 = 29.93$ cm（舊版誤寫 35.93 cm，實際代入的 29.93 是對的）。
LL 引起之版頂壓應力（須乘 $n$ 換回版材料）：

$$f_{deck,top}^{LL} = +\frac{M_{LL} \times y_{deck,top}}{I_c} \times n = +\frac{10{,}000{,}000 \times 29.93}{4{,}188{,}695} \times 0.8944 = 71.45 \times 0.8944 = 63.9 \text{ kgf/cm}^2$$

版容許壓應力 $0.60f'_{c2} = 0.60\times280 = 168$ kgf/cm²（舊版寫 $0.4\times280=112$，係數同樣無出處）：
$63.9 < 168$ ✓ 版本身通過。

版 DL 在 Stage 1 而非 Stage 2

若版 DL 誤置於組合斷面（Stage 2），梁底在 Stage 1 結束後只扣掉梁自重：

$$f_{bot}^{S1,\text{錯誤}} = +251.56 - \frac{5.76\times500{,}000}{32{,}000} = +251.56 - 90.0 = +161.6\ \text{kgf/cm}^2$$

差異達 112.5 kgf/cm²，是本題最大的單一失分點。原卷「澆置樓版時利用梁作為支撐」就是判定依據。

幾何與假設的精度說明

  • $I_c$ 精算 $= 4{,}188{,}695$ cm⁴（正文寫 4,188,623，差 0.002%，係 $\bar y$ 取三位小數的進位，不影響任何結論）。

  • $\gamma_c = 2400$ kgf/m³ 為原卷未給之假設。若改用 2,300 kgf/m³（同庫 RC-2012-1 原卷給的值），
    $w_{S1} = 12.42$ kgf/cm、$M_{S1} = 6{,}210{,}000$、$M_{S1}/S = 194.1$ → 梁頂 $+153.2$、梁底 $-97.9$ kgf/cm²，
    結論（Class C）不變。作答時務必把假設寫出來。

  • 版的有效寬度：$\min(L/4=500,\ b_w+16h_f=270,\ \text{梁間距}=200) = 200$ cm，與題給版寬相同 ✓。

6. 依最新規範對照（土木 401-112／ACI 318-19）

結論：兩個主線應力值不變（梁頂 $+161.6$ 壓、梁底 $-106.3$ 拉），但驗算的判定全部改寫。

$E_c$ $15000\sqrt{f'_c}$（kgf 制） $4700\sqrt{f'_c}$ MPa ＝ $15000\sqrt{f'_c}$ kgf/cm² 無

一句話總結： 最新規範沒有改變「怎麼算」，但改變了「算出來代表什麼」。
本題舊版把壓應力判成超限（其實通過）、把拉應力當成單純超限（其實已開裂、分析前提失效），
兩處都是用了不存在的容許值係數造成的。
