1. 原始題目重述 (Problem Restatement)

題目： 某 RC 柱底承受 $P = 270$ tf、$M = 232.5$ tf·m，依線性內插求彎矩塑鉸性質，以民國 109 年交通部頒「公路橋梁耐震評估與補強設計規範」公式，評估曲率韌性需求 $\mu_\phi$、轉角韌性需求 $\mu_\theta$、位移韌性需求 $\mu$。（25 分）

材料與幾何：

  • 斷面：$80 \times 80$ cm，淨高 $l_u = 6.4$ m
  • $f'_c = 280$ kgf/cm²，$f_y = 4200$ kgf/cm²，主筋 D32（$d_b = 3.22$ cm）
  • 反曲點位於淨高 $l_u/2 = 3.2$ m 處 → 懸臂長度 $L = 3.2$ m

規範公式：
$$\delta_y = \frac{\phi_y L^2}{3}, \quad \theta_y = \frac{\delta_y}{L}$$
$$\delta_u = \frac{M_u}{M_y}\delta_y + (\phi_u - \phi_y)L_p(L - 0.5L_p), \quad \theta_u = \frac{\delta_u}{L}$$
$$L_p = 0.08L + 0.0022\,d_b\,f_y \ge 0.0044\,d_b\,f_y$$

原卷原文（111 年第四題）核對： 「某鋼筋混凝土柱之斷面尺寸 $80\times80$ cm、淨高度 6.4 m，
$f'_c$=280、$f_y$=4200 kgf/cm²，縱向主筋使用 D32。已知該柱於軸壓力分別為 $P$=180 tf 及 $P$=360 tf 作用時，
柱底彎矩塑鉸性質分別如表 3 所示，皆為雙線性曲線。該柱底今承受軸壓力 $P$=270 tf，彎矩 $M$=232.5 tf-m，
假設其彎矩塑鉸性質可由表 3 數值作線性內插，且反曲點位於淨高度一半位置。
請根據民國 109 年 12 月交通部頒「公路橋梁耐震評估與補強設計規範」所列公式如下，以撓曲變形為主，
評估反曲點下方柱視作單曲率柱時之曲率韌性需求 $\mu_\phi$、轉角韌性需求 $\mu_\theta$，與位移韌性需求 $\mu$。（25 分）」

卷首另註明本科作答規範為土木 401-100，但本題明確改用交通部橋梁規範，兩者不衝突。

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

核心觀念： 依橋梁耐震規範的雙線性彎矩-曲率模型，評估 RC 柱在指定軸力下的三種韌性比。

⚠ 題意歧義（2026-08-22 留檔）： 題幹說「韌性需求」，但原卷印出的公式（$\delta_u$、$\theta_u$、下標 $u$）
是韌性容量的算式；而題目給的 $M = 232.5$ tf·m 恰好是內插後 $M_y = 220$ 與 $M_u = 245$ 的正中點，
在「照公式算容量」的讀法下完全用不到。兩種讀法的完整數字都已留檔於 §5 爭議點 2。
本解主線採讀法 A（照原卷印出的公式，用 $M_u$、$\phi_u$）。

出題者意圖：

  1. 測驗線性內插的正確執行（$P = 270$ 在 180~360 之間）
  2. 考驗 $L_p$ 公式的適用（混合單位、下限控制）
  3. 確認三個韌性需求的計算層次：曲率（斷面層次）→ 轉角（構件層次）→ 位移（整體層次）

4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

Step 1：確認懸臂長度

反曲點位於淨高一半：
$$L = \frac{l_u}{2} = \frac{6.4}{2} = \mathbf{3.2 \text{ m}}$$

Step 2：線性內插塑鉸參數（$P = 270$ tf）

$$\alpha = \frac{270 - 180}{360 - 180} = \frac{90}{180} = 0.5$$

參數 $P=180$ tf $P=360$ tf 內插（$P=270$ tf）
$\phi_y$（rad/m） 0.004 0.006 $0.004 + 0.5\times0.002 = \mathbf{0.005}$
$M_y$（tf·m） 200 240 $200 + 0.5\times40 = \mathbf{220}$
$\phi_u$（rad/m） 0.030 0.010 $0.030 + 0.5\times(-0.020) = \mathbf{0.020}$
$M_u$（tf·m） 230 260 $230 + 0.5\times30 = \mathbf{245}$

確認： 應用彎矩 $M = 232.5$ tf·m 介於 $M_y = 220$ tf·m 與 $M_u = 245$ tf·m 之間，柱底已進入塑性階段。

Step 3：塑鉸長度 $L_p$

$$d_b = 3.22 \text{ cm} = 0.0322 \text{ m}, \quad f_y = 4200 \text{ kgf/cm}^2$$

第一式：
$$0.08L + 0.0022\,d_b\,f_y = 0.08\times3.2 + 0.0022\times0.0322\times4200$$
$$= 0.256 + 0.297 = 0.553 \text{ m}$$

下限：
$$0.0044\,d_b\,f_y = 0.0044\times0.0322\times4200 = 0.595 \text{ m}$$

$$\boxed{L_p = \max(0.553,\ 0.595) = \mathbf{0.595 \text{ m}}} \quad \text{（下限控制）}$$

Step 4：降伏位移與轉角

$$\delta_y = \frac{\phi_y L^2}{3} = \frac{0.005 \times 3.2^2}{3} = \frac{0.005 \times 10.24}{3} = \frac{0.05120}{3} = \mathbf{0.01707 \text{ m}}$$

$$\theta_y = \frac{\delta_y}{L} = \frac{0.01707}{3.2} = \mathbf{0.005335 \text{ rad}}$$

Step 5：極限位移與轉角

$$\frac{M_u}{M_y} = \frac{245}{220} = 1.1136$$

$$L - 0.5L_p = 3.2 - 0.5\times0.595 = 3.2 - 0.2975 = 2.9025 \text{ m}$$

$$\delta_u = \frac{M_u}{M_y}\delta_y + (\phi_u - \phi_y)\cdot L_p\cdot(L - 0.5L_p)$$

$$= 1.1136\times0.01707 + (0.020 - 0.005)\times0.595\times2.9025$$

$$= 0.01902 + 0.015\times0.595\times2.9025$$

$$= 0.01902 + 0.015\times1.7270$$

$$= 0.01902 + 0.02591 = \mathbf{0.04493 \text{ m}}$$

$$\theta_u = \frac{\delta_u}{L} = \frac{0.04493}{3.2} = \mathbf{0.01404 \text{ rad}}$$

Step 6：三種韌性需求

$$\boxed{\mu_\phi = \frac{\phi_u}{\phi_y} = \frac{0.020}{0.005} = \mathbf{4.0}}$$

$$\boxed{\mu_\theta = \frac{\theta_u}{\theta_y} = \frac{0.01404}{0.005335} = \mathbf{2.63}}$$

$$\boxed{\mu = \frac{\delta_u}{\delta_y} = \frac{0.04493}{0.01707} = \mathbf{2.63}}$$

驗算： $\mu_\theta = \theta_u/\theta_y = (\delta_u/L)/(\delta_y/L) = \delta_u/\delta_y = \mu$ ✓（兩者必定相等）

5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

爭議點 1：$L_p$ 公式的單位系統

本題 $L_p$ 公式使用混合單位（$L$ 與 $d_b$ 以 m 代入，$f_y$ 以 kgf/cm²），係台灣橋梁耐震規範的特定版本。其背後物理是 Priestley & Park（1987）的原始公式：

$$L_p = 0.08L + 0.022\,d_b\,f_y \quad (L,\,d_b \text{ in m},\, f_y \text{ in MPa})$$

轉換：$f_y = 4200 \text{ kgf/cm}^2 \approx 412 \text{ MPa}$，$d_b = 0.0322 \text{ m}$

$$\Rightarrow 0.022 \times 0.0322 \times 412 = 0.292 \text{ m} \approx 0.297 \text{ m} \quad\checkmark$$

爭議點 2：$M = 232.5$ tf·m 的角色——兩種讀法都要會（本題最值得留檔處）

關鍵觀察： $M = 232.5 = \dfrac{220 + 245}{2}$，恰好是內插後 $M_y$ 與 $M_u$ 的正中點。
出題者隨手挑一個彎矩不會這麼剛好；這強烈暗示 232.5 是要被「用」的，而不只是拿來確認已降伏。
但原卷印出的公式（$\delta_u = \frac{M_u}{M_y}\delta_y + \ldots$，下標全是 $u$）又明明是極限狀態的算式。

讀法 A（本解主線） 讀法 B（依 $M = 232.5$ 的「需求」）
依據 照原卷印出的公式逐字代入（下標 $u$） 「需求」＝在實際承受的 $M = 232.5$ 之狀態評估
曲率 $\phi_u = 0.020$ rad/m $\phi_d = \phi_y + \dfrac{232.5-220}{245-220}(\phi_u-\phi_y) = \mathbf{0.0125}$ rad/m
$\mu_\phi$ $0.020/0.005 = \mathbf{4.00}$ $0.0125/0.005 = \mathbf{2.50}$
位移 $\delta_u = 4.491$ cm $\delta_d = \dfrac{232.5}{220}\delta_y + (0.0125-0.005)L_p(L-0.5L_p) = \mathbf{3.099}$ cm
$\mu_\theta = \mu$ $4.491/1.707 = \mathbf{2.63}$ $3.099/1.707 = \mathbf{1.82}$
名稱正確性 算出來其實是韌性容量 才是嚴格意義的韌性需求

採 A 為主線的理由： 題幹明寫「請根據規範所列公式如下……評估」，而印出來的公式下標就是 $u$；
照字面代入是最不會被扣分的作法。$M = 232.5$ 則用來確認柱底確實已降伏（$232.5 > M_y = 220$）
且尚未達極限（$232.5 < M_u = 245$）——這是「可以把它當塑鉸來算」的前提，本身就是必要的一步。

考場建議：兩個都寫。 先照公式給 A（$\mu_\phi = 4.0$、$\mu_\theta = \mu = 2.63$），
再補一句「若『需求』係指在 $M = 232.5$ tf·m 之實際狀態，則 $\mu_\phi = 2.5$、$\mu_\theta = \mu = 1.82$」。
規範用語上，A 算的是容量、B 算的是需求，而耐震評估的判準正是「容量 $\ge$ 需求」——
本題兩者相除 $2.63 / 1.82 = 1.44$，代表尚有 44% 的韌性餘裕，這句話寫上去很加分。

進階：三層韌性的物理意義

$$\mu_\phi = 4.0 \gg \mu_\theta = \mu = 2.63$$

這是因為：

  • $\mu_\phi$ 只看斷面塑鉸點的曲率比（局部），$\phi_u/\phi_y$ 直接由雙線性模型讀出。
  • $\mu$ 看的是整體頂點位移（全局），塑鉸區只是 $L_p = 0.595$ m 的一段，其貢獻被稀釋於整根 $L = 3.2$ m 的柱中。
  • 兩者關係：$\mu \approx 1 + (\mu_\phi - 1)\,\lambda$，其中 $\lambda = 3\dfrac{L_p}{L}\!\left(1 - 0.5\dfrac{L_p}{L}\right) < 1$。

驗算：$\lambda = 3\times\dfrac{0.595}{3.2}\times\left(1 - 0.5\times\dfrac{0.595}{3.2}\right) = 3\times0.1859\times0.9070 = 0.506$

$$\mu \approx 1 + (4.0-1)\times0.506 = \mathbf{2.518}$$

比主線的 2.632 略小——差額來自本題公式多了一項應變硬化 $\dfrac{M_u}{M_y}\delta_y$（$M_u/M_y = 1.114$）。
若把硬化拿掉（$M_u/M_y = 1$）：$\delta_u = 0.01707 + 0.02590 = 0.04297$ m，$\mu = 2.518$ ✓ 與近似式完全吻合。
這個交叉驗算很值得寫——它證明你懂公式裡每一項在做什麼。

6.3 $L_p$ 公式的來源與單位（複核確認）

原式為 Priestley & Park (1987)：$L_p = 0.08L + 0.022\,d_b f_{ye} \ge 0.044\,d_b f_{ye}$（$L,d_b$：m；$f_{ye}$：MPa）。
換成 kgf/cm²：$0.022/10.197 = 0.002157 \approx \mathbf{0.0022}$、$0.044/10.197 = 0.004315 \approx \mathbf{0.0044}$ ✓
與規範印出的係數完全吻合——代入時 $f_y$ 直接用 4200 kgf/cm²，不要再換算成 MPa。

本題 $0.08L = 0.256$ m 只佔 43%，下限式 $0.0044d_bf_y = 0.595$ m 控制（大 7.5%）。
$L$ 越短、主筋越粗、$f_y$ 越高，下限越容易控制——這是本題刻意設計的考點。
