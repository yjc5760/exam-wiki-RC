1. 原始題目重述 (Problem Restatement)

原卷原文（98 年第三題）：

試以壓拉桿模式（strut-and-tie model），預估圖一受兩點載重簡支撐深梁之最大載重 $P$ 及可能破壞模式為何？其中，梁配有水平與垂直腹筋，且符合 ACI 規範之規定。混凝土 $f'_c = 250\ \text{kgf/cm}^2$，鋼筋 $f_y = 4200\ \text{kgf/cm}^2$，$A_{s,\text{D19}} = 2.87\ \text{cm}^2$。假設純彎區水平壓桿寬為 20 cm，不考慮強度折減係數。鋼筋兩端有良好錨定，且承壓鈑與混凝土表面均有良好接觸。（25 分）

圖說：簡支深梁，梁寬 $b=20$ cm，梁高 $h=70$ cm，梁全長 170 cm。底部尺寸鏈為 20｜30｜20｜30｜20｜30｜20 = 170 cm，其中四段 20 cm 分別是左支承鈑、左載重鈑、右載重鈑、右支承鈑，中央那段 30 cm 標註為「純彎區」。故支承鈑中心在 10 與 160 cm、載重鈑中心在 60 與 110 cm；支承跨度 $L = 150$ cm、剪力跨 $a = 50$ cm。6-D19（3 層 × 2 支）分布於底部 20 cm 範圍內，形心距底 10 cm。$f'_c=250$ kgf/cm²，$f_y=4200$ kgf/cm²，$A_{s,\text{D19}}=2.87$ cm²。

⚠ 尺寸鏈判讀是本題的第一道關卡。 原圖是七段連續尺寸鏈（20-30-20-30-20-30-20），
四段 20 cm 是鈑寬、三段 30 cm 是鈑與鈑之間的淨距。若誤把它讀成
「支承至載重 = 30、純彎區 = 20」（跨度 80 cm、$a = 30$ cm），
壓桿角度會從 45° 變成 59°，桿件力全錯，控制條件也會從斜壓桿跳到 CCT 節點。
判準：中央 30 cm 那一段被明文標註為「純彎區」——純彎區必位於兩載重鈑之間，
所以 30 cm 是淨距、20 cm 是鈑寬，不可能反過來。

材料與假設：

  • $f'_c = 250$ kgf/cm²，$f_y = 4200$ kgf/cm²，$A_{s,\text{D19}} = 2.87$ cm²（$A_s = 6\times2.87 = 17.22$ cm²）
  • 純彎區水平壓桿寬（＝頂部節點高）$h_c = 20$ cm → 形心距梁頂 10 cm
  • 拉力桿節點高 $h_t = 20$ cm（鋼筋分布範圍）→ 形心距梁底 10 cm
  • 承壓鈑寬 $l_b = 20$ cm（支承與載重點同）
  • 腹筋符合 ACI 最小水平／垂直腹筋規定
  • $\phi = 1.0$（不考慮強度折減）

2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

核心觀念：

  • 深梁（$a/d = 50/60 = 0.83 \ll 2$；淨跨/$h = 130/70 = 1.86 < 4$）不滿足平截面假設，傳力路徑以壓拉桿模式描述
  • STM 三要素：壓力桿（Struts）、拉力桿（Ties）、節點（Nodes）
  • 每一要素、每一節點面都要驗核，最小者決定最大載重，且該項即決定破壞模式

出題者意圖：

  1. 測驗 STM 幾何建立（力臂 $z$、桿件角度 $\theta$）——先要讀對尺寸鏈
  2. 測驗壓力桿有效強度（$\beta_s$：瓶形 0.75 vs 棱柱/邊界 1.0）
  3. 測驗節點強度（$\beta_n$：CCT 0.80 vs CCC 1.0），且需分面驗核
  4. 推論破壞模式（脆性壓碎 vs 延性降伏），並提出改善方向

3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

作戰計畫：

  1. 讀尺寸鏈 → 定 $L$、$a$；建立 STM 幾何（$z$、$\theta$）
  2. 以平衡求各桿件力（皆表為 $P$ 的倍數）
  3. 逐項驗核：拉力桿、水平壓桿、斜壓桿、CCT 節點三面、CCC 節點三面
  4. 取最小值 → $P_{\max}$；由控制項判定破壞模式；提改善建議

Step 2：各桿件力（以 $P$ 表示）

對稱條件：每個支承反力 $R = P/2$

桿件 力 推導
拉力桿（水平，底部） $T = \mathbf{0.5P}$ $(P/2)\times(a/z) = (P/2)\times(50/50)$

Step 3：拉力桿強度限制

$$F_{nt} = A_s f_y = 17.22\times4200 = 72{,}324\ \text{kgf}$$

$$0.5P \le 72{,}324 \quad\Rightarrow\quad \boxed{P \le 144{,}648\ \text{kgf} = 144.6\ \text{tf}}$$

Step 4：純彎區水平壓桿強度限制

純彎區壓桿為棱柱形／邊界壓桿（斷面均勻，無橫向擴展），$\beta_s = 1.0$：

$$f_{ce} = 0.85\beta_s f'_c = 0.85\times1.0\times250 = 212.5\ \text{kgf/cm}^2$$

$$A_{cs} = h_c\times b = 20\times20 = 400\ \text{cm}^2 \quad\Rightarrow\quad F_{ns} = 212.5\times400 = 85{,}000\ \text{kgf}$$

$$0.5P \le 85{,}000 \quad\Rightarrow\quad \boxed{P \le 170{,}000\ \text{kgf} = 170.0\ \text{tf}}$$

Step 5：斜向壓桿（瓶形）強度限制 ← 控制項

斜向壓桿為瓶形壓桿（有腹筋符合 ACI），$\beta_s = 0.75$：

$$f_{ce} = 0.85\times0.75\times250 = 159.375\ \text{kgf/cm}^2$$

壓桿寬度（在支承節點處）：

$$w_s = l_b\sin\theta + h_t\cos\theta = 20(0.7071) + 20(0.7071) = 14.14 + 14.14 = 28.28\ \text{cm}$$

$$A_{cs} = w_s\times b = 28.28\times20 = 565.7\ \text{cm}^2$$

$$F_{ns} = 159.375\times565.7 = 90{,}156\ \text{kgf}$$

$$0.7071P \le 90{,}156 \quad\Rightarrow\quad \boxed{P \le 127{,}500\ \text{kgf} = 127.5\ \text{tf}} \quad\leftarrow\ \textbf{最嚴格}$$

Step 6：節點強度限制

支承節點（CCT 節點：含一條拉桿）　$f_{ce} = 0.85\times0.80\times250 = 170\ \text{kgf/cm}^2$

承壓面（支承反力） $l_b b = 20\times20 = 400$ $P/2$ $2\times170\times400 = 136{,}000$
背面（拉桿面） $h_t b = 20\times20 = 400$ $T = 0.5P$ $170\times400/0.5 = 136{,}000$
斜壓桿面 $w_s b = 565.7$ $0.7071P$ $170\times565.7/0.7071 = 136{,}000$

$$\Rightarrow\quad \boxed{P \le 136{,}000\ \text{kgf} = 136.0\ \text{tf}}$$

三面同值不是巧合： $\theta = 45°$ 時 $R = T = P/2$ 且 $w_s = \sqrt2\,l_b$，
三個面的應力比例完全一致。這是 45° 幾何的自然結果，可當成計算正確的驗算。

載重點節點（CCC 節點：全為壓力）　$f_{ce} = 0.85\times1.0\times250 = 212.5\ \text{kgf/cm}^2$

斜壓桿面 565.7 $0.7071P$ $170{,}000$

Step 8：可能破壞模式

依強度由低至高排序，破壞會依序觸發：

  1. 斜向瓶形壓桿劈裂／壓碎 → $P = 127.5$ tf → 控制、脆性破壞（最先發生）
  2. 壓應力場自 28.3 cm 寬的節點面向壓桿中段橫向擴展，產生垂直於壓桿的橫向拉力
  3. 腹筋（符合 ACI 最小量）可抑制劈裂裂縫展開，故容許 $\beta_s = 0.75$ 而非 0.4，但仍是壓碎控制

  4. 破壞形式：支承與載重點之間出現斜向裂縫，隨即混凝土壓碎——無明顯預警

  5. CCT 節點承壓／壓桿面壓碎 → $P = 136.0$ tf（僅高 6.7%）

  6. 與斜壓桿只差 6.7%，實際試驗中兩者可能同時發生、難以分辨

  7. 拉力桿（6-D19）降伏 → $P = 144.6$ tf（高 13.4%）

  8. 最延性的模式，但被前兩項擋住，不會率先發生

  9. CCC 節點與水平壓桿 → $P = 170.0$ tf（高 33%），有充分餘裕

結論：本梁為壓力（剪力）控制的脆性破壞，非延性彎曲破壞。

改善建議（依效益排序）：

  1. 加大承壓鈑（$l_b$ 由 20 → 30 cm）：$w_s$ 增至 35.4 cm，斜壓桿容量升至 159.4 tf、CCT 節點升至 170 tf，破壞模式即轉為拉力桿降伏（144.6 tf，延性）。最直接有效。
  2. 增加腹筋量／改善配置：僅提高劈裂後的殘餘韌性，$\beta_s$ 已是有腹筋上限 0.75，帳面強度不再增加。
  3. 提高 $f'_c$：壓桿與節點強度成正比、拉力桿不變 → 同樣可把控制項推向拉力桿。
  4. 加寬梁寬 $b$：壓桿與節點容量正比增加、拉力桿不變 → 效果同 3。

② 為何 CCT 節點比 CCC 節點弱？

拉桿的錨定在節點內產生分裂拉力（bond splitting），降低節點混凝土的有效壓力強度。

③ 瓶形壓桿的物理意義

瓶形壓桿（bottle-shaped strut）的壓應力場在傳遞過程中橫向擴展，產生垂直於壓桿方向的橫向拉力。若無腹筋，橫向拉力會使壓桿沿中央劈裂。ACI 規定：腹筋符合最小量時 $\beta_s = 0.75$；否則只能取 0.4（318-19）／0.60λ（318-14 以前）。本題腹筋合規，取 0.75。

④ $a/d$ 比值與 STM 適用性

$a/d = 50/60 = 0.83 < 2$，屬深梁區域，剪力主要由「拱作用（arch action）」而非「梁作用（beam action）」傳遞，故用 STM。若 $a/d > 2$（細長梁），Whitney 應力塊＋傳統 $V_c + V_s$ 較適用。

⑤ 若計入強度折減係數

題目明訂「不考慮強度折減係數」。若依 ACI 318-19 §21.2.1 對 STM 取 $\phi = 0.75$：

$$\phi P_{\max} = 0.75\times127.5 = \mathbf{95.6\ \text{tf}}$$

⑥ 依最新規範（ACI 318-19 第 23 章／土木 401-112）重算對照

ACI 318-19 把 STM 章節大幅改寫，有效強度式增列圍束修正係數 $\beta_c$：

$$\text{壓桿：}f_{ce} = 0.85\,\beta_c\,\beta_s\,f'_c\qquad\text{節點：}f_{ce} = 0.85\,\beta_c\,\beta_n\,f'_c$$

項目 ACI 318-14（本解主線） ACI 318-19 本題影響
斜壓桿 $\beta_s$ 瓶形＋腹筋合規 = 0.75 內部壓桿＋腹筋符合 §23.5 = 0.75 不變
水平壓桿 $\beta_s$ 棱柱形 = 1.0 邊界壓桿 = 1.0 不變
無腹筋時 $\beta_s$ $0.60\lambda$ 0.4 （本題不適用）
拉力區壓桿 $\beta_s$ 0.40 0.4 （本題不適用）
節點 $\beta_n$ CCC 1.0／CCT 0.8／CTT 0.6 相同 不變
$\beta_c$（圍束） 無此係數 $1.0$，或 $\sqrt{A_2/A_1}\le2.0$（受圍束時） 承壓鈑寬 = 梁寬 20 cm，橫向無圍束 → $\beta_c = 1.0$

術語對照要記： 318-19 把「棱柱形／瓶形」的分類改成「邊界壓桿（boundary strut）／內部壓桿（interior strut）」——本題頂部水平壓桿沿構材受壓邊界，屬邊界壓桿（1.0）；斜壓桿位於 D 區內部，屬內部壓桿（腹筋合規 0.75）。分類名稱換了，本題數值恰好不變，但無腹筋的懲罰從 0.60λ 加重到 0.4，這是 318-19 最實質的改變。

⑦ 考場重點：所有限制都要算，而且要分面

本題若只算「拉力桿 + 斜壓桿 + CCT 承壓面」三項會得到相同答案，但漏掉節點的背面與壓桿面就少了論述完整性；而 45° 時三面同值，正好是「算對了」的自我驗證。
