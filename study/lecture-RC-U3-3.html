§0 全景：一場你可以作弊的賽跑

一句話：地震不會問你哪裡該壞 —— 所以你要在設計階段就把「想要它壞的地方」做弱、「不准它壞的地方」做強， 而且差距要大到即使材料超強也翻不了盤。
延性機構（梁端彎矩塑鉸）和脆性機構（剪力破壞、接頭破壞、柱壓碎）在賽跑，誰先到達自己的強度，誰就決定破壞模式。 能力設計法（capacity design）就是刻意讓延性機構永遠先到。RC-U3-3 這 18 題考題，全部是這一句話的展開。

一般強度設計問的是「撐不撐得住」；耐震設計問的是「壞的時候用什麼方式壞」。 這是完全不同的問題 —— 所以本單元幾乎沒有一條公式是在算「需求」， 它們都在算「某個機構最多可能有多強」，然後拿這個上限去設計別的構件。 只要抓住這個顛倒的邏輯，1.25、\(\phi=1.0\)、6/5、\(V_c=0\) 就全部合理了（見 §1）。

兩張圖是同一棟建築的兩種命運，差別只在「哪裡先出鉸」（變形已放大示意）。左圖側位移全集中在一樓，6 個鉸就成機構；右圖每層都分擔變形，要 15 個鉸 —— 這就是「強柱弱梁」值得用 6/5 去買的東西（§5）。注意右圖柱底仍然出鉸：強柱弱梁救不了柱底，所以柱底一定要有密箍（§4）。
為什麼要這樣看？
如果只把本單元當成「一堆耐震規範的公式與限值」，你會發現要背的東西多到記不住： \(1.25f_y\)、\(\phi=1.0\)、\(6/5\)、\(V_c=0\)、\(A_{sh}\) 兩式、\(l_o\) 三式、\(s\) 三式、\(\gamma\sqrt{f'_c}A_j\)、\(\phi=0.85\)、\(\phi=0.6\)……
但如果理解「這些全是同一場賽跑的讓分」，你只需要記住讓分的方向： 延性那一側往下調（做弱、允許它先壞），脆性那一側往上調（做強、絕對不准它先壞）。 考場上忘記某個係數時，至少能寫出方向與理由，拿到大部分過程分。

§1 讓分階梯：每個係數在補償什麼

本節主張：耐震設計的所有「奇怪係數」都在做同一件事 —— 確保「延性那一側的真實上限」低於「脆性那一側的保證下限」。 公式方向搞清楚，數字忘了也能推。

1.1 為什麼剪力設計不能用 φMn

\(\phi M_n\) 是「我保證至少有這麼強」（下限）；\(M_{pr}\) 是「它最多可能有這麼強」（上限）。剪力設計要問的是「塑鉸能把多大的力送進來」—— 那是上限問題，所以必須用 \(M_{pr}\)，而且不能再折減。本例若拿 \(\phi M_n=141.4\) 去推剪力，地震項只有真實值的 75%。另注意 \(M_{pr}/M_n=1.20\) 而非 1.25：鋼筋力放大 1.25 倍時壓力區深度 \(a\) 也跟著變大（19.2 → 23.9 cm），力臂變短。

§2 韌性到底是什麼：三個層次不是三個公式

本節主張：曲率韌性 \(\mu_\phi\)、轉角韌性 \(\mu_\theta\)、位移韌性 \(\mu\) 是同一件事在三個尺度上的投影： 斷面 → 構件 → 系統。而且它們必然滿足 \(\mu_\phi \geq \mu_\theta = \mu\) —— 這個不等式本身就是考點。
左圖依 RC-2022-4 內插值按比例繪出：\(\mu_\phi=4.0\) 是斷面能提供的曲率放大倍數。右圖把同一根柱的曲率分佈也按比例畫出：橘色塑性區只占柱長 0.595/3.2 ≈ 19%，其餘部分仍是彈性的，所以頂點位移只放大 \(\mu=2.63\) 倍（撓度已放大示意，但 \(\delta_u/\delta_y\) 比例正確）。

2.1 為什麼 μφ 一定大於 μ

降伏位移是整根構件的彈性積分：

$$\delta_y = \frac{\phi_y L^2}{3}$$

而極限位移只在塑鉸長度 \(L_p\) 內獲得額外的塑性轉角：

$$\theta_p = (\phi_u - \phi_y)\,L_p, \qquad \delta_u = \underbrace{\frac{M_u}{M_y}\delta_y}_{\text{硬化後的等效彈性位移}} + \underbrace{\theta_p\left(L - \tfrac{L_p}{2}\right)}_{\text{塑鉸轉角乘力臂}}$$
極限檢查（三個都要會）
① 令 \(L_p \to 0\)（塑鉸集中成一點）：\(\theta_p \to 0\)，\(\delta_u \to (M_u/M_y)\delta_y\) → \(\mu \to M_u/M_y \approx 1.1\)。 斷面再有韌性，若塑鉸長度為零，構件就沒有韌性 —— 這是 \(L_p\) 存在的全部意義。
② 令 \(L_p \to L\)（整根都塑化，例如均勻彎矩）：\(\mu\) 會逼近 \(\mu_\phi\)。
③ \(\mu_\theta = \dfrac{\theta_u}{\theta_y} = \dfrac{\delta_u/L}{\delta_y/L} = \dfrac{\delta_u}{\delta_y} = \mu\) —— 兩者必定相等， 考場上算出不一樣就是算錯。（RC-2022-4 的內建檢查點。）
手算：RC-2022-4（2022，橋梁耐震規範，計算量小但觀念密度高）
柱 80×80 cm、淨高 \(l_u = 6.4\) m、\(P = 270\) tf、D32 主筋、\(f_y = 4200\) kgf/cm²。

① 懸臂長度：反曲點把雙曲率柱切成兩根懸臂

$$L = \frac{l_u}{2} = 3.2\ \text{m}$$

② 線性內插（P = 270 落在 180 與 360 之間）

$$\alpha = \frac{270-180}{360-180} = 0.5 \;\Rightarrow\; \phi_y = 0.005,\; M_y = 220,\; \phi_u = 0.020,\; M_u = 245$$ 注意 \(\phi_u\) 是「內插後變小」（0.030 → 0.010，軸力越大韌性越差），這是物理上正確的方向 —— 軸壓削弱曲率韌性。

③ 塑鉸長度（下限常常控制）

$$L_p = \max\!\big(0.08L + 0.0022 d_b f_y,\; 0.0044 d_b f_y\big)$$ $$= \max(0.08\times3.2 + 0.0022\times0.0322\times4200,\; 0.0044\times0.0322\times4200)$$ $$= \max(0.256+0.2975,\; 0.5951) = \max(0.5535,\; 0.5951) = \mathbf{0.595\ m}$$

④ 三個韌性比

$$\delta_y = \frac{0.005\times3.2^2}{3} = 0.01707\ \text{m},\qquad \theta_y = \frac{0.01707}{3.2} = 0.005333\ \text{rad}$$ $$\delta_u = \frac{245}{220}\times0.01707 + (0.020-0.005)\times0.595\times(3.2-0.2975) = 0.019006 + 0.025907 = 0.044913\ \text{m}$$ $$\mu_\phi = \frac{0.020}{0.005} = \mathbf{4.00},\qquad \mu_\theta = \frac{0.014035}{0.005333} = \mathbf{2.63},\qquad \mu = \frac{0.044913}{0.017067} = \mathbf{2.63}$$ 三個自我檢查：
① \(\mu_\theta = \mu\) ✓（必然相等）
② \(\mu < \mu_\phi\) ✓（塑鉸只佔 0.595/3.2 = 19% 的柱長）
③ 應用彎矩 \(M = 232.5\) 介於 \(M_y=220\) 與 \(M_u=245\) 之間 → 柱底確實已進入塑性，題目自洽。
陷阱：L 用全柱高
觸發信號：「反曲點位於淨高一半」「雙曲率柱」「單曲率柱」。
錯誤思維：\(L = l_u = 6.4\) m。
正確認知：\(L\) 是塑鉸到反曲點的距離。雙曲率柱 \(L = l_u/2\)；真正的單懸臂（如橋墩）才是 \(L = l_u\)。 用錯會讓 \(\delta_y\) 差 4 倍（\(L^2\)）。出自 RC-2022-4。
陷阱：Lp 公式的混合單位
\(0.0022\,d_b\,f_y\) 裡 \(d_b\) 用公尺、\(f_y\) 用 kgf/cm²，結果直接得到公尺。 係數已吸收單位換算，不要自己再換。且 \(0.0044 d_b f_y\) 是下限（本題正是它控制），不是上限。

§3 耐震梁：從 Mpr 反推剪力

本節主張：耐震梁的剪力設計完全不看載重組合的剪力圖。 它問的是「當兩端塑鉸都完全發展時，梁裡的剪力有多大」—— 這是一個純靜力平衡問題，只要把自由體圖畫對就不會錯。

3.1 自由體圖決定一切

側移向左時，兩端塑鉸彎矩作用在梁上同為逆時針：左端頂筋受拉（\(M_{pr}^-\)）、右端底筋受拉（\(M_{pr}^+\)）。地震項 \(\left(M_{pr}^-+M_{pr}^+\right)/l_n\) 是彎矩圖橘色直線的斜率 → 全跨定值；重力項 \(\pm w_u l_n/2\) 是拋物線的斜率 → 線性。兩者同號的那一端（本圖為左端，46.43 tf）就是控制端（這就是公式裡 \(\pm\) 的意思）；側移反向時右端改為頂筋受拉，控制端也跟著換邊，數值相同。
為什麼地震項是「定值」而重力項是「線性」
兩端塑鉸的彎矩方向相同（都在抵抗同一個方向的層間變位），畫成彎矩圖是一條斜直線從 \(M_{pr}^-\) 到 \(-M_{pr}^+\) → 斜率（＝剪力）為常數 \(\left(M_{pr}^-+M_{pr}^+\right)/l_n\)。
重力載重的彎矩圖是拋物線 → 斜率線性變化。
所以 \(V_e\) 的兩項不是「兩個獨立公式硬湊」，它們是同一張彎矩圖的兩個部分的斜率。
順帶解決一個常見疑問：為什麼分母是淨跨 \(l_n\) 而不是中心距？ 因為塑鉸發生在柱面（那裡才是梁的斷面），力臂就是柱面到柱面。

3.2 手算：RC-2025-2（2025，30 分，耐震梁公版流程）

給定：\(l_n = 9\) m，\(b_w = 60\) cm，\(h = 76\) cm，\(d' = 9\) cm；柱面頂 8-D32、底 6-D32； \(w_u = 2\) tf/m；\(f'_c = 280\)、\(f_y = 4200\) kgf/cm²；箍筋 D13（\(f_{yt}=2800\)，\(A_b = 1.27\) cm²）。

① 幾何與超強鋼筋強度

$$d = 76 - 9 = 67\ \text{cm},\quad A_{s,top} = 8\times8.14 = 65.12,\quad A_{s,bot} = 6\times8.14 = 48.84\ \text{cm}^2$$ $$1.25 f_y = 1.25\times4200 = 5250\ \text{kgf/cm}^2$$

② 兩個方向的 Mpr（頂底鋼筋量不同 → 必須各算一次）

$$a_{top} = \frac{65.12\times5250}{0.85\times280\times60} = \frac{341{,}880}{14{,}280} = 23.94\ \text{cm} \;\Rightarrow\; M_{pr}^- = 341{,}880\times(67-11.97) = \mathbf{188.1\ tf·m}$$ $$a_{bot} = \frac{48.84\times5250}{14{,}280} = 17.96\ \text{cm} \;\Rightarrow\; M_{pr}^+ = 256{,}410\times(67-8.975) = \mathbf{148.8\ tf·m}$$

③ 設計剪力

$$V_{seis} = \frac{188.1+148.8}{9} = \frac{336.9}{9} = 37.43\ \text{tf},\qquad V_{grav} = \frac{2\times9}{2} = 9.00\ \text{tf}$$ $$V_u = 37.43 + 9.00 = \mathbf{46.43\ tf}\quad(\text{控制端：地震與重力同向})$$

④ Vc = 0 判斷（兩個條件都要寫）

$$\frac{V_{seis}}{V_u} = \frac{37.43}{46.43} = 80.6\% > 50\% \quad✓ \qquad N_u = 0 < \frac{A_g f'_c}{20} \quad✓ \;\Rightarrow\; V_c = 0$$ $$V_s\ \text{需求} = \frac{V_u}{\phi} = \frac{46.43}{0.75} = 61.91\ \text{tf}\quad(\text{全部由箍筋承擔})$$

⑤ 箍筋間距（強度需求 vs 耐震構造限制，取小）

$$A_v = 4\times1.27 = 5.08\ \text{cm}^2\ (4\ \text{腳}) \;\Rightarrow\; s_{req} = \frac{A_v f_{yt} d}{V_s} = \frac{5.08\times2800\times67}{61{,}910} = 15.39\ \text{cm}$$ $$s_{seis} = \min\!\left(\frac{d}{4},\; 6d_b,\; 150\ \text{mm}\right) = \min(16.8,\; 19.3,\; 15.0) = 15.0\ \text{cm}$$ $$\Rightarrow s = 15\ \text{cm}\ \text{（密箍區）};\quad \text{密箍區長度} = 2h = 152\ \text{cm};\quad \text{第一支距柱面} \leq 5\ \text{cm}\ (\text{梁：§18.6.4.4})$$ 第一支箍筋別套錯構件：耐震梁第一支箍筋距柱面 \(\le 50\) mm（§18.6.4.4）； \(s_o/2\) 是柱的規定（§18.7.5.3），兩者不可混用。
三個自我檢查：
① \(M_{pr}^-/M_{pr}^+ = 188.1/148.8 = 1.26\)，與鋼筋量比 \(65.12/48.84 = 1.33\) 同一量級 ✓ （不會完全相等，因為 \(a\) 不同；若差很多就算錯了）。
② 地震剪力佔比 80.6% 遠大於 50% → \(V_c=0\) 幾乎必然。耐震梁的 \(V_c=0\) 是常態，不是例外。
③ \(s_{req} = 15.39\) 與 \(s_{seis} = 15.0\) 幾乎相同 → 這題的箍筋量「剛好」，是出題者調過的。 若你算出 \(s_{req}\) 只有 5 cm 或高達 40 cm，回去檢查 \(A_v\) 的腳數與 \(f_{yt}\)。

陷阱二：抄到舊版的箍筋間距

・舊制（ACI 318-11 及更早／土木 401-100 世代）：\(\min(d/4,\; 8d_b,\; 24d_{b,tie},\; 300\text{ mm})\) → 本題會由 \(d/4 = 16.8\) cm 控制

陷阱三：φ 用 0.9

§4 耐震柱：圍束箍筋 Ash 兩式的分工

本節主張：\(A_{sh}\) 兩個公式不是「規範不放心所以列兩個」。 它們針對兩種不同的失效：一個管「保護層剝落後強度不能掉」，一個管「延性的最低底線」。 而且哪一式控制，看一個比值就知道，不必兩式都算完才比較。

4.1 兩式的物理與「誰控制」的判斷

$$A_{sh} \geq \max\underbrace{\left[0.3\,s\,b_c\frac{f'_c}{f_{yt}}\left(\frac{A_g}{A_{ch}}-1\right)\right.}_{\text{式①：補回剝落損失}} ,\quad \underbrace{\left.0.09\,s\,b_c\frac{f'_c}{f_{yt}}\right]}_{\text{式②：延性底線}}$$
式①在補什麼
柱在大變形下保護層一定會剝落。剝落瞬間軸向承載面積從 \(A_g\) 掉到 \(A_{ch}\)， 損失的強度約與 \((A_g - A_{ch})\) 成正比。式① 的括號 \(\left(\dfrac{A_g}{A_{ch}}-1\right) = \dfrac{A_g-A_{ch}}{A_{ch}}\) 就是「損失佔核心的比例」—— 圍束帶來的強度增量必須至少補回這個損失，柱才不會在保護層剝落的瞬間掉載重。
推論：保護層越厚、斷面越小 → \(A_g/A_{ch}\) 越大 → 需要越多圍束。這完全符合直覺。

式②在補什麼
式① 有一個致命缺陷：大斷面柱的 \(A_g/A_{ch}\) 趨近 1，式① 會趨近於零， 彷彿大柱不需要任何圍束。但圍束的另一個作用是提升混凝土的極限壓應變 （無圍束 \(\varepsilon_{cu}\approx0.003\)，良好圍束可到 0.01~0.02），這與斷面大小無關。 式② 不含 \(A_g/A_{ch}\)，正是這條「與尺寸無關的延性底線」。
不必兩式都算完的判斷法（自己推一次）
兩式只差在括號，令它們相等： $$0.3\left(\frac{A_g}{A_{ch}}-1\right) = 0.09 \;\Longrightarrow\; \frac{A_g}{A_{ch}} = 1 + \frac{0.09}{0.3} = \mathbf{1.30}$$ 所以：\(A_g/A_{ch} > 1.30\) → 式①控制（小柱、厚保護層）；\(< 1.30\) → 式②控制（大柱）。
驗證：RC-2013-2 的 \(2500/1764 = 1.417 > 1.3\) → 式①控制 ✓； RC-2012-3 的 \(3600/2304 = 1.563 > 1.3\) → 式①控制 ✓。
（考題絕大多數落在式①，但你要能說出式②何時控制，這是拿高分的地方。）

4.2 為什麼繫筋（crossties）不能省

50×50 cm、16-D32、保護層 4 cm 依比例繪製；淡色區＝外拱以外、圍束到不了的混凝土（拱高取跨距 1/4 示意）。繫筋一個動作帶來三個好處：①增加 \(A_{sh}\) 的腳數（切面 a–a 從 2 腳變 5 腳）、②縮短外拱跨距（讓圍束真正到得了核心中央）、③把 \(h_x\) 變小，使 \(s_o = 10 + (35-h_x)/3\) 放寬。
Ash 是「單一方向」的量 —— 這是最容易錯的定義
\(A_{sh,x}\) ＝ 所有沿 x 方向提供圍束力的箍筋腳的截面積之和。 外方箍在 x 方向提供 2 腳（左右兩支垂直腿），每根垂直方向的繫筋再提供 1 腳。
所以 RC-2013-2 的「1 外箍 + 3 繫筋 = 5 腳/方向」， \(A_{sh} = 5\times1.27 = 6.35\ \text{cm}^2\)。不是把所有箍筋腳加起來（那會是 10 腳）。
公式裡的 \(b_c\) 也要取與該方向垂直的核心尺寸 —— 方形柱兩方向相同，長方形柱必須分開算兩次。

4.3 手算：RC-2013-2（2013，25 分，柱圍束公版）

給定：方形柱 50×50 cm，16-D32（每面 5 根），保護層 4 cm（至箍筋外緣）， \(f'_c = 280\)、\(f_{yh} = 2800\) kgf/cm²，箍筋 D13（\(A_b=1.27\)）。

① 核心尺寸

$$h_c = 50 - 2\times4 = 42\ \text{cm},\quad A_g = 2500,\quad A_{ch} = 42^2 = 1764\ \text{cm}^2$$ $$\frac{A_g}{A_{ch}} = 1.417 > 1.30 \;\Rightarrow\; \textbf{式①控制（不必算式②）}$$

② 單位間距所需 Ash

$$\frac{A_{sh}}{s} = 0.3\times42\times\frac{280}{2800}\times(1.417-1) = 0.3\times42\times0.10\times0.417 = 0.526\ \text{cm}^2/\text{cm}$$

③ 間距三條件（取小）

$$\frac{b}{4} = 12.5\ \text{cm};\qquad 6d_b = 6\times3.22 = 19.3\ \text{cm};$$ $$h_x = 2\times9.4 = 18.8\ \text{cm}\ (\text{跳過中間位置時}) \;\Rightarrow\; s_o = 10+\frac{35-18.8}{3} = 15.4 \xrightarrow{\text{上限 }15} 15.0\ \text{cm}$$ $$s \leq \min(12.5,\;19.3,\;15.0) = 12.5 \;\Rightarrow\; \textbf{取 } s = 12\ \text{cm}$$

④ 需求與配置

$$A_{sh,req} = 0.526\times12 = 6.31\ \text{cm}^2/\text{方向} \;\Rightarrow\; \text{腳數} \geq \frac{6.31}{1.27} = 4.97 \to \mathbf{5\ \text{腳}}$$ 外箍 2 腳 + 繫筋 3 腳 = 5 腳 → \(A_{sh} = 5\times1.27 = 6.35 \geq 6.31\) ✓

⑤ 密箍區長度

$$l_o \geq \max\!\left(\text{柱最大邊長},\; \frac{l_u}{6},\; 45\ \text{cm}\right) = \max(50,\; l_u/6,\; 45)\ \text{cm}$$ 兩個自我檢查：
① 若只配 2 繫筋（4 腳，\(A_{sh}=5.08\)）→ \(5.08 < 6.31\) 不足。 所以「所有主筋都要被支撐」這個構造要求，在本題同時也是強度要求。
② \(h_x\) 與 \(s_o\) 是互相牽動的：多配繫筋 → \(h_x\) 減半（18.8 → 9.4）→ \(s_o = 10+(35-9.4)/3 = 18.5 \to 15\)（仍受 15 上限）。 本題 \(s_o\) 不是控制條件，控制的是 \(b/4 = 12.5\)。先算三個再取小，不要猜。
陷阱：hc（或 bc）的量法
知識庫內對 \(b_c\) 的定義有兩種措辭：「至箍筋外緣」（code-ref）與「至箍筋中心線」（concepts）。 RC-2013-2 用 \(h_c = 50-2\times4 = 42\)（保護層量到箍筋外緣）； RC-2012-3 用 \(b_c = 60-2\times6 = 48\)（保護層 6 cm 量到主筋心）。
結論：跟著題目給的「保護層量到哪裡」定義走，並在答案紙上寫出你的 \(h_c\) 怎麼來的。 兩種量法差約一個箍筋直徑，對 \(A_{sh}\) 影響約 3%，寫清楚不會被扣分；沒寫才會。

§5 強柱弱梁：6/5 買到了什麼，又沒買到什麼

本節主張：強柱弱梁不是「柱要比梁強」這麼簡單的一句話。 它是在節點處比較「上下柱的彎矩容量之和」與「左右梁的彎矩容量之和」， 而且 6/5 只是降低柱出鉸的機率，不是保證 —— 這就是柱端仍然必須配密箍的原因。

5.1 節點平衡：為什麼是「和」而不是單一構件

節點是一個自由體：兩根梁送進來的彎矩（同向）必須由上下兩根柱（反向）承接。所以問題不是「這根柱比這根梁強嗎」，而是「柱能提供的總容量是否超過梁能送進來的總需求」。注意同一個節點左梁是頂筋受拉、右梁是底筋受拉；地震方向反轉時兩者互換 → \(\sum M_{nb}\) 要兩個方向各算一次取大。
6/5 = 1.2 買到了什麼
它讓「柱先到達強度」這件事在機率上變得不容易：柱多 20% 的容量， 足以吸收一般的分析誤差、鋼筋放樣誤差、樓板參與（樓板鋼筋會讓梁的負彎矩容量比計算值大）。

又沒買到什麼（這是高分關鍵）
① \(\sum M_{nb}\) 用標稱強度算，但梁真正會發展到 \(M_{pr} = 1.25\) 倍 → 1.2 < 1.25， 單看這個比較，強柱弱梁其實「不夠」。
② 柱的 \(M_{nc}\) 隨當時軸力變化；地震時軸力起伏（一側柱受拉、一側受壓）， 最不利軸力下的 \(M_{nc}\) 可能比設計假設低。
③ 高模態反應與雙向地震會讓實際柱彎矩超過靜力分析值。
結論：柱端出鉸無法完全排除 → 所以規範仍然要求柱端有 \(l_o\) 密箍區與 \(A_{sh}\) 圍束。 這兩件事（強柱弱梁 + 柱端圍束）是互補而不是重複 —— 一個降低柱出鉸的機率，一個確保萬一出鉸了柱還有延性。

5.2 柱的設計剪力也來自梁的 Mpr

既然設計意圖是「梁端出鉸、柱保持彈性」，那麼柱能受到的最大剪力就被梁的塑鉸強度封頂 —— 再大的地震也送不進更多力。所以：

$$V_u^{col} = \frac{M_{col,top} + M_{col,bot}}{l_n},\qquad M_{col} = \frac{\Sigma M_{pr,\text{beam at joint}}}{2}\ (\text{上下柱等勁度})$$

分子是「柱端」的彎矩，不是「梁端」的 \(M_{pr}\)。接頭處梁傳來的彎矩要由接頭上、下兩根柱分擔， 所以 \(V_u^{col}\) 化簡後等於 \(\Sigma M_{pr,\text{beam at joint}}/l_n\) —— 分母是一根柱的淨高，分子是一個接頭的梁彎矩總和。

手算：RC-2012-3（2012，30 分，把梁與柱串起來的觀念鏈題）
柱 60×60 cm、12-#7、保護層 6 cm（至主筋心）、\(l_n = 300\) cm、\(N_u = 50\) tf、 4 腳 #4 箍筋（\(A_b=1.27\)）、\(f'_c=280\)、\(f_{yt}=4200\) kgf/cm²。
由前一題得梁端 \(M_{pr}^- = 75.52\)、\(M_{pr}^+ = 41.11\) tf·m。

① 柱設計剪力（接頭彎矩由上下柱分擔）

$$\text{接頭平衡：}\ \Sigma M_{col} = \Sigma M_{pr,\text{beam at joint}} = M_{pr}^- = 75.52\ \text{tf·m}$$ $$\text{上下柱等勁度}\Rightarrow\ M_{col,top} = M_{col,bot} = \frac{75.52}{2} = 37.76\ \text{tf·m}$$ $$V_u = \frac{M_{col,top}+M_{col,bot}}{l_n} = \frac{37.76+37.76}{3.0} = \frac{\Sigma M_{pr,\text{beam at joint}}}{l_n} = \frac{75.52}{3.0} = \mathbf{25.17\ tf}$$
陷阱：分子把梁的 Mpr 算了兩次
分子是一個接頭的梁 \(M_{pr}\) 總和，不是上下兩個接頭的總和； 寫成 \((75.52+75.52)/3.0 = 50.3\) tf 會高估一倍。 接頭處梁傳來的彎矩由接頭上、下兩根柱依勁度分擔（等勁度各半）， 所以「上下柱端各有 37.76」與「一個接頭有 75.52」講的是同一件事，不可再乘二。

② 密箍區長度

$$l_o = \max\!\left(\frac{l_n}{6},\; b_{\max},\; 45\right) = \max(50,\; 60,\; 45) = \mathbf{60\ cm}$$

③ 核心尺寸與 Ash

$$b_c = 60-2\times6 = 48\ \text{cm},\quad A_g = 3600,\quad A_{ch} = 48^2 = 2304,\quad \frac{A_g}{A_{ch}} = 1.563 > 1.30 \Rightarrow \text{式①控制}$$ $$\frac{A_{sh}}{s} = 0.3\times48\times\frac{280}{4200}\times0.5625 = 0.540\ \text{cm}^2/\text{cm}$$ $$A_{sh,prov} = 4\times1.27 = 5.08\ \text{cm}^2 \;\Rightarrow\; s \leq \frac{5.08}{0.540} = 9.41\ \text{cm}$$

④ 幾何間距上限

$$h_x = \frac{48}{3} = 16\ \text{cm} \Rightarrow s_o = 10+\frac{35-16}{3} = 16.3 \xrightarrow{\text{上限}} 15\ \text{cm}$$ $$s \leq \min\!\left(\frac{b}{4},\; 6d_b,\; s_o\right) = \min(15,\; 6\times2.22,\; 15) = 13.3\ \text{cm}$$

⑤ Vc = 0 判斷（柱的軸力條件是臨界）

$$\frac{A_g f'_c}{20} = 0.05\times280\times3600 = 50{,}400\ \text{kgf} = 50.4\ \text{tf}$$ $$N_u = 50\ \text{tf} < 50.4\ \text{tf} \;\Rightarrow\; V_c = 0\ \text{（只差 0.8%！）}$$ 三個自我檢查：
① 圍束需求給的 \(s \leq 9.41\) cm 比幾何限制 \(13.3\) cm 更嚴 → 本題是圍束控制，不是構造控制。若你算出圍束需求比幾何限制寬鬆，回去檢查 \(A_g/A_{ch}\)。
② \(N_u\) 與門檻只差 0.8% —— 出題者故意設在臨界點，務必把 50.4 算出來寫在紙上， 只寫「軸力小所以 \(V_c=0\)」拿不到分。
③ 柱剪力 25.17 tf 對 60×60 柱而言 \(v = 25170/(60\times54) \approx 7.77\) kgf/cm²， 約 \(0.46\sqrt{f'_c}\)，離 \(V_n\) 上限（約 \(2.65\sqrt{f'_c}b d\)）餘裕很大 —— 柱的剪應力水準本來就遠低於梁。
陷阱：柱剪力用地震分析的側力算
觸發信號：「以梁端產生塑鉸方式計算因地震引入柱剪力」。
錯誤思維：拿載重組合 \(U = 1.2D+1.0L+1.0E\) 的柱剪力當設計值。
正確認知：能力設計法用梁的 \(M_{pr}\) 反推。這個值通常比彈性分析大很多 —— 因為它代表「地震再大也就這樣了」的上限，反而是更可靠的設計基礎。 出自 RC-2012-3。

§6 梁柱接頭：整棟樓最容易被忽略的瓶頸

本節主張：接頭剪力可以是柱剪力的 2~6 倍，因為梁的頂筋拉力與底部混凝土壓力在接頭內形成一對水平力， 柱剪力只抵消其中一小部分。這是為什麼接頭常常是整個框架的控制點。

6.1 力平衡：Vjh 從哪裡來

切面以上：左梁頂筋拉力 \(T_{top}\) 把接頭往左拉，右梁頂部壓力 \(C_{bot}\)（大小等於右梁底筋拉力，故以 bot 標記）把接頭往左推 —— 兩者同向，所以相加；上柱剪力 \(V_{col}\) 方向相反，所以相減。搞錯這個符號會讓答案差兩倍以上 —— 而且是最常見的錯誤。
為什麼接頭剪力遠大於柱剪力（量級感）
以 RC-2005-3 的角接頭為例（只有一側有梁）： \(V_{jh}/V_{col} = 131.5/28.18 = \mathbf{4.67}\) 倍。
若是內接頭（兩側都有梁），分子還要多一項 \(C_{bot}\)（另一側梁的壓力），\(V_{jh}\) 幾乎翻倍而 \(V_{col}\) 只增一部分 → 比值會更高。
物理原因：梁的彎矩靠「頂筋拉力 × 力臂」傳遞，而力臂（約 \(0.9d\)）比柱的力臂（約半層高）短得多 → 同樣的彎矩，梁端的內力偶遠大於柱端的剪力。 所以「梁越深、鋼筋越多，接頭壓力越大」，這也是為什麼深梁配大量頂筋的設計常在接頭卡住。

6.2 γ 係數：三種單位制，三組數字

$$\phi V_{n} = \phi\,\gamma\sqrt{f'_c}\,A_j,\qquad \phi = 0.85$$
接頭類型（依有梁圍束的面數）psi 制MPa 制kgf/cm² 制
四面有梁（內接頭）201.75.3
三面或對面兩面有梁（T 形）151.23.9
其他（外接頭、角接頭）121.03.2
三組數字是同一組（自己驗一次就永遠不會記錯）
\(k\sqrt{f'_c}\) 型的係數換單位時，係數本身會變（因為根號裡也換了）： $$\text{psi} \to \text{kgf/cm}^2:\ \times\sqrt{0.0703} = 0.265 \qquad \text{psi} \to \text{MPa}:\ \times\sqrt{0.006895} = 0.0830$$ 驗算（psi → kgf/cm²）：\(20\times0.265 = 5.30\)、\(15\times0.265 = 3.98\)、\(12\times0.265 = 3.18\) ✓
驗算（psi → MPa）：\(20\times0.0830 = 1.66\approx1.7\)、\(15\times0.0830 = 1.25\approx1.2\)、\(12\times0.0830 = 1.00\) ✓
但三套數字是各規範自己取整的結果，不可互相反推。 從 MPa 換回 kgf/cm² 要乘 \(\sqrt{10.197} = 3.193\)：SI 的 \(1.7/1.2/1.0\) 得 \(5.43/3.83/3.19\)。 土木 401 印的 5.3／3.9／3.2 裡，\(5.3\) 對得上 psi 路徑（\(20\times0.265 = 5.30\)）、 \(3.9\) 對得上 SI 路徑（\(1.2\times3.193 = 3.83\)）—— 所以 T 形那一格是 3.9，不是 4.0 （4.0 只是 psi 路徑 3.98 的進位，土木 401 並未採用）。
這正是 RC-2005-3 解析裡「\(\gamma = 12\times0.265 = 3.18 \approx 3.2\)」那一行的來源。
陷阱：抄到不同單位制的 γ（這是本考點最常見的整題錯判來源）
三組數字都「看起來像 γ」，但只有與你所用單位制相符的那一組是對的。 用 kgf/cm² 算應力卻套 MPa 制的 1.7，接頭強度會被低估到約 1/3， 好斷面也會被判「不合格」。
可信的錨點是兩份 verified 解答： RC-2005-3（角接頭 \(\gamma=3.2\)，附 \(12\times0.265\) 的換算推導）與 RC-2003-3（內接頭 \(\gamma=5.3\)，明載對應 psi 制 20）。
考場上若題目未給 \(\gamma\)，寫出「採 kgf/cm² 制，\(\gamma=3.2\)（其他類接頭，等值於 ACI 12 psi 制）」最安全。

6.3 手算：RC-2005-3（2005，20 分，接頭群唯一必練）

給定：樓層高 \(H = 365\) cm，柱 60×60 cm，梁寬＝柱寬＝60 cm，梁 \(d = 70\) cm， 梁拉力筋 6-#8（\(A_s = 30.42\) cm²），\(f'_c = 280\)、\(f_y = 4200\) kgf/cm²。求角柱接頭剪力強度檢核。

① 梁鋼筋拉力（耐震取 1.25fy）

$$T = 1.25\,A_s f_y = 1.25\times30.42\times4200 = 159{,}705\ \text{kgf}$$ 依據：\(V_{jh} = \gamma\sqrt{f'_c}A_j\) 這條檢核只存在於耐震專章， 其配套規定即「接頭力須以梁受拉鋼筋 \(1.25f_y\) 計算」（土木 401-112 §15.6.2／ACI 318-19 §18.8.2.1）。

② 梁可能彎矩強度 Mpr（用來反推柱剪力）

$$a = \frac{159{,}705}{0.85\times280\times60} = 11.18\ \text{cm} \;\Rightarrow\; M_{pr} = 159{,}705\times\left(70-\frac{11.18}{2}\right) = 102.86\ \text{tf·m}$$

③ 柱剪力（接頭彎矩由上下柱各半，反曲點在樓層中高）

$$M_{col} = \frac{M_{pr}}{2} = 51.43\ \text{tf·m} \;\Rightarrow\; V_{col} = \frac{M_{pr}/2}{H/2} = \frac{M_{pr}}{H} = \frac{10{,}286{,}000}{365} = 28{,}181\ \text{kgf} = \mathbf{28.18\ tf}$$ 檢查：\(V_{col}\times H = 28.18\times3.65 = 102.9\) tf·m，應等於一個接頭的梁彎矩 ✓ （寫成 \(2M/H\) 就會多算一倍）。

④ 接頭剪力需求（角接頭：只有一側有梁）

$$V_{jh} = T - V_{col} = 159{,}705 - 28{,}181 = 131{,}524\ \text{kgf} = \mathbf{131.5\ tf}$$

⑤ 有效接頭面積（用規範原式，不用坊間簡化式）

$$b_j = \min\!\left(b_w + h_c,\; b_w + 2x\right) \le b_c \;\Rightarrow\; \min(60+60,\; 60+0) = 60\ \text{cm}\ (\le b_c = 60) \;\Rightarrow\; A_j = 60\times60 = 3600\ \text{cm}^2$$

⑥ 強度與檢核（角接頭 → γ = 3.2）

$$\phi V_n = 0.85\times3.2\times\sqrt{280}\times3600 = 0.85\times3.2\times16.733\times3600 = 163{,}851\ \text{kgf} = \mathbf{163.8\ tf}$$ $$V_{jh} = 131.5 \leq \phi V_n = 163.8 \quad✓\qquad \text{使用率} = 80\%$$ 三個自我檢查：
① \(V_{jh}/V_{col} = 131.5/28.18 = \mathbf{4.67}\) 倍 → 落在「接頭剪力是柱剪力的好幾倍」的合理帶內 ✓
② \(b_j\) 兩個候選（\(b_w+h_c\)、\(b_w+2x\)）都要寫出來再取小，最後還要 \(\le b_c\)； 梁寬＝柱寬（\(x = 0\)）時 \(b_j = b_c\) 是必然結果。
③ 若改以標稱 \(f_y\) 計算（\(T = 127{,}764\) kgf、\(M_n = 83.72\) tf·m、\(V_{col} = 22.94\) tf）， 則 \(V_{jh} = 104.8\) tf、使用率 64% —— 兩種算法結論都是通過，但耐震主線（\(1.25f_y\)）只剩 20% 餘裕。 作答時寫明你採用哪一種並說明理由；接頭題出自耐震專章，寫 \(1.25f_y\) 最安全。

§7 其他耐震構件：牆、橫膈版、耐震搭接

本節主張：這三類題目看似各自獨立，但它們遵守同一條原則： 凡是脆性、無替代路徑的傳力機制，折減更嚴、構造要求更多。 只要抓住這一點，沒見過的規定也能推出方向。

7.1 剪力牆（RC-2003-4，40 分大題）

項目規定／做法為什麼
\(\phi = 0.6\)牆的剪力折減比一般構件（0.75）更嚴牆剪力破壞是脆性、且牆是單一抗側力路徑，一旦破壞無替代
邊界構材（boundary element）牆兩端加大並加密箍牆的彎矩由兩端的拉壓力偶承擔 → 兩端是「柱」，需要柱的圍束要求
單層配筋條件
\(V_u \leq 0.53\sqrt{f'_c}A_{cv}\)		超過就必須雙層配筋剪力大 → 斜壓桿效應強 → 需要兩側都有鋼筋夾住，避免混凝土保護層剝離帶走鋼筋
水平＋垂直剪力筋都要兩個方向都要驗算配筋率牆的剪力傳遞是桁架機制：斜壓桿需要水平與垂直兩組拉力桿共同錨住
彎鉤錨定 \(l_{dh} = 0.06 f_y d_b/\sqrt{f'_c}\)水平筋在邊界構材內錨定水平剪力筋若在邊界構材處拔出，整個桁架機制失效
把剪力牆當成「一根躺著的深梁 + 兩根柱」
・牆版 = 深梁的腹板 → 負責剪力（水平＋垂直剪力筋 = 腹板的桁架）
・兩端邊界構材 = 深梁的頂底翼板／或兩根柱 → 負責彎矩（覆沒力矩 \(M\) 除以牆長得到拉壓力）
這個類比讓你不用背牆的規定：邊界構材的箍筋要求 ≈ 柱的要求（§4），牆版的剪力要求 ≈ 梁的要求但 \(\phi\) 更嚴。
RC-2003-4 的 \(M = 360\) tf·m、\(l_w = 9\) m → 邊界構材拉力約 \(360/(0.8\times9) = 50\) tf 量級， 再扣掉軸壓 25 tf/邊 → 這就是縱筋量的來源。

7.2 橫膈版（RC-2019-3）

樓版在耐震系統裡的角色是把地震慣性力水平傳遞到抗側力構件（牆或框架）。 所以它是一片「躺著的深梁」：需要抗剪鋼筋與弦力（chord）鋼筋。 考點通常是：算出樓層地震剪力 → 決定版內抗剪鋼筋比 \(\rho_t\) → 與撓曲控制的間距要求比較，取嚴者。

陷阱：橫膈版的鋼筋量被「撓曲控制」而非「剪力控制」
版的鋼筋間距同時受①剪力需求②撓曲最小鋼筋量與最大間距（\(\min(3h,\;45\text{ cm})\) 等）約束。 RC-2019-3 的重點正是「最終設計比較」—— 兩個需求都算，取嚴者，並說明是哪一個控制。

7.3 耐震搭接（RC-2010-2、RC-2003-2、RC-2004-1）

規定內容為什麼（耐震理由）
搭接位置限於柱中段 1/2（避開柱端 \(l_o\)）柱端是潛在塑鉸區，搭接在該處會在反覆載重下劈裂失效
搭接等級一律採 Class B（\(1.3 l_d\)）耐震設計不允許用 Class A 的寬鬆條件（同一斷面搭接比例大、應力高）
同一斷面搭接量\(\leq 50\%\) 主筋面積避免同一斷面同時是「弱面」
搭接區橫向鋼筋需配置圍束箍筋（間距加密）搭接的傳力靠混凝土劈裂抗力，橫向鋼筋提供圍束才不會劈開
\(l_d\) 詳細計算式的 \(K_{tr}\)橫向鋼筋指標，出現在 \((c+K_{tr})/d_b\) 分母它量化了上一條：橫向鋼筋越多 → 圍束越好 → \(l_d\) 越短
一條原則貫穿本節
搭接、接頭、牆的剪力、版的傳力，共同點都是「靠混凝土的抗拉／劈裂／互鎖」在傳力 —— 而這些機制在反覆載重下會退化。
所以規範的手法永遠是同兩招：①加橫向鋼筋提供圍束（\(A_{sh}\)、\(K_{tr}\)、搭接區箍筋、牆的雙層配筋）， ②把機制移到不會退化的位置（搭接移到柱中段、塑鉸移到梁端）。
記住這兩招，遇到沒背過的耐震條文也能答出「規範應該會要求什麼」。

§11 自我檢測：12 個「為什麼」

不用紙筆，用嘴巴回答。答不出來的，回去讀對應章節。

1. 耐震設計和一般強度設計在問的問題有什麼根本不同？

強度設計問「撐不撐得住」（強度 ≥ 需求）；耐震設計問「壞的時候用什麼方式壞」。 因為大地震下結構必然進入非線性，重點不再是不壞，而是壞得延性、可見、可耗能、不倒塌。 所以本單元的公式幾乎都在算「某個機構最多可能有多強」，再拿這個上限去設計別的構件。（§0）

2. 為什麼 1.25？它補償的是一件事還是兩件事？

兩件事：①鋼筋實際降伏強度統計上超過標稱值（SD420 實測常在 1.1~1.15 倍）； ②塑鉸大轉角下鋼筋進入應變硬化，應力繼續爬升。1.25 是兩者合起來的工程近似。（§1.2）

3. 為什麼 Mpr 的 φ 是 1.0 而不是 0.9？

φ < 1 的用途是「保證下限」（我至少有這麼強）。但 Mpr 要回答的是「它最多可能有多強」—— 那是上限問題，折減會讓答案往錯的方向跑，使剪力設計偏不安全。（§1.1）

4. 為什麼 Ve 的地震項在全跨是定值，而重力項是線性？

兩端塑鉸彎矩方向相同 → 彎矩圖是斜直線 → 斜率（剪力）為常數。 重力彎矩圖是拋物線 → 斜率線性變化。兩項是同一張彎矩圖的兩個部分的斜率，不是硬湊的公式。（§3.1）

5. Ve 分母為什麼是淨跨 ln？

塑鉸發生在柱面（那裡才是梁的斷面，接頭內不是梁），所以力臂是柱面到柱面的淨跨。（§3.1）

6. 塑鉸區 Vc 為什麼要歸零？為什麼還要附帶一個軸力條件？

反覆正負彎矩使裂縫貫穿全深度，骨材互鎖失效、壓力區混凝土剝落 → Vc 不可靠。 軸力條件（Nu < Agf'c/20）的意義是：足夠的軸壓可以把裂縫壓閉合、恢復骨材互鎖。 所以梁（無軸壓）幾乎必然 Vc=0，柱（有軸壓）要實際算過才知道。（§1.2、§8）

7. Ash 兩個公式各在防什麼？哪一式會控制？

式① \(0.3(A_g/A_{ch}-1)\)：補回保護層剝落瞬間損失的軸向強度。 式② \(0.09\)：與斷面大小無關的延性底線（提升 εcu），因為大斷面柱的 Ag/Ach 趨近 1，式①會趨近 0。 分界在 \(A_g/A_{ch} = 1.30\)：大於則式①控制。（§4.1）

8. 繫筋（crossties）有哪三個好處？

①直接增加 Ash 的腳數；②縮短箍筋外拱的跨距，讓圍束真正到得了核心中央； ③把 hx 變小，使 so = 10+(35−hx)/3 放寬。三件事是同一個動作的三個好處。（§4.2）

9. 強柱弱梁的 6/5 買到了什麼？沒買到什麼？

買到：吸收分析誤差、放樣誤差、樓板參與，讓柱出鉸在機率上不容易。 沒買到：梁實際會發展到 1.25 倍（> 1.2）、柱 Mnc 隨軸力變動、高模態與雙向地震 —— 所以柱出鉸無法完全排除，柱端仍須密箍。兩者互補而非重複。（§5.1）

10. 為什麼接頭剪力可以是柱剪力的好幾倍？

梁彎矩靠「頂筋拉力 × 力臂（約 0.9d）」傳遞，柱剪力的力臂是半層高，長得多。 同樣的彎矩，力臂短的那一側內力大得多。而且 T_top 與 C_bot 對切面同向 → 相加。 RC-2005-3 的角接頭就有 4.67 倍（\(T\) 取 \(1.25f_y\)、\(V_{col}=M_{pr}/H\)），內接頭把 \(T_{bot}\) 也加進來後更高。（§6.1）

11. γ 係數為什麼會有 5.3 / 1.7 / 20 三種數字？

同一組值的三種單位制。\(k\sqrt{f'_c}\) 型係數換單位時係數本身會變： psi → kgf/cm² 乘 \(\sqrt{0.0703}=0.265\)、psi → MPa 乘 \(\sqrt{0.006895}=0.0830\)。 驗算 20×0.265 = 5.30、20×0.0830 = 1.66 ✓。（§6.2）

12. 為什麼斷面韌性 μφ 幾乎總是大於位移韌性 μ？

因為塑性曲率只發生在塑鉸長度 \(L_p\) 這一小段（RC-2022-4 約佔柱長 19%）， 其餘部分仍是彈性的。極限檢查：令 \(L_p\to0\) 則 \(\mu\to M_u/M_y\approx1.1\) —— 斷面再有韌性，塑鉸長度為零則構件沒有韌性。（§2.1）

★ 精選 5 題：時間只夠練五題就練這五題

選題邏輯：一題練到最多獨立技能、彼此重疊最少，並且五題合起來覆蓋能力設計法的完整鏈條 （韌性定義 → 梁 → 柱 → 機構 → 接頭）。18 題裡有大量重複（接頭 4 題幾乎同型、柱圍束 3 題同型）， 練完這五題等於練完那些重複。

① RC-2025-2（2025，30 分）— 耐震梁公版，最新題

為什麼選它：本單元唯一「從 Mpr 一路做到箍筋間距與密箍區長度」的完整流程題， 而且是最新年份。2016-2、2012-2 都是它的子集 —— 練這一題等於練那兩題。 數字也被出題者調過（\(s_{req}=15.39\) vs \(s_{seis}=15.0\)），逼你兩個限制都算。

做完要能回答：①為什麼 Mpr⁻ 和 Mpr⁺ 要各算一次？②為什麼同一題出現 φ=1.0 與 φ=0.75？ ③密箍區為什麼是 2h 不是 2d？

② RC-2013-2（2013，25 分）— 柱圍束，且要自己畫配置

先讀：§4.1、§4.2、§4.3

③ RC-2012-3（2012，30 分）— 把梁與柱串起來的觀念鏈題

為什麼選它：它強迫你走完「梁塑鉸 → 柱剪力 → 柱圍束」的整條因果鏈， 還附帶一個臨界的 Vc=0 軸力判斷（Nu = 50 vs 門檻 50.4 tf，只差 0.8%）。 而且它與 RC-2012-2（梁 Mpr）、RC-2012-4（接頭）共用同一張構架圖 —— 練它時順手把那兩題的題目看過，等於掌握「一組構架考三個構件」的整套題型。
先讀：§5.1、§5.2、§4.1
做完要能回答：①柱剪力為什麼不用彈性分析值？②圍束需求與幾何間距限制哪一個控制，為什麼？ ③強柱弱梁通過了，為什麼柱端還要密箍？

④ RC-2005-3（2005，20 分）— 接頭群唯一必練，計算量最小

為什麼選它：接頭 4 題（2003-3、2005-3、2012-4、2018-2）幾乎同型，選計算最完整又最短的這一題。 它把「T → Mn → Vcol → Vjh → bj → Aj → γ → φVn」八個步驟壓在 20 分裡， 且解析附有 γ = 12 psi0.5 → 3.2 的換算推導，是本單元單位制問題的錨點。
先讀：§6.1、§6.2、§6.3
做完要能回答：①T_top 與 C_bot 為什麼相加、Vcol 為什麼相減？ ②角接頭與內接頭的 γ 差多少倍，為什麼？③內接頭的 Vjh 會變成多少？

⑤ RC-2022-4（2022，25 分）— 「韌性」二字的定義來源

為什麼選它：整個單元叫「韌性要求與耐震設計」，但只有這一題真的在量化韌性。 計算量小（純內插 + 代公式），卻是唯一會讓你想通「斷面韌性 ≠ 構件韌性 ≠ 系統韌性」的題目。 而且它有兩個內建自我檢查點（μθ = μ、Lp 下限控制），練起來投報率極高。
先讀：§2、§2.1
做完要能回答：①為什麼 L = lu/2？②為什麼軸力越大 φu 越小？ ③若 Lp → 0，μ 會趨近多少，這代表什麼？

練這五題的正確方法

  1. 先寫「這一題屬於哪一群、我要估上限還是下限」再動筆。 上限（Mpr、Vjh 的 T）→ 材料往上調、不折減；下限（Vc、φVn）→ 往下調、折減更嚴。 2 分鐘寫完這個判斷，能救回半題的分數。
  2. 每個 min／max 的候選全部寫出來再取值。 本單元有大量三選一（\(l_o\)、\(s\)、\(b_j\)、\(A_{sh}\) 兩式）—— 只寫最後結果拿不到過程分，而過程分通常佔一半以上。
  3. 把規範版本與單位制寫在答案紙第一行。 本單元至少有三處版本／單位差異（梁密箍間距、γ 係數、ΣMnb 是否含 1.25）， 註明依據後兩種答案都能得分；不註明才會被扣。
  4. ③和④各算兩遍。第二遍改一個條件（③把 Nu 改成 60 tf 看 Vc 是否還歸零； ④把角接頭改成內接頭，加上 T_bot 再算一次）。會判斷方向，比會算數字更能應付變形題。
  5. 量級檢查表隨身帶：Mpr/Mn ≈ 1.25；Ve 地震項佔比通常 > 70%； 接頭 Vjh/Vcol 約 1.5~6；柱 Ag/Ach 約 1.3~1.7；μφ 約 3~6 而 μ 約 2~4。出範圍就停下找錯。
誠實說明：這五題沒有涵蓋以下考點群
① 剪力牆設計（RC-2003-4）—— 只出現過一次，但是單題 40 分，且要同時處理邊界構材、水平／垂直剪力筋、錨定、斷面圖四個部分。 本講義 §7.1 只給了觀念骨架。這是本單元最大的缺口，強烈建議另外投資這一題， 它的分數等於本講義精選 ①②③ 加起來的一半以上。
② 耐震搭接與 ld 詳細計算法（RC-2003-2、RC-2004-1、RC-2010-2，共 3 題）—— 技術屬 RC-U2-3（錨定與搭接），但在耐震脈絡下反覆出現。§7.3 有觀念、無練習。
③ 橫膈版（RC-2019-3）—— 近年題型，且「剪力需求 vs 撓曲構造要求誰控制」的比較是關鍵。
④ 混凝土品質統計驗收（RC-2004-1 前半）—— 與力學無關的規範記憶題，本講義完全未觸及。
⑤ 梁的地震彎矩組合與配筋（RC-2016-1）—— 屬 RC-U1-1，但它是 §3 的前置（沒有 As 就沒有 Mpr）。
候補兩題：RC-2003-4（剪力牆，40 分，最值得補）、 RC-2010-2（耐震搭接，把 §7.3 變成可操作的計算）。

§13 因果鏈總表：能用嘴巴講出來才算懂

每一條都應該可以在 20 秒內不看講義講完。講不出來的，回去讀括號裡的節。

鏈 1：能力設計法為什麼存在（§0、§1）
大地震下結構必然進入非線性 → 問題從「不壞」變成「怎麼壞」 → 延性機構與脆性機構在賽跑，先到者決定破壞模式 → 所以刻意把延性側往上估（1.25fy、φ=1.0）、脆性側往下估（Vc=0、φ=0.85/0.75/0.6）→ 讓延性一定先到，而且領先幅度大到材料超強也翻不了盤。
鏈 2：為什麼剪力設計不能用 φMn（§1.1）
\(\phi M_n\) 是「保證下限」、\(M_{pr}\) 是「可能上限」 → 兩者差 \(1.25/0.9 = 1.39\) 倍 → 剪力要問「塑鉸能送進多大的力」，那是上限問題 → 用 \(\phi M_n\) 反推會低估 39% → 剪力可能先於彎矩破壞 → 能力設計法失效。
鏈 3：Ve 公式的兩項從哪來（§3.1）
兩端塑鉸彎矩方向相同 → 地震彎矩圖是斜直線 → 斜率為常數 \(\sum M_{pr}/l_n\) → 重力彎矩圖是拋物線 → 斜率線性 \(\pm w_u l_n/2\) → 兩者同號的那一端是控制端 → 這就是公式裡 \(\pm\) 的意思；分母用淨跨因為塑鉸在柱面。
鏈 4：Vc = 0 與軸力條件（§1.2、§8）
塑鉸區反覆正負彎矩 → 裂縫貫穿全深度 → 骨材互鎖失效、壓力區剝落 → \(V_c\) 不可靠 → 但足夠的軸壓能把裂縫壓閉合、恢復互鎖 → 所以加一個 \(N_u < A_g f'_c/20\) 的條件 → 梁（無軸壓）幾乎必然 \(V_c=0\)；柱（有軸壓）必須實際算過才知道。
鏈 5：Ash 為什麼是兩式（§4.1）
柱大變形時保護層必剝落 → 損失 \((A_g-A_{ch})\) 的承載面積 → 圍束的強度增量要補回它（式①）→ 但大斷面柱 \(A_g/A_{ch}\to1\)，式①趨近 0 → 而圍束還有「提升 \(\varepsilon_{cu}\)」的作用，與尺寸無關 → 需要一條不含 \(A_g/A_{ch}\) 的延性底線（式②）→ 分界 \(A_g/A_{ch}=1.30\)。
鏈 6：繫筋的三重效果（§4.2）
箍筋只在角落被撐住 → 中間段外拱、圍束到不了核心中央 → 加繫筋 → ①直接增加 \(A_{sh}\) 腳數 ②縮短外拱跨距、擴大有效圍束區 ③縮小 \(h_x\)、放寬 \(s_o\) → 三個好處是同一個動作帶來的。
鏈 7：強柱弱梁與柱密箍為什麼並存（§5.1）
柱端出鉸 → 層崩塌機構（6 個鉸就倒）→ 必須讓梁先出鉸 → \(\sum M_{nc}\ge\frac65\sum M_{nb}\) → 但 1.2 < 1.25（梁的實際超強）、柱 \(M_{nc}\) 隨軸力變動、高模態效應 → 柱出鉸無法完全排除 → 所以柱端仍需 \(l_o\) 與 \(A_{sh}\)：一個降低機率，一個保底延性。
鏈 8：接頭為什麼是瓶頸（§6.1）
梁彎矩靠「頂筋拉力 × 約 0.9d 的力臂」傳遞，柱剪力的力臂是半層高 → 力臂短的一側內力大得多 → \(T_{top}\) 與 \(C_{bot}\) 對切面同向相加、只有 \(V_{col}\) 相減 → \(V_{jh}\) 可達柱剪力的 1.5~6 倍 → 梁越深、頂筋越多，接頭越容易卡住。
鏈 9：韌性的三個尺度（§2.1）
斷面能提供 \(\mu_\phi = \phi_u/\phi_y\) → 但塑性曲率只發生在 \(L_p\) 這一小段 → 塑鉸轉角 \(\theta_p = (\phi_u-\phi_y)L_p\) 乘力臂 \((L-L_p/2)\) 才變成頂點位移 → 其餘柱長仍是彈性 → 所以 \(\mu < \mu_\phi\)；而 \(\theta=\delta/L\) 使 \(\mu_\theta\) 必等於 \(\mu\)。
鏈 10：所有耐震構造規定的兩招（§7.3）
搭接、接頭、牆剪力、版傳力的共同點：都靠混凝土的抗拉／劈裂／骨材互鎖傳力 → 這些機制在反覆載重下退化 → 規範只有兩招： ①加橫向鋼筋提供圍束（\(A_{sh}\)、\(K_{tr}\)、搭接區箍筋、牆雙層配筋）、 ②把機制移到不會退化的位置（搭接移到柱中段、塑鉸移到梁端）→ 遇到沒背過的條文，用這兩招也能推出方向。
